# Pilot notes (invented, for the handover copilot)

## What was built
- A claims queue with four states and a sign-off rule enforced in the backend.
- An agent that reads one claim and returns approve, decline or refer.
- A scoreboard on a held-out set, a swarm with a cap, and this copilot.

## What was decided
- Payouts over S$800 always wait for a handler's signature.
- The agent only returns an answer. The backend decides what happens to it.
- Memory holds facts only, each with a source and a date.
