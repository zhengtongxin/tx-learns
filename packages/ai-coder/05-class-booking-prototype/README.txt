Class booking prototype: package
================================
What this is: a one-sheet MVP plan plus the one rule that matters, built and
tested with a coding agent: a class never holds more people than its seats,
and a cancel moves the first waitlisted person in.

Folders
  starter/   mvp.txt left blank, booking.js with three empty functions, the test.
  final/     a finished mvp.txt and booking.js, and the same test.

What you need
  - Node.js 18 or newer (no install step).
  - A coding agent. A payment link and hosting are optional later steps.

Offline check (no keys, no network)
  cd final
  node test_booking.js     prints one "ok:" line.
  Run it in starter/ first: it fails until the agent finishes.

Use it
  1. Fill in mvp.txt for a small business you know (made-up is fine).
  2. Put the not-now list in your AGENTS.md so the agent respects it.
  3. Get the tests passing, then add your own.

The studio is only an example. Use your own idea.
