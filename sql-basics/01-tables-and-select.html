Step 1 · Tables, rows, columns第 1 步 · 表、行、列

Learn先学

A database stores data in tables. A table is a grid: each column has a name and a type (name text, price number), and each row is one record. Unlike a loose spreadsheet, a database enforces the shape, handles many users at once and can answer questions about millions of rows in a blink. SQL is the language for asking.

数据库把数据存在表里。表是一张网格：每一列有名字和类型（name 是文本，price 是数字），每一行是一条记录。和随手的表格不同，数据库会强制保证形状，能同时服务很多用户，还能瞬间回答关于上百万行数据的问题。SQL 就是用来提问的语言。

Step 2 · SELECT and FROM第 2 步 · SELECT 与 FROM

Learn先学

SELECT says which columns you want and FROM says which table. SELECT * means every column. LIMIT 3 keeps only the first three rows. Keywords are not case sensitive, but writing them in capitals makes a query easier to read.

SELECT 说明要哪几列，FROM 说明哪张表。SELECT * 表示所有列。LIMIT 3 只保留前三行。关键字不分大小写，但写成大写能让查询更好读。

SELECT name, price FROM menu; SELECT * FROM menu LIMIT 3;

Takeaways要点回顾

• A table has typed columns and one row per record.
• SELECT picks columns, FROM picks the table.
• LIMIT keeps only the first rows.

• 表有带类型的列，每条记录一行。
• SELECT 选列，FROM 选表。
• LIMIT 只保留前几行。
