Joining tables连接多张表

Step 1 · One fact, one place第 1 步 · 一个事实，一个地方

Learn先学

If every order row repeated the customer’s name, a spelling fix would mean editing hundreds of rows. Instead each customer lives once in a customers table with a unique primary key id, and each order stores only that number in a foreign key column customer_id. The link is a number, not a copy.

如果每条订单都重复写客户姓名，改个拼写就要改几百行。更好的做法是：每个客户只在 customers 表里存一次，带一个唯一的主键 id；每条订单只在外键列 customer_id 里存这个编号。链接靠的是编号，而不是复制。

Step 2 · JOIN第 2 步 · JOIN

Learn先学

JOIN ... ON lines up rows from two tables where the key matches. An INNER JOIN keeps only rows that have a match on both sides. A LEFT JOIN keeps every row of the left table and fills the missing side with NULL, which is how you find customers with no orders.

JOIN ... ON 把两张表中键相同的行对在一起。INNER JOIN 只保留两边都有匹配的行。LEFT JOIN 保留左表的所有行，缺失的一边用 NULL 补上，这正是找出“没有订单的客户”的办法。

SELECT customers.name, orders.item FROM customers JOIN orders ON orders.customer_id = customers.id;

Takeaways要点回顾

• Store each fact once and link tables by keys.
• INNER JOIN keeps matches only; LEFT JOIN keeps all left rows.
• A missing match shows up as NULL.

• 每个事实只存一次，用键链接各表。
• INNER JOIN 只留匹配的；LEFT JOIN 保留左表所有行。
• 没有匹配的一侧显示为 NULL。
