Test functions测试函数

Organise checks into small named test functions that a runner finds and runs · ~10 min · reading and practice把检查整理成小而有名字的测试函数，让测试运行器自己找到并运行 · 约 10 分钟 · 阅读加练习

Step 1 · One test, one idea第 1 步 · 一个测试，一个想法

Learn先学

Group asserts into functions that each check one idea, named for it: test_zero_items_cost_nothing. When it fails, the name alone tells you what broke. A test runner such as pytest finds every function whose name starts with test_, runs them all, and reports which passed and which failed instead of stopping at the first.

把 assert 分组到各自只检查一个想法的函数里，并用它命名：test_zero_items_cost_nothing。失败时，光看名字就知道什么坏了。pytest 这样的测试运行器会找出所有以 test_ 开头的函数，全部运行，并报告哪些通过、哪些失败，而不是在第一个失败处停下。

from shop import total def test_total_multiplies(): assert total(2, 3.0) == 6.0 def test_zero_items_cost_nothing(): assert total(0, 9.9) == 0

Step 2 · Arrange, act, assert第 2 步 · 准备、执行、断言

Learn先学

A readable test has three beats: arrange the input, act by calling the code, assert on the result. Keep them in that order and keep each test short. A test that needs a page of setup is a sign the code under test does too much.

好读的测试有三拍：准备输入，执行——调用代码，断言结果。保持这个顺序，让每个测试都很短。一个需要一页准备工作的测试，说明被测的代码做的事太多了。

Takeaways要点回顾

• One test checks one idea and is named for it.
• A runner finds test_ functions and reports every result.
• Arrange, act, assert, in that order.

• 一个测试检查一个想法，并以它命名。
• 运行器找出 test_ 函数，并报告每个结果。
• 准备、执行、断言，按这个顺序。
