Assertions断言

Turn “it looks right” into a check that says pass or fail, using assert · ~10 min · reading and practice用 assert 把“看起来对”变成会说通过或失败的检查 · 约 10 分钟 · 阅读加练习

Step 1 · Looking is not checking第 1 步 · 看一眼不叫检查

Learn先学

Running code and glancing at the output proves little: you may not notice a wrong number, and tomorrow you will not remember what “right” looked like. A test writes the expected answer down and lets the computer compare, every time, in a second. Edit the code at 11 pm and the test tells you if you broke something.

运行代码、扫一眼输出，证明不了多少：你可能没注意到错的数字，明天也记不得“对”的样子。测试把期望的答案写下来，让电脑每一次都在一秒内比对。半夜十一点改了代码，测试会告诉你有没有改坏。

Step 2 · assert第 2 步 · assert

Learn先学

assert condition does nothing if the condition is true and stops with an AssertionError if it is false. Add a message after a comma to say what went wrong. A test is usually a call with a known answer: assert total(2, 3.0) == 6.0.

assert 条件 在条件为真时什么都不做，为假时就用 AssertionError 停下。逗号后可以加一句说明出了什么问题。测试通常就是一次已知答案的调用：assert total(2, 3.0) == 6.0。

def total(qty, price): return qty * price assert total(2, 3.0) == 6.0 assert total(0, 9.9) == 0, "zero items should cost nothing" print("all good")

对 def double(n): return n * 2，判断每个 assert 是否通过。

Takeaways要点回顾

• A test writes down the expected answer and checks it automatically.
• assert is silent when true and raises AssertionError when false.
• Add a message so a failure explains itself.

• 测试把期望的答案写下来，并自动检查。
• assert 为真时沉默，为假时抛出 AssertionError。
• 加一句说明，让失败自己讲清楚。
