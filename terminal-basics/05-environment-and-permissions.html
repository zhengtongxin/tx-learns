Environment and permissions环境与权限

Use environment variables and PATH, and read and change file permissions · ~10 min · reading and practice使用环境变量与 PATH，并读懂、修改文件权限 · 约 10 分钟 · 阅读加练习

Step 1 · Environment variables第 1 步 · 环境变量

Learn先学

An environment variable is a named setting that programs can read, such as HOME or an API key. Set one with export NAME=value and read it with $NAME. A variable set in one terminal is not visible in another, and it disappears when the terminal closes unless you save it in your shell profile. API keys belong here or in a .env file, never inside code you share.

环境变量是程序可以读取的有名字的设置，比如 HOME 或 API 密钥。用 export 名字=值 设置，用 $名字 读取。在一个终端里设的变量，别的终端看不到；终端关掉就消失，除非写进 shell 的配置文件。API 密钥放在这里或 .env 文件里，绝不写进要分享的代码。

export SHOP=Mei echo "Hello $SHOP"

Step 2 · PATH第 2 步 · PATH

Learn先学

When you type a command name, the shell looks for a program with that name in each folder listed in PATH, in order. “command not found” usually means the program is not installed or its folder is not in PATH. which name shows which file would run.

你输入命令名时，shell 会按顺序在 PATH 列出的每个文件夹里找同名程序。“command not found”通常说明程序没装，或它所在的文件夹不在 PATH 里。which 名字 会显示将运行的是哪个文件。

Step 3 · Permissions第 3 步 · 权限

Learn先学

ls -l shows ten characters like -rwxr-xr--. The first says file or folder, then three groups of read, write and execute for the owner, the group and everyone else. A script must be executable to run directly: chmod +x script.sh. chmod 600 file keeps a file private to you. A “Permission denied” error means the permission bits, not a broken file.

ls -l 会显示类似 -rwxr-xr-- 的十个字符。第一位表示文件还是文件夹，后面三组分别是所有者、所属组和其他人的读、写、执行权限。脚本要可执行才能直接运行：chmod +x script.sh。chmod 600 文件 让文件只有你自己能用。“Permission denied”说的是权限位的问题，不是文件坏了。

Takeaways要点回顾

• export sets a variable and $NAME reads it.
• PATH lists the folders searched for commands.
• chmod changes who may read, write or run a file.

• export 设置变量，$NAME 读取它。
• PATH 列出查找命令的文件夹。
• chmod 修改谁能读、写、运行文件。
