Reading and searching查看与搜索

Read files, count lines and search file contents and names without opening an editor · ~10 min · reading and practice不开编辑器就能读文件、数行数，并按内容和名字搜索 · 约 10 分钟 · 阅读加练习

Step 1 · Look inside a file第 1 步 · 看文件里面

Learn先学

cat file prints a whole file. For long files use head -n 3 file for the first lines and tail -n 3 file for the last, and wc -l file to count the lines. This is how you peek at logs and data without opening anything.

cat 文件 打印整个文件。文件很长时，用 head -n 3 文件 看开头几行，tail -n 3 文件 看最后几行，wc -l 文件 数行数。这样不用打开任何东西就能偷看日志和数据。

cat menu.txt head -n 2 menu.txt wc -l menu.txt

Step 2 · Search inside files第 2 步 · 在文件内容里搜索

Learn先学

grep word file prints the lines that contain the word. -i ignores case, -n shows line numbers, -c counts the matching lines, and -r word folder searches every file in a folder. When something is “somewhere in the project”, grep finds it in a second.

grep 词 文件 打印包含该词的行。-i 忽略大小写，-n 显示行号，-c 统计匹配的行数，-r 词 文件夹 搜索文件夹里的每个文件。当东西“在项目里的某处”，grep 一秒就能找到。

Step 3 · Search for names第 3 步 · 按名字找文件

Learn先学

find folder -name "*.txt" lists files by name, where * matches anything. Use grep when you know what a file says and find when you know what it is called.

find 文件夹 -name "*.txt" 按名字列出文件，其中 * 匹配任意内容。知道文件“写了什么”用 grep，知道文件“叫什么”用 find。

Takeaways要点回顾

• cat, head and tail read; wc counts.
• grep searches inside files, find searches names.
• -i, -n, -c and -r make grep far more useful.

• cat、head、tail 读；wc 计数。
• grep 搜索文件内容，find 搜索名字。
• -i、-n、-c、-r 让 grep 强大得多。
