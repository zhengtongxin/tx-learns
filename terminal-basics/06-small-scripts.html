Small scripts小脚本

Save commands in a script, use variables and loops, and check whether a command worked · ~10 min · reading and practice把命令存进脚本，使用变量和循环，并检查命令是否成功 · 约 10 分钟 · 阅读加练习

Step 1 · A script is saved commands第 1 步 · 脚本就是存起来的命令

Learn先学

A script is a text file of commands. Start it with #!/usr/bin/env bash (the “shebang”, which names the interpreter), make it executable and run it with ./backup.sh. Anything you repeat more than twice is worth saving.

脚本就是一个写满命令的文本文件。开头写上 #!/usr/bin/env bash（叫 shebang，指明解释器），把它设为可执行，再用 ./backup.sh 运行。凡是重复超过两次的事，都值得存成脚本。

#!/usr/bin/env bash set -e name="menu" cp "$name.txt" "$name.bak" echo "Saved $name"

Step 2 · Variables and loops第 2 步 · 变量与循环

Learn先学

A variable is set without spaces around the equals sign, name="menu", and read with $name. Quote it, "$name", so spaces in a value do not split it. A loop repeats for each item: for f in *.txt; do echo "$f"; done.

变量赋值时等号两边不能有空格，name="menu"，读取用 $name。读取时加上引号 "$name"，这样值里有空格也不会被拆开。循环对每一项重复一次：for f in *.txt; do echo "$f"; done。

Step 3 · Did it work第 3 步 · 它成功了吗

Learn先学

Every command finishes with an exit status: 0 means success and anything else means failure. $? holds the last one. cmd1 && cmd2 runs the second only if the first succeeded, and set -e at the top of a script stops it at the first failure instead of carrying on with broken data.

每条命令结束时都有一个退出状态：0 表示成功，其他都表示失败。$? 保存最近一个。cmd1 && cmd2 只在第一条成功时才运行第二条；脚本开头的 set -e 会在第一次失败时就停下，而不是带着错误数据继续。

Takeaways要点回顾

• A script is saved commands with a shebang first line.
• Variables take no spaces around = and need quotes when read.
• Exit status 0 is success; set -e stops on failure.

• 脚本是存起来的命令，第一行是 shebang。
• 变量赋值时 = 两边无空格，读取时要加引号。
• 退出状态 0 是成功；set -e 在失败时停止。
