Files and folders文件与文件夹

Create, copy, move and delete files and folders, and know why delete has no undo · ~10 min · reading and practice创建、复制、移动和删除文件与文件夹，并明白为什么删除无法撤销 · 约 10 分钟 · 阅读加练习

Step 1 · Make things第 1 步 · 创建

Learn先学

mkdir name makes a folder, and mkdir -p a/b/c makes the whole chain. touch file makes an empty file, or updates the time of an existing one. Names with spaces need quotes, so most people avoid spaces and use dashes.

mkdir 名字 创建文件夹，mkdir -p a/b/c 一次建出整条路径。touch 文件 创建空文件，或更新已有文件的时间。带空格的名字要加引号，所以多数人避免空格，改用短横线。

mkdir -p shop/data touch shop/data/prices.txt ls shop/data

Step 2 · Copy and move第 2 步 · 复制与移动

Learn先学

cp from to copies a file (add -r for a folder). mv from to moves it, and renaming is just moving to a new name in the same place. Both overwrite the destination without asking if it already exists.

cp 源 目标 复制文件（复制文件夹加 -r）。mv 源 目标 移动，而改名就是在同一位置移动成新名字。如果目标已存在，两者都会不打招呼地直接覆盖。

cp prices.txt prices-backup.txt mv prices.txt menu.txt ls

Step 3 · Delete with care第 3 步 · 小心删除

Learn先学

rm file deletes a file and rm -r folder deletes a folder and everything in it. There is no trash can: the data is gone. Before a risky rm, run ls with the same path to see exactly what it would hit, and never paste an rm -rf you do not understand.

rm 文件 删除文件，rm -r 文件夹 删除文件夹及其中全部内容。没有回收站：数据就没了。执行有风险的 rm 之前，先用同样的路径跑一遍 ls，看清它会命中什么；也别粘贴自己看不懂的 rm -rf。

Takeaways要点回顾

• mkdir and touch create; cp and mv copy and move.
• Renaming is moving to a new name.
• rm has no undo: ls first.

• mkdir 和 touch 创建；cp 和 mv 复制和移动。
• 改名就是移动成新名字。
• rm 无法撤销：先 ls。
