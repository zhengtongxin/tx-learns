The terminal and paths终端与路径

Know where you are, move around and tell absolute paths from relative ones · ~10 min · reading and practice知道自己在哪，学会移动，并分清绝对路径与相对路径 · 约 10 分钟 · 阅读加练习

Step 1 · Text in, text out第 1 步 · 输入文字，得到文字

Learn先学

The terminal is a window where you type a command and read the answer, instead of clicking. A shell (usually bash or zsh) reads each line you type and runs it. Anything you can click you can also type, and what you type can be saved, repeated and automated. That is why developers and AI coding tools live in it.

终端是一个你输入命令、读取结果的窗口，而不是点击。shell（通常是 bash 或 zsh）读取你输入的每一行并执行。你能点的，也都能打出来；而打出来的东西可以保存、重复、自动化。所以开发者和 AI 编程工具都住在里面。

Every command has the same shape: the program, then options, then what to act on, for example ls -l notes.

每条命令的形状都一样：程序名，然后选项，然后操作对象，比如 ls -l notes。

Step 2 · Where am I第 2 步 · 我在哪

Learn先学

At any moment the shell is “in” one folder, the current directory. pwd prints it, ls lists what is inside, and cd name moves into a folder. cd .. goes up one level, and cd alone goes to your home folder.

任何时候 shell 都“在”某一个文件夹里，叫当前目录。pwd 打印它，ls 列出里面的内容，cd 名字 进入某个文件夹。cd .. 回到上一层，单独一个 cd 回到你的主目录。

pwd ls cd projects ls cd ..

Step 3 · Absolute and relative paths第 3 步 · 绝对路径与相对路径

Learn先学

An absolute path starts at the root / and means the same thing from anywhere: /home/mei/projects. A relative path starts from where you are: projects/shop, or ../notes for “up one, then notes”. ~ stands for your home folder. Use relative paths for speed and absolute ones when you must be sure.

绝对路径从根目录 / 开始，无论你在哪里意思都一样：/home/mei/projects。相对路径从你所在的位置开始：projects/shop，或 ../notes，意思是“上一层，再进 notes”。~ 代表你的主目录。图快用相对路径，要确保无误时用绝对路径。

Takeaways要点回顾

• The shell is always in one current directory; pwd shows it.
• ls lists, cd moves, cd .. goes up.
• Absolute paths start with /, relative ones start from here.

• shell 总在某个当前目录里；pwd 显示它。
• ls 列出，cd 移动，cd .. 上一层。
• 绝对路径以 / 开头，相对路径从当前位置算起。
