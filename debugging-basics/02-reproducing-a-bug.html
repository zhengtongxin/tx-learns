Finding the bug · Lesson 2找到问题 · 第 2 课

Reproducing a bug复现问题

Make a bug happen on demand, with the smallest input that still shows it · ~10 min · reading and practice让问题能随时出现，并找到仍能触发它的最小输入 · 约 10 分钟 · 阅读加练习

Step 1 · If you cannot repeat it, you cannot fix it第 1 步 · 不能重现，就修不了

Learn先学

A bug you cannot trigger is a bug you cannot test a fix for. The first job is to find the exact steps and input that make it happen every time. Write them down: the input, what you did, what you expected and what you got instead. If it happens only sometimes, note what differed between the times it worked and the times it did not.

不能触发的问题，你就没法验证修复是否有效。第一件事是找出每次都能让它发生的确切步骤和输入。把它们写下来：输入是什么、你做了什么、你预期什么、实际得到什么。如果只是偶尔发生，就记下成功和失败的几次之间有什么不同。

Step 2 · Shrink the example第 2 步 · 缩小示例

Learn先学

Take the failing case and cut it down: remove inputs, lines and settings one at a time, and after each cut check that the bug still happens. Stop when removing anything more makes it disappear. What is left is a minimal example, often only a few lines, and the cause is usually visible in it.

拿到会出错的案例，把它削减：一次去掉一个输入、一行代码或一项设置，每去掉一样就检查问题是否还在。再去掉就消失时停下。剩下的就是最小示例，通常只有几行，原因往往一眼就能看出来。

def last_word(s): return s.split(" ")[-1] # repr() shows the value with its quotes, so an empty string is visible as '' print(repr(last_word("hi there ")))

Step 3 · Make it repeatable第 3 步 · 让它可重复

Learn先学

Remove what changes between runs. Fix the input instead of typing it fresh, use the same data file, set the same random seed (a starting number that makes random choices come out the same every run) and note the versions you ran. Once a script makes the bug appear in one command, you can try fixes quickly and prove each one. Sort each habit.

去掉每次运行之间会变的东西。把输入固定下来，而不是每次重新输入；用同一份数据文件；设置同样的随机种子（一个起始数字，让每次运行的“随机”选择都一样）；记下用的版本。一旦有个脚本一条命令就能让问题出现，你就能快速试修复、并逐个验证。给每个习惯分类。

Takeaways要点回顾

• Find steps that trigger the bug every time.
• Shrink the example until nothing more can go.
• Fix the input and seed so the failure repeats.

• 找到每次都能触发问题的步骤。
• 不断缩小示例，直到再也不能去掉东西。
• 固定输入和随机种子，让失败可以重复。
