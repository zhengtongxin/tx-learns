Looking inside看清内部

Print, log and step through code to see the real values instead of the ones you assume · ~10 min · reading and practice用打印、日志和单步运行看到真实的值，而不是你以为的值 · 约 10 分钟 · 阅读加练习

Step 1 · Print with a label第 1 步 · 带标签地打印

Learn先学

The quickest way to see inside is print. A bare number is hard to read once there are several, so label each value. In Python, f"{x=}" prints the name and the value together. Print what you believe is true at that point, and be ready to be surprised.

最快看清内部的办法是 print。一旦有好几个，光秃秃的数字就难读了，所以给每个值加标签。在 Python 里，f"{x=}" 会同时打印名字和值。打印你相信在这一点上成立的东西，并准备好被打脸。

x = 3 items = [1, 2] print(f"{x=}") print(f"{len(items)=}")

Step 2 · Facts and assumptions第 2 步 · 事实与假设

Learn先学

Debugging is mostly finding the one belief that is false: “this list is never empty”, “this runs before that”, “the file has been saved”. Write your beliefs as a list, then check each one with a print or a test. The belief you were most sure of is often the wrong one, because you stopped checking it.

调试多半是在找出那个错误的信念：“这个列表从不为空”、“这个先于那个运行”、“文件已经保存了”。把你的信念列成清单，然后逐条用打印或测试检查。你最有把握的那条，往往恰恰是错的，因为你早就不再检查它了。

Step 3 · Logs and debuggers第 3 步 · 日志与调试器

Learn先学

Prints vanish when you clean up. A log is a print you keep on purpose, with a level (info, warning, error) so you can turn the noise up or down; it is how you look inside a program running somewhere you cannot watch. A debugger pauses the program at a line you choose and lets you look at every variable and step forward one line at a time, with no code changes. Use prints for a quick look, a debugger when you need to explore, and logs for what happens after you have gone home.

打印在你清理代码时就消失了。日志是你有意保留的打印，带有级别（信息、警告、错误），可以把噪音调大调小；用它才能看到在你看不到的地方运行的程序。调试器在你选定的某一行暂停程序，让你查看每个变量，并一行一行往下走，不用改代码。快速看一眼用打印，需要探索时用调试器，你下班之后发生的事靠日志。

import logging logging.basicConfig(level=logging.INFO) logging.info("loaded %d rows", 3) # a log line that stays in the code items = [] breakpoint() # pauses here so a debugger can inspect items

Takeaways要点回顾

• Print values with labels, and expect surprises.
• The belief you stopped checking is often the false one.
• Prints for a quick look, a debugger to explore, logs for later.

• 带标签地打印值，并预期会有意外。
• 你不再检查的那条信念往往是错的。
• 打印看一眼，调试器做探索，日志留给之后。
