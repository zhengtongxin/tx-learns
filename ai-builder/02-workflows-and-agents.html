Workflows and agents工作流与智能体

Know when a fixed workflow beats an agent, and how data moves between nodes · ~12 min · concepts知道什么时候固定工作流胜过智能体，以及数据怎么在节点间流动 · 约 12 分钟 · 讲概念

Step 1 · Data travels as items第 1 步 · 数据以“条目”流动

Learn先学

Each node receives a list of items, and each item is a small block of JSON: named fields with values. A node changes the items and passes them on.

每个节点收到一串条目，每个条目是一小块 JSON：有名字的字段和对应的值。节点处理完条目，再往下传。

Three new rows in a sheet become three items. The next node runs once per item.

表格里新来三行，就变成三个条目。下一个节点会对每个条目各跑一次。

{ "name": "Wei Jie", "plan": "weekend", "amount": 42.5 }

Step 2 · Read a field with an expression第 2 步 · 用表达式读取字段

Learn先学

To use a field from the previous node, write an expression inside double curly braces. $json means "the current item".

要用上一个节点的字段，就在双花括号里写表达式。$json 表示“当前这个条目”。

• {{ $json.name }} gives Wei Jie.
• {{ $json.amount * 1.09 }} adds 9% tax.
• {{ $json.plan }} can fill a message: Hi Wei Jie, your weekend plan is ready.

• {{ $json.name }} 得到 Wei Jie。
• {{ $json.amount * 1.09 }} 加上 9% 的税。
• {{ $json.plan }} 可以填进消息：Hi Wei Jie，你的 weekend 方案已准备好。

Switch a field to Expression mode and n8n shows a live preview of the result.

把字段切到 Expression 模式，n8n 会实时预览结果。

Hi {{ $json.name }}, your {{ $json.plan }} plan is {{ $json.amount * 1.09 }} dollars with GST.

Step 3 · Workflow or agent?第 3 步 · 工作流还是智能体？

Learn先学

Use a workflow when you can write the steps down. It is cheap, fast and repeatable. Use an agent when the steps depend on what comes in.

步骤能写下来，就用工作流：便宜、快、结果可重复。步骤要看输入才能定，就用智能体。

Best of both: a fixed workflow with one AI step inside it, such as "classify this email". You keep control and still use a model where words are messy.

两全其美的做法：固定工作流里只放一个 AI 步骤，比如“给这封邮件分类”。流程你来掌控，只在文字乱的地方用模型。

给每一项分类。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Data moves as items, each one a block of JSON.
• An expression like {{ $json.name }} reads a field from the current item.
• Workflows are cheap and repeatable; agents are flexible but cost more.
• Often the best design is a fixed flow with one AI step.
• Start with the plain workflow and add a model only where it earns its place.

• 数据以条目流动，每个条目是一块 JSON。
• 像 {{ $json.name }} 这样的表达式，读取当前条目的字段。
• 工作流便宜、可重复；智能体灵活，但更贵。
• 最好的设计往往是固定流程加一个 AI 步骤。
• 先用普通工作流，只在值得的地方加模型。
