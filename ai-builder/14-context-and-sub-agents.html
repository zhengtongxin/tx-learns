Context and sub-agents上下文与子智能体

Decide what a model sees on each call, and split work among helpers with their own fresh context · ~12 min · concepts决定模型每次调用能看到什么，并把工作分给各有干净上下文的助手 · 约 12 分钟 · 讲概念

Step 1 · Context is everything it sees第 1 步 · 上下文就是它看到的一切

Learn先学

A model knows only what is in its context for this call. Context engineering is choosing what goes in, every time.

模型只知道这次调用的上下文里有什么。上下文工程就是每次都精心挑选放进去的内容。

• Instructions: the system message.
• Memory: a short summary of what matters from before.
• Retrieved facts: the few passages from search.
• Tool results: what the last tool returned.
• The question: what the user wants now.

• 指示：系统消息。
• 记忆：对之前重要内容的简短摘要。
• 检索到的事实：搜索出的几段文字。
• 工具结果：上一个工具返回的内容。
• 问题：用户现在想要什么。

More is not better. Extra text costs money, slows the reply and can bury the one line that matters.

不是越多越好。多余的文字花钱、拖慢回复，还可能把关键的那一行埋掉。

Step 2 · Keep it clean第 2 步 · 保持干净

Learn先学

• Trim: send the last few turns and a summary, not the whole history.
• Retrieve, do not paste: search for the two passages that matter instead of pasting the manual.
• Label: mark each part ("Facts:", "Question:") so the model knows which is which.
• Order: put the question last, with the rules near it.

• 裁剪：发最近几轮加一份摘要，不要发整段历史。
• 检索，别粘贴：搜出最相关的两段，而不是把整本手册贴进去。
• 打标签：给每一部分标上“事实：”“问题：”，让模型分得清。
• 排顺序：问题放最后，规则放在它附近。

Sort each one.

给每一项分类。

Step 3 · Sub-agents with their own context第 3 步 · 拥有自己上下文的子智能体

Learn先学

One agent doing everything fills its context with clutter. Instead a main agent delegates: it hands a narrow task to a sub-agent that starts with a fresh, small context, does the work, and returns only a short result.

一个智能体包办一切，上下文会被杂物塞满。更好的做法是主智能体分派任务：把一个窄任务交给子智能体，它从干净的小上下文开始，做完只回传一个简短结果。

In n8n, add an AI Agent Tool node to your main agent. Give each sub-agent one job, the tools for it, and no more.

在 n8n 里，给主智能体加一个 AI Agent Tool 节点。每个子智能体只有一个任务和它需要的工具，不多给。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Context is everything the model sees on this call.
• Choose the smallest context that holds what the answer needs.
• Trim history, retrieve instead of pasting, label the parts.
• A sub-agent works in its own fresh context and returns a short result.
• Use sub-agents when clutter is the problem, not by default.

• 上下文就是模型这次调用看到的一切。
• 选出包含答案所需内容的最小上下文。
• 裁剪历史，检索而不是粘贴，给各部分打标签。
• 子智能体在自己干净的上下文里工作，只回传简短结果。
• 在“杂乱”成问题时才用子智能体，别默认就用。
