Data and APIs数据与接口

Call any web service with the HTTP Request node and shape what comes back · ~12 min · hands-on用 HTTP Request 节点调用任何网络服务，并整理返回的数据 · 约 12 分钟 · 动手做

Step 1 · Call an API第 1 步 · 调用接口

Learn先学

Many apps have no n8n node. Almost all have an API, a web address that answers with JSON. The HTTP Request node calls it for you.

很多应用没有现成的 n8n 节点，但几乎都有 API：一个会用 JSON 回答的网址。HTTP Request 节点就替你去调用它。

• Method: GET reads, POST sends.
• URL: the address of the service.
• Authentication: usually a key in a header; save it as a credential, not in the URL.

• 方法：GET 是读取，POST 是发送。
• URL：服务的地址。
• 认证：通常是请求头里的密钥；存成凭证，不要写进网址。

Method: GET URL: https://api.example.com/v1/rates?base=SGD Auth: Header Auth, name "Authorization", saved as a credential Result: one item with the JSON the service returned

Step 2 · Shape the result第 2 步 · 整理结果

Learn先学

The raw answer is rarely what the next node wants. Use Edit Fields to keep only what you need, an IF node to split paths, and a Code node when you need real logic.

原始返回很少正好是下一个节点要的样子。用 Edit Fields 只留需要的字段，用 IF 节点分路，需要真正的逻辑时再用 Code 节点。

A Code node runs a few lines of JavaScript on every item. $input.all() is all incoming items; you return a new list.

Code 节点会对每个条目运行几行 JavaScript。$input.all() 是所有输入条目，你再返回一个新列表。

// Keep rows over $100 and add a field with the amount in cents. const rows = $input.all().map(item => item.json); const big = rows.filter(r => r.amount > 100); return big.map(r => ({ json: { ...r, cents: Math.round(r.amount * 100) } }));

Step 3 · When the API says no第 3 步 · 接口拒绝时

Learn先学

Every reply carries a status code. Learn the common ones; they tell you what to fix.

每个回复都带一个状态码。认得常见的几个，就知道该修什么。

• 401 / 403: the key is missing or not allowed.
• 404: wrong address or the thing does not exist.
• 429: too many requests; slow down or add a Wait node.
• 500: the service itself failed; retry later.

• 401 / 403：密钥缺失或没有权限。
• 404：地址错了，或者东西不存在。
• 429：请求太多；放慢，或加一个 Wait 节点。
• 500：服务本身出错；稍后重试。

In the node settings turn on Retry On Fail for temporary errors.

在节点设置里为临时性错误打开 Retry On Fail（失败重试）。

Sort each one.

给每一项分类。

Now make it yours现在把它变成你的

Takeaways要点回顾

• The HTTP Request node reaches any service that has an API.
• Keep keys in credentials, never in the URL.
• Edit Fields, IF and Code shape the data for the next step.
• Status codes tell you what to fix: 401 key, 429 rate, 500 retry.
• Turn on retry and add waits for the flaky and the rate-limited.

• HTTP Request 节点能连任何有 API 的服务。
• 密钥放凭证里，不要写进网址。
• Edit Fields、IF 和 Code 把数据整理成下一步要的样子。
• 状态码告诉你该修什么：401 看密钥，429 放慢，500 重试。
• 不稳定或有限速的接口，要开重试并加等待。
