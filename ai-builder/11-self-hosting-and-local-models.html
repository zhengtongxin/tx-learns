Self-hosting and local models自托管与本地模型

Run n8n and a model on your own machine, and know what that costs you · ~13 min · hands-on在自己的电脑上跑 n8n 和模型，并知道这要付出什么 · 约 13 分钟 · 动手做

Step 1 · Why host it yourself第 1 步 · 为什么要自己托管

Learn先学

• Privacy: documents never leave your machine.
• Cost: no per-run fee for the workflow engine, and a local model has no per-token charge.
• Control: you choose versions and limits.

• 隐私：文档不离开你的电脑。
• 成本：工作流引擎没有按次费用，本地模型也不按 token 收费。
• 可控：版本和限制由你决定。

The price: you do the updates, backups and security, and a model that fits on your laptop is weaker than a frontier one. Choose it for a reason, not for fashion.

代价是：更新、备份、安全都由你负责，而且能放进笔记本的模型，比前沿模型弱。要有理由才选它，别图时髦。

Sort each one.

给每一项分类。

Step 2 · Start n8n and a local model第 2 步 · 启动 n8n 和本地模型

Learn先学

Install Docker, then start n8n with one command. A volume keeps your workflows when the container restarts. Install Ollama to download and run open models, then pull one.

安装 Docker，用一条命令启动 n8n。数据卷能让容器重启后工作流还在。安装 Ollama 来下载和运行开源模型，再拉一个模型下来。

Open http://localhost:5678 for n8n. Ollama listens on port 11434.

n8n 在 http://localhost:5678，Ollama 监听 11434 端口。

# start n8n, keeping its data in a volume called n8n_data docker volume create n8n_data docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n # in another terminal: download a small model and try it ollama pull llama3.2 ollama run llama3.2 "Say hello in five words."

Step 3 · Connect them第 3 步 · 把两者连起来

Learn先学

In n8n add an Ollama Chat Model to your agent and create the credential with a base URL. Here is the trap: n8n runs inside a container, so localhost means the container itself, not your computer.

在 n8n 里给智能体接一个 Ollama Chat Model，创建凭证并填写基础地址。这里有个陷阱：n8n 跑在容器里，localhost 指的是容器自己，不是你的电脑。

• n8n in Docker, Ollama on your machine: use http://host.docker.internal:11434.
• Both on the same machine without Docker: use http://localhost:11434.
• Do not expose port 5678 to the internet without HTTPS and a login.

• n8n 在 Docker 里、Ollama 在你的电脑上：用 http://host.docker.internal:11434。
• 两者都在同一台机器上且不用 Docker：用 http://localhost:11434。
• 没有 HTTPS 和登录之前，不要把 5678 端口暴露到互联网。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Self-host for privacy, cost control or control, not for fashion.
• You own updates, backups and security.
• Docker plus a volume runs n8n and keeps your data.
• Ollama runs open models locally; pull one with a single command.
• Inside a container, localhost is the container: use host.docker.internal.

• 为了隐私、成本或可控才自托管，别图时髦。
• 更新、备份和安全由你负责。
• Docker 加数据卷就能跑 n8n 并保住数据。
• Ollama 在本地运行开源模型，一条命令就能拉下来。
• 在容器里 localhost 指容器自己，要用 host.docker.internal。
