Automating with workflows · Lesson 1用工作流自动化 · 第 1 课

Your first AI agent第一个 AI 智能体

Build a chat agent in n8n that can answer and use a tool · ~12 min · hands-on在 n8n 里做出一个会回答、也会用工具的聊天智能体 · 约 12 分钟 · 动手做

Step 1 · Start on the canvas第 1 步 · 先打开画布

Learn先学

n8n is a canvas where you drag boxes called nodes and join them with lines. A trigger node starts the run; every node after it does one job and hands its result on.

n8n 是一块画布：把叫节点的方框拖上去，再用线连起来。触发器节点负责开头，后面每个节点各做一件事，再把结果交给下一个。

The quickest start is n8n Cloud: sign up for the free trial, click Create workflow, and you have an empty canvas. Nothing to install.

最快的起步是 n8n Cloud：注册免费试用，点 Create workflow，就得到一块空白画布。什么都不用装。

Step 2 · Give it a brain and a job第 2 步 · 给它大脑和任务

Learn先学

Click the agent node and plug in a chat model. n8n asks for a credential: paste your model provider's API key once and every workflow can reuse it.

点开智能体节点，接上一个聊天模型。n8n 会要一个凭证：把模型服务商的 API 密钥粘贴一次，之后每个工作流都能复用。

Then write the system message, the standing instructions. Say who it is, what it may do, and when to stop.

再写系统消息，也就是长期有效的指示：它是谁、能做什么、什么时候该停。

You are the front desk helper for a small tuition centre. Answer in two sentences at most. Use the tools when a question needs a calculation or a lookup. If you are not sure, say so. Never guess a fee.

Step 3 · Add a tool and watch it choose第 3 步 · 加一个工具，看它自己选

Learn先学

A tool is a node the agent may call. Add the built-in Calculator, then ask: "What is 18 lessons at $42.50 each, plus 9% GST?"

工具就是智能体可以调用的节点。加上内置的计算器，然后问：“18 节课，每节 42.50 元，再加 9% 消费税是多少？”

• The agent reads the question and decides it needs the Calculator.
• It calls the tool, reads the number, and writes the answer.
• Open the run log to see each step it took.

• 智能体读完问题，判断需要计算器。
• 它调用工具，读到结果，再写出答案。
• 打开运行日志，可以看到它走的每一步。

You did not wire "if maths, use calculator". The model chose. That choice is what makes it an agent.

你没有写“遇到算术就用计算器”。是模型自己选的。这个选择，就是智能体和普通流程的区别。

Sort each one.

给每一项分类。

Now make it yours现在把它变成你的

Takeaways要点回顾

• An n8n workflow is nodes on a canvas: a trigger, then steps.
• The AI Agent node needs a chat model; tools and memory plug in.
• A credential stores an API key once, for every workflow.
• The system message sets the job and the limits.
• An agent chooses its tools; a plain workflow does not.

• n8n 工作流就是画布上的节点：先触发，再一步步做。
• AI Agent 节点需要一个聊天模型，工具和记忆可以接上去。
• 凭证把 API 密钥存一次，所有工作流共用。
• 系统消息规定任务和边界。
• 智能体自己选工具，普通工作流不会。
