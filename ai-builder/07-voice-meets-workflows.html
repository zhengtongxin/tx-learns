Voice meets workflows语音连接工作流

Let a voice agent call an n8n workflow as a tool, and answer in time · ~12 min · hands-on让语音智能体把 n8n 工作流当工具来调用，并及时回答 · 约 12 分钟 · 动手做

Step 1 · A webhook is a door into n8n第 1 步 · Webhook 是进 n8n 的门

Learn先学

A webhook is a web address that starts a workflow when something calls it. Add a Webhook node, set the method to POST, and n8n shows two addresses: a test URL (works while you watch the canvas) and a production URL (works once the workflow is active).

Webhook 是一个网址，有人调用它就会启动工作流。加一个 Webhook 节点，方法选 POST，n8n 会给出两个地址：测试地址（你盯着画布时才有效）和生产地址（工作流启用后才有效）。

The voice agent will call the production URL, so switch the workflow to Active before a real call.

语音智能体调用的是生产地址，所以真通话之前要把工作流切成 Active（启用）。

Step 2 · Define the tool第 2 步 · 定义这个工具

Learn先学

In ElevenLabs add a server tool (a tool that calls a web address). Give it a clear name and description, because that is how the model decides when to use it, then the URL and the fields to send.

在 ElevenLabs 里加一个服务器工具（调用网址的工具）。给它清楚的名称和描述，模型就是靠这个决定什么时候用它；再填网址和要发送的字段。

In n8n, a Respond to Webhook node sends the answer back. Keep it short and plain: the agent will read it aloud.

在 n8n 里，用 Respond to Webhook 节点把答案送回去。保持简短平实，智能体会把它念出来。

// what the voice agent sends to n8n { "question": "Do you have the blue city bike in size M?" } // what the Respond to Webhook node sends back { "answer": "Yes. Two blue city bikes in size M are in stock at 389 dollars." }

Step 3 · Be fast and be safe第 3 步 · 要快，也要安全

Learn先学

• Fast: a caller waits in silence. Keep the workflow under a few seconds; do slow work after replying.
• Short: return one or two plain sentences, not a data dump.
• Safe: anyone who finds the URL can call it. Check a secret in a header, and never return private data.

• 快：来电的人在静默中等待。工作流控制在几秒以内，慢的活放到回复之后再做。
• 短：回一两句平实的话，不要倒出一堆数据。
• 安全：谁找到网址都能调用它。要在请求头里校验一个密钥，也别返回隐私数据。

Tell the agent what to say while it waits, for example "One moment, let me check."

提前告诉智能体等待时说什么，比如“请稍等，我查一下。”

Sort each one.

给每一项分类。

Now make it yours现在把它变成你的

Takeaways要点回顾

• A webhook starts a workflow when a URL is called.
• Use the production URL and activate the workflow for real calls.
• The tool name and description decide when the model calls it.
• Return short plain sentences the agent can speak.
• Keep it fast, and check a secret so strangers cannot call it.

• Webhook 在网址被调用时启动工作流。
• 真通话要用生产地址，并启用工作流。
• 工具的名称和描述决定模型什么时候调用它。
• 返回智能体能直接说的简短平实句子。
• 要快，并校验密钥，免得陌生人也能调用。
