Step 1 · One plug for many tools第 1 步 · 一个插头接很多工具

Learn先学

Every app used to need custom code for every tool. MCP (Model Context Protocol) is an open standard that fixes this. A tool or data source is wrapped once as an MCP server, and any MCP client (an AI app) can use it.

过去每个应用对每个工具都要写专门的代码。MCP（模型上下文协议）是解决这个问题的开放标准：工具或数据源只需包装一次，做成 MCP 服务器，任何 MCP 客户端（AI 应用）都能使用。

Think of a USB-C port: one shape, many devices.

可以把它想成 USB-C 接口：一种形状，接很多设备。

Step 2 · What a server offers第 2 步 · 服务器提供什么

Learn先学

• Tools: actions the model may call, such as "add a row".
• Resources: data it can read, such as a file.
• Prompts: ready-made instructions a person can pick.

• 工具：模型可以调用的动作，比如“添加一行”。
• 资源：它能读取的数据，比如一个文件。
• 提示词：人可以直接选用的现成指示。

The client asks the server what it has, then the model chooses. Each tool carries a name, a plain description and the inputs it needs.

客户端先问服务器有什么，再由模型来选。每个工具都带着名称、一句通俗的描述和所需的输入。

Step 3 · MCP in n8n, and staying safe第 3 步 · n8n 里的 MCP 与安全

Learn先学

• MCP Server Trigger: turns your n8n workflows into tools that apps like Claude can call.
• MCP Client Tool: lets an n8n agent use someone else's MCP server.

• MCP Server Trigger：把你的 n8n 工作流变成 Claude 这类应用可以调用的工具。
• MCP Client Tool：让 n8n 智能体使用别人的 MCP 服务器。

A server can read your data and take actions, so be careful:

服务器可以读你的数据、也能执行动作，所以要小心：

• Install only servers you trust, and give each the smallest access it needs.
• Keep a person in the loop for anything that writes, sends or deletes.
• Text a tool returns can contain hostile instructions. Treat it as data, not orders.

• 只装你信任的服务器，每个只给它需要的最小权限。
• 凡是会写入、发送、删除的动作，都留一个人来把关。
• 工具返回的文字里可能藏着恶意指令，把它当数据，不要当命令。

Sort each one.

给每一项分类。

Now make it yours现在把它变成你的

Takeaways要点回顾

• MCP is a standard plug between AI apps and tools or data.
• A server offers tools, resources and prompts.
• A client discovers them, and the model chooses.
• n8n can act as an MCP server and as an MCP client.
• Trust little, grant little, keep a person on risky actions.

• MCP 是 AI 应用与工具、数据之间的标准插头。
• 服务器提供工具、资源和提示词。
• 客户端发现它们，由模型来选择。
• n8n 既可以当 MCP 服务器，也可以当 MCP 客户端。
• 少信任、少授权，高风险动作留人把关。
