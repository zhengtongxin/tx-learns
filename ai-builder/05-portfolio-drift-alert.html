Portfolio drift alert持仓偏离提醒

Check a portfolio every weekday and send a plain alert when a holding drifts too far · ~30 min · project每个工作日检查一次持仓，某项偏离太多就发一条通俗的提醒 · 约 30 分钟 · 项目

Step 1 · Write the rule as code第 1 步 · 把规则写成代码

Learn先学

Money maths belongs in code, not in a model. A model can slip on a decimal; a function cannot. Start with the rule: a holding's weight is its value divided by the total, and its gap is the weight minus its target.

涉及钱的算术要交给代码，不要交给模型。模型可能错一个小数点，函数不会。先定规则：持仓的占比是它的价值除以总价值，偏差是占比减去目标占比。

Alert only when the gap is bigger than a limit, for example 5 points. Otherwise you will be told something every day.

只有偏差超过阈值（比如 5 个百分点）才提醒，否则你每天都会收到消息。

// How far each holding has drifted from its target share. // holdings: [{ symbol, qty, price }] targets: { symbol: share between 0 and 1 } function drift(holdings, targets) { const total = holdings.reduce((sum, h) => sum + h.qty * h.price, 0); return holdings.map(h => { const weight = total === 0 ? 0 : (h.qty * h.price) / total; const target = targets[h.symbol] ?? 0; return { symbol: h.symbol, weight: round(weight), target, gap: round(weight - target), trade: Math.round((target - weight) * total), // + buy, - sell, in dollars }; }); } function round(x) { return Math.round(x * 1000) / 1000; } // Only the rows whose gap is bigger than the limit (for example 0.05 = 5 points). function breaches(rows, limit) { return rows.filter(r => Math.abs(r.gap) > limit); }

Step 2 · Wire the daily workflow第 2 步 · 接好每日工作流

Learn先学

Four nodes: a Schedule Trigger (weekdays, 8 am, set the workflow time zone to Asia/Singapore), a node that provides the holdings, a Code node that runs the rule, and a Message node that words the result.

四个节点：Schedule Trigger（工作日早上 8 点，工作流时区设为 Asia/Singapore）、提供持仓的节点、运行规则的 Code 节点，以及写出结果的 Message 节点。

The Code node returns no items when nothing breaches the limit. n8n then stops the run, so a quiet day sends nothing.

没有任何一项超过阈值时，Code 节点就不返回条目。n8n 随即结束这次运行，所以平静的一天什么都不会发。

Step 3 · Let AI word it, never compute it第 3 步 · 让 AI 只写措辞，不做计算

Learn先学

Add one AI step after the check. It receives the finished numbers and writes two plain sentences. It may not change, add or round any figure.

在检查之后加一个 AI 步骤。它拿到算好的数字，写两句通俗的话，不许改动、增加或四舍五入任何数字。

Send the result to Telegram (create a bot with @BotFather and note the chat id) or Gmail. Keep it an alert: the workflow never trades. A person decides.

把结果发到 Telegram（用 @BotFather 创建机器人并记下 chat id）或 Gmail。它只是提醒：工作流绝不下单，由人来决定。

Takeaways要点回顾

• Put exact maths in code; let the model write only the words.
• Alert on a limit, so quiet days stay quiet.
• Returning no items ends an n8n run cleanly.
• Set the workflow time zone so 8 am means your 8 am.
• The workflow alerts; a person decides about money.

• 精确算术放代码里，模型只写文字。
• 设一个阈值再提醒，平静的日子就保持安静。
• 不返回条目，n8n 就干净地结束这次运行。
• 设好工作流时区，8 点才是你的 8 点。
• 工作流负责提醒，涉及钱由人决定。
