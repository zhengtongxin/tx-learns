Step 1 · Prepare and ingest the sheet第 1 步 · 整理并入库产品资料

Learn先学

Write a short product sheet in plain text: one ## heading per product or policy, then facts in short sentences. A good sheet is the biggest quality lever you have.

写一份简短的产品资料，纯文字：每个产品或政策一个 ## 标题，下面用短句写事实。资料写得好，是影响质量最大的一个杠杆。

Chunk it by heading and put the title at the front of each chunk, so a chunk like "Warranty is 2 years" still says which product it is about. Then embed and store the chunks as in lesson 9.

按标题切块，并把标题放在每块的开头，这样“保修 2 年”这样的块仍然知道说的是哪个产品。然后像第 9 课那样嵌入并存储。

// Cut a markdown product sheet into chunks, one section at a time. // Each chunk starts with its section title, so it still makes sense on its own. function chunkMarkdown(md, maxChars = 500) { const sections = md.split(/^## /m).slice(1); // drop anything before the first "## " const chunks = []; for (const section of sections) { const [title, ...rest] = section.split('\n'); const body = rest.join(' ').replace(/\s+/g, ' ').trim(); if (!body) continue; let current = ''; for (const sentence of body.split(/(?<=[.!?])\s+/)) { if (current && (title + ': ' + current + ' ' + sentence).length > maxChars) { chunks.push({ title, text: title + ': ' + current }); current = ''; } current += (current ? ' ' : '') + sentence; } if (current) chunks.push({ title, text: title + ': ' + current }); } return chunks; }

Step 2 · Build the lookup workflow第 2 步 · 做查询工作流

Learn先学

Four nodes after the webhook: embed the question, call match_documents for the top three chunks, join them into one short answer, and respond. Facts only: the voice agent will turn them into speech.

webhook 之后四个节点：嵌入问题，调用 match_documents 取前三块，合并成一段简短答案，再回应。只给事实：由语音智能体把它说成话。

Drop weak matches. If nothing is close enough, return "No information found" and let the agent say so.

把匹配度低的丢掉。如果没有足够接近的，就返回“没有相关信息”，让智能体如实告知。

Step 3 · Connect the voice agent and test第 3 步 · 接上语音智能体并测试

Learn先学

In ElevenLabs add a server tool that posts the question to your production webhook. Then write the rules into the system prompt: answer only from the tool, keep it to two sentences, and when the tool finds nothing, say so and offer to take a message.

在 ElevenLabs 里加一个服务器工具，把问题 POST 到你的生产 webhook。再把规则写进系统提示词：只依据工具回答，限两句话，工具查不到时要如实说，并主动提出记下留言。

Then make test calls: easy questions, a product you do not stock, and a question that changes mid-sentence. Fix the sheet before you fix the prompt.

然后打测试电话：简单问题、你没进的产品，以及说到一半改口的问题。先改资料，再改提示词。

You are the phone helper for Tampines Cycle Works. For any product, price, stock, repair or policy question, call the lookup tool first. Answer only from what the tool returns, in two short sentences. If the tool says no information was found, say so, then offer to take a name and number. Never guess a price, a date or a warranty.

Sort each one.

给每一项分类。

Takeaways要点回顾

• Write the sheet in short facts, one heading per topic.
• Prefix every chunk with its title so it stands alone.
• The workflow fetches facts; the voice agent does the talking.
• Drop weak matches and say "no information" honestly.
• Fix the sheet first, the prompt second.

• 资料用短句写事实，每个主题一个标题。
• 每个块以标题开头，单独也说得通。
• 工作流负责取事实，语音智能体负责说话。
• 丢掉弱匹配，并诚实地说“没有相关信息”。
• 先改资料，再改提示词。
