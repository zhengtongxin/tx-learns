Step 1 · Four layers第 1 步 · 四层

Learn先学

Like a hawker centre: building and gas, cook, stall, plate. The AI world stacks the same way.

• Layer 1, chips and cloud: the machines that train and run models.
• Layer 2, models: text, images, speech, code.
• Layer 3, tools and platforms: stitch a model to your data.
• Layer 4, applications: finished products people use.

像小贩中心：大楼和煤气、厨师、摊位、那盘饭。AI 世界也是这样叠起来的。

• 第 1 层，芯片与云：训练和运行模型的机器。
• 第 2 层，模型：文字、图像、语音、代码。
• 第 3 层，工具与平台：把模型缝到你的数据上。
• 第 4 层，应用：人们直接用的成品。

Place each product on its layer.

把每个产品放到它所在的层。

Step 2 · Six words, in plain words第 2 步 · 六个词，大白话

• LLM: predicts the next piece of text, like a very well-read autocomplete.
• Multimodal: also reads images or audio.
• Embeddings: text as numbers, so similar things sit close together.
• Retrieval (RAG): look up the facts first, then answer.
• Fine-tuning: extra training on your own examples.
• Agent: a model that uses a tool, checks the result and repeats.

• 大语言模型（LLM）：预测下一段文字，像读书极多的自动补全。
• 多模态：还能看图或听音频。
• 嵌入（embeddings）：把文字变成数字，让相似的东西靠得近。
• 检索（RAG）：先查资料再回答。
• 微调：用你自己的例子再训练一遍。
• 智能体：调用工具、看清结果、重复的模型。

Step 3 · A buying question points to a layer第 3 步 · 采购问题会指向某一层

Learn先学

"Which model?" is layer 2. "How do we connect it to our files?" is layer 3. "Can we just buy something?" is layer 4. Layer 1 you usually rent and never see. Names change monthly; the layers hardly move, so place each new name on a layer. "Open" model does not mean free: running it costs machines and people.

“用哪个模型？”是第 2 层。“怎么接上我们的文件？”是第 3 层。“能不能直接买个现成的？”是第 4 层。第 1 层通常是租的，你看不到。名字每月换，层几乎不动，所以给每个新名字找到它的层。“开放”模型不等于免费：运行它要机器和人。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Four layers: chips and cloud, models, tools and platforms, applications.
• Models are closed (sold by an API) or open (you can run them); open is not free.
• Retrieval, agents and workflow builders all live at layer 3.
• Names change monthly. The layers change slowly.

• 四层：芯片与云、模型、工具与平台、应用。
• 模型分闭源（通过 API 出售）和开放（可自己运行）；开放不等于免费。
• 检索、智能体和流程搭建器都在第 3 层。
• 名字每个月换，层变得很慢。
