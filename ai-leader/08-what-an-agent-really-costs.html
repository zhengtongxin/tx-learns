True cost of an agent智能体的真实成本

Cost an agent per task and name its risks before you say yes · ~7 min · decisions, no code在点头之前，按每个任务算出智能体的成本，并说清它的风险 · 约 7 分钟 · 做决定，不写代码

Step 1 · Cost per task, not a monthly fee第 1 步 · 看每个任务的成本，不看月费

Learn先学

An agent is an AI that takes many steps by itself to finish a job, and every step is a paid call to the model. “Model fee: S$180 a month” is one slice of five:

• Model usage
• Tools and data access
• Build time
• Checking time (people who review its work)
• Running and monitoring

Ask for the cost per task, as an average and as a worst case. An agent that retries a failing step keeps paying for each try, so a few cents can become several dollars on one stuck invoice. Cost the same task done by hand, mistakes included, to compare fairly.

智能体是自己走很多步去完成一件事的 AI，每一步都是一次付费调用。“模型费用：每月 S$180”只是五块中的一块：

• 模型使用
• 工具和数据接入
• 搭建时间
• 检查时间（审阅它工作的人）
• 运行和监控

要问每个任务的成本，既要平均值，也要最坏情况。智能体对失败的步骤反复重试，每试一次都在付钱，所以一张卡住的发票，几分钱就可能变成几新元。再把同一个任务用人工做的成本也算出来（包括错误），才能公平比较。

Step 2 · What can go wrong, and what stops it第 2 步 · 会出什么错，什么能拦住

Learn先学

Name five risks: it loops, takes a wrong action, is tricked by hostile text hidden in a document, leaks data, or quietly gets worse. Four controls cover most of them:

• a step and spend limit per task
• read-only access first, and only the records the job needs
• a person's approval before anything that cannot be undone
• a regular test set of questions with known answers, plus logs you can read

点名五种风险：它会循环、做错动作、被文件里藏的恶意文字骗到、泄露数据，或悄悄变差。四种控制能管住大部分：

• 每个任务的步数和花费上限
• 先只读，只开放这份工作需要的记录
• 任何无法撤销的事先由人批准
• 一套有标准答案的定期测试集，加上看得懂的日志

Now make it yours现在轮到你

Takeaways要点回顾

• An agent's cost has five parts: model usage, tools and data, build time, checking time and running.
• Ask for cost per task, average and worst case, not only a monthly fee.
• A retry loop can turn a few cents into several dollars.
• Cap steps and spend, start read-only, and keep a person on anything that cannot be undone.
• Compare with the same task by hand, mistakes included.

• 智能体的成本有五部分：模型使用、工具和数据、搭建时间、检查时间和运行。
• 要每个任务的成本，要平均和最坏情况，不能只看月费。
• 重试循环能把几分钱变成几新元。
• 限制步数和花费，先只读，无法撤销的事一律由人把关。
• 和同一个任务的人工做法对比，错误也算进去。
