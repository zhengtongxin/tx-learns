Agent SDKs · Lesson 2智能体 SDK · 第 2 课

Tools, handoffs, guardrails工具、交接与护栏

One agent becomes a small team, with checks at the door · ~25 min · hands-on一个智能体变成一支小团队，门口还有安检 · 约 25 分钟 · 动手实践

Step 1 · An agent as a tool第 1 步 · 把智能体当工具

Learn先学

Example: Fern, the help desk agent of an online plant shop. Instead of stuffing plant knowledge into Fern's prompt, build a separate Plant Doctor agent and give it to Fern with .as_tool(). It is like asking a colleague: you get an answer, then you keep talking to the customer.

示例：网上植物店的客服智能体 Fern。不要把植物知识塞进 Fern 的提示词，而是单独做一个 Plant Doctor 智能体，用 .as_tool() 交给 Fern。就像问同事：拿到答案后，还是你继续和顾客说话。

from agents import Agent, Runner plant_doctor = Agent( name="Plant Doctor", instructions="Diagnose a houseplant from its symptoms. Two sentences: the likely cause, then one fix.", model="gpt-5.4-mini") fern = Agent( name="Fern", instructions="You are the help desk of a plant shop. Be warm and brief. For sick plants, ask plant_doctor, then answer in your own words.", model="gpt-5.4-mini", tools=[plant_doctor.as_tool( tool_name="plant_doctor", tool_description="Diagnose a sick houseplant from a description of its symptoms")]) result = await Runner.run(fern, "My monstera has yellow leaves with brown tips")

Step 2 · A handoff, and which to use第 2 步 · 交接，以及怎么选

Learn先学

For refunds, a Returns Desk agent should own the whole chat. List it in handoffs: when the model picks it, the SDK makes it the active agent. That is transferring the phone call, not asking a colleague. To tell the two apart ask: who talks to the customer next? The first agent still talking means a tool; the second agent taking over means a handoff.

退款时，应由 Returns Desk 智能体接管整段对话。把它写进 handoffs：模型选中它时，SDK 就让它成为当前智能体。这是把电话转过去，而不是问同事。分辨两者只需问：接下来谁和顾客说话？第一个智能体继续说是工具；第二个智能体接手是交接。

returns_desk = Agent( name="Returns Desk", handoff_description="Handles refunds and returns for damaged or wrong orders", instructions="You handle returns. Ask for the order number, then explain the next step.", model="gpt-5.4-mini") fern = Agent(name="Fern", ..., tools=[...], handoffs=[returns_desk]) result = await Runner.run(fern, "My pot arrived cracked. I want my money back.") print(result.last_agent.name) # who gave the final answer: Returns Desk

Step 3 · Guardrails第 3 步 · 护栏

Learn先学

A guardrail is a check that can stop a run. An input guardrail checks the customer's message before Fern replies; an output guardrail checks the final answer before the customer sees it. Each returns GuardrailFunctionOutput; if tripwire_triggered is true, the SDK raises an exception you catch.

护栏是能叫停运行的检查。输入护栏在 Fern 回复之前检查顾客的消息；输出护栏在顾客看到之前检查最终回答。两者都返回 GuardrailFunctionOutput；tripwire_triggered 为真时，SDK 抛出异常，由你捕获。

import re from agents import (input_guardrail, output_guardrail, GuardrailFunctionOutput, InputGuardrailTripwireTriggered) @input_guardrail async def no_card_numbers(ctx, agent, message): found = bool(re.search(r"\d(?:[ -]?\d){12,15}", str(message))) return GuardrailFunctionOutput(output_info={"card_number": found}, tripwire_triggered=found) @output_guardrail async def no_discount_promises(ctx, agent, output): # deliberately simple promised = "discount" in str(output).lower() return GuardrailFunctionOutput(output_info={"discount": promised}, tripwire_triggered=promised) fern = Agent(name="Fern", ..., input_guardrails=[no_card_numbers], output_guardrails=[no_discount_promises]) try: result = await Runner.run(fern, "Charge 4111 1111 1111 1111 for two ferns") except InputGuardrailTripwireTriggered: print("Please never share card numbers in chat. Use the checkout page.")
Where they run在哪里运行

Input guardrails run only on the first agent, output guardrails only on the agent giving the final answer. Put them on the front-door agent, not on helpers.

输入护栏只在第一个智能体上运行，输出护栏只在给出最终回答的智能体上运行。装在“前台”智能体上，不要装在帮手身上。

Now make it yours现在把它变成你的

Takeaways要点回顾

• agent.as_tool(...) turns an agent into a tool; the caller stays in charge.
• handoffs=[other] passes the whole conversation on; result.last_agent says who answered.
• Tool or handoff? Ask who talks to the user next.
• A guardrail trips by raising an exception you catch.
• Input guardrails run on the first agent, output guardrails on the one giving the final answer.

• agent.as_tool(...) 把智能体变成工具，调用者继续掌控。
• handoffs=[other] 把整段对话交出去，result.last_agent 告诉你是谁回答的。
• 工具还是交接？问接下来谁和用户说话。
• 护栏触发时会抛出异常，由你捕获。
• 输入护栏在第一个智能体上运行，输出护栏在给出最终回答的智能体上运行。
