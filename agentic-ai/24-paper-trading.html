Paper-trading simulation模拟交易

Watch autonomous agents trade pretend money and learn from the result · ~60 min · project看自主的智能体用模拟的钱做交易，并从结果中学习 · 约 60 分钟 · 项目

Key point要点

A whole system can be built from MCP servers (small programs that offer tools to an agent) plus agents on a timer. Here four agent “uncles” each trade S$10,000 of pretend money on four made-up tickers (a ticker is the short code for a share, such as KOPI), with different written strategies (steady, news-chasing, charts, contrarian). Watch the agents and the feedback loop; this is play money only.

一整个系统可以由 MCP 服务端（向智能体提供工具的小程序）加定时运行的智能体搭成。这里四位智能体“大叔”各拿 1 万新元的模拟资金，在四个虚构的股票代码（一只股票的简短代号，比如 KOPI）上交易，各有不同的书面策略（稳健、追新闻、看图表、反向）。重点是观察智能体和反馈循环；这只是玩具资金。

Step 1 · The floor is three MCP servers第 1 步 · 交易所是三个 MCP 服务端

Learn先学
  • The floor is the trading room: the folder floor/ that holds the three servers and the uncles.
  • The accounts server (your own server, written with the FastMCP helper) holds cash, shares and each uncle's strategy.
  • The market server gives prices from a simulator: a slow, smooth made-up price function, so two calls a second apart do not jump. Swap in a real provider later without touching any uncle.
  • The push server has one tool that pings your phone.
  • 交易所就是交易大厅：文件夹 floor/，里面放着三个服务端和几位大叔。
  • 账户服务端（你自己用 FastMCP 这个辅助库写的服务端）保存现金、持股和每位大叔的策略。
  • 行情服务端用模拟器给出价格：一个缓慢平滑的虚构价格函数，所以相隔一秒的两次调用不会大跳。以后可换成真实数据源，不用动任何大叔。
  • 推送服务端只有一个工具：给你的手机发提醒。
# floor/market.py: made-up prices that move slowly import math, time BASE = {"KOPI": 10.0, "ROTI": 5.0, "TEHT": 8.0, "NASI": 12.0} def get_price(symbol: str) -> float: t = time.time() / 600 seed = sum(map(ord, symbol)) # each ticker gets its own wave wave = math.sin(t + seed) * 0.6 + math.sin(t * 2.3 + seed * 1.7) * 0.3 return round(BASE[symbol] * (1 + 0.08 * wave), 2)
# floor/accounts_server.py import json, os from mcp.server.fastmcp import FastMCP from floor.market import get_price mcp = FastMCP("accounts") DB = "accounts.json" # a file, so cash survives between runs STRATEGIES = { "Wong": "Buy only solid, boring companies and hold them.", "Muthu": "Chase whatever is in the news.", "AhKow": "Trade on chart patterns.", "Hamid": "Buy what everyone else is selling.", } class Account: def __init__(self, name, data=None): self.name = name d = data or {"cash": 10000.0, "holdings": {}, "trades": [], "strategy": STRATEGIES[name]} self.__dict__.update(d) @classmethod def get(cls, name): data = json.load(open(DB)) if os.path.exists(DB) else {} return cls(name, data.get(name)) def save(self): data = json.load(open(DB)) if os.path.exists(DB) else {} data[self.name] = {k: getattr(self, k) for k in ("cash", "holdings", "trades", "strategy")} json.dump(data, open(DB, "w")) def buy(self, symbol, qty, price): if qty * price > self.cash: return "Not enough cash" self.cash -= qty * price self.holdings[symbol] = self.holdings.get(symbol, 0) + qty self.trades.append({"side": "buy", "symbol": symbol, "qty": qty, "price": price}) self.save() return f"Bought {qty} {symbol} at S${price}" def set_strategy(self, text): self.strategy = text self.save() return "Strategy updated" @mcp.tool() async def buy_shares(name: str, symbol: str, qty: int) -> str: """Buy shares at the current price from this account's cash. Fails if cash is short.""" return Account.get(name).buy(symbol, qty, get_price(symbol)) @mcp.tool() async def past_trades(name: str) -> dict: """This uncle's last 10 trades, what he owns is worth now, and his profit against the S$10,000 start.""" a = Account.get(name) worth = a.cash + sum(qty * get_price(sym) for sym, qty in a.holdings.items()) return {"trades": a.trades[-10:], "worth": round(worth, 2), "profit": round(worth - 10000, 2)} # sell_shares is buy_shares in reverse: add the cash, take away the shares if __name__ == "__main__": mcp.run(transport="stdio")
# floor/market_server.py from mcp.server.fastmcp import FastMCP from floor.market import get_price mcp = FastMCP("market") @mcp.tool() async def lookup_price(symbol: str) -> float: """Latest price of a ticker, in S$.""" return get_price(symbol) if __name__ == "__main__": mcp.run(transport="stdio") # floor/push_server.py: one tool, same shape (ends with the same mcp.run) import os, requests mcp = FastMCP("push") @mcp.tool() async def push(message: str) -> str: """Send a short note to my phone, e.g. after a trade.""" r = requests.post("https://api.pushover.net/1/messages.json", data={ "user": os.getenv("PUSHOVER_USER"), "token": os.getenv("PUSHOVER_TOKEN"), "message": message}) return "sent" if r.ok else "failed"

Step 2 · One uncle, one researcher, a timer第 2 步 · 一位大叔、一位研究员、一个定时器

Learn先学
  • Each uncle is an agent whose tools come from the three servers. His researcher is another agent with two ready-made servers: one fetches a web page, the other is Tavily, a web search service that needs its own key (TAVILY_API_KEY) and is filtered down to its one search tool. The researcher is handed over as a tool with as_tool, so the uncle stays in charge.
  • In the code, create_static_tool_filter is what keeps only the search tool. AsyncExitStack opens servers in a loop and closes them all, even on failure. max_turns=30 stops a runaway run.
  • asyncio.gather runs all four at once, then the floor sleeps. Watch the cost: four traders, each with a researcher, every N minutes adds up while you sleep.
  • 每位大叔都是一个智能体，工具来自这三个服务端。他的研究员是另一个智能体，带两个现成的服务端：一个抓取网页，另一个是 Tavily，一项需要单独密钥（TAVILY_API_KEY）的网页搜索服务，并且过滤到只剩一个搜索工具。研究员用 as_tool 作为工具交给他，所以大叔始终是主导。
  • 代码里的 create_static_tool_filter 负责只留下搜索工具。AsyncExitStack 循环打开服务端，最后统一关闭，失败时也一样。max_turns=30 防止失控。
  • asyncio.gather 让四位同时运行，然后交易所休眠。留意成本：四位交易员各带研究员，每 N 分钟一次，你睡觉时费用也在涨。
import asyncio, os from contextlib import AsyncExitStack from agents import Agent, Runner, trace from agents.mcp import MCPServerStdio, create_static_tool_filter from floor.accounts_server import STRATEGIES import floor.tracing # Step 3: importing it switches the per-uncle log on STRATEGY_NOTE = "Look at how your past trades actually performed, and update your strategy if the results say you should." only_search = create_static_tool_filter(allowed_tool_names=["tavily_search"]) def trader_servers(): mods = ["accounts_server", "push_server", "market_server"] return [MCPServerStdio({"command": "uv", "args": ["run", "-m", f"floor.{m}"]}, client_session_timeout_seconds=120) for m in mods] def researcher_servers(): return [MCPServerStdio({"command": "uvx", "args": ["mcp-server-fetch"]}, client_session_timeout_seconds=120), MCPServerStdio({"command": "npx", "args": ["-y", "tavily-mcp@latest"], "env": {"TAVILY_API_KEY": os.getenv("TAVILY_API_KEY")}}, tool_filter=only_search, client_session_timeout_seconds=120)] async def run_uncle(name: str, model: str = "gpt-4o-mini"): async with AsyncExitStack() as stack: t_srv = [await stack.enter_async_context(s) for s in trader_servers()] r_srv = [await stack.enter_async_context(s) for s in researcher_servers()] researcher = Agent(name="Researcher", model=model, mcp_servers=r_srv, instructions="Research the ticker you are asked about: news first, then context. Reply in three lines.") uncle = Agent(name=name, model=model, mcp_servers=t_srv, instructions=f"{STRATEGIES[name]} Trade only KOPI, ROTI, TEHT, NASI. Never guess prices. {STRATEGY_NOTE}", tools=[researcher.as_tool(tool_name="Researcher", tool_description="Research news and prices for a ticker")]) with trace(f"{name}-trading"): # Step 3 adds a trace_id here await Runner.run(uncle, f"You are {name}. Check your account, trade if it is worthwhile, then push a short note.", max_turns=30) async def floor(): while True: await asyncio.gather(*(run_uncle(n) for n in STRATEGIES)) await asyncio.sleep(int(os.getenv("RUN_EVERY_N_MINUTES", "60")) * 60) if __name__ == "__main__": asyncio.run(floor())

Step 3 · Trace each uncle, let him learn第 3 步 · 追踪每位大叔，让他学习

Learn先学
  • Four agents at once make a messy log. A custom TracingProcessor is called for every span (an agent step, tool call or model call). Put the uncle's name inside the trace_id so every span traces back to its owner.
  • The learning loop: change_strategy lets an uncle rewrite his own strategy after reviewing past_trades. past_trades also returns what the account is worth now and the profit against the S$10,000 start. That number is real feedback, so a fixed prompt becomes a loop that learns.
  • 四个智能体同时跑，日志会很乱。自定义的 TracingProcessor 会在每个 span（智能体的一步、工具调用或模型调用）时被调用。把大叔的名字放进 trace_id，每个 span 就能追溯到主人。
  • 学习循环：change_strategy 让大叔在查看 past_trades 之后改写自己的策略。past_trades 还会返回账户现在值多少钱，以及相对 1 万新元起始资金的盈亏。这个数字是真实的反馈，固定的提示词于是变成会学习的循环。
# add to floor/accounts_server.py, above the mcp.run line @mcp.tool() async def change_strategy(name: str, new_strategy: str) -> str: """Replace this uncle's written strategy. Use it only after reviewing real results.""" return Account.get(name).set_strategy(new_strategy) # floor/tracing.py import secrets from agents import TracingProcessor, add_trace_processor from floor.db import write_log # a small helper that inserts a row into SQLite def make_trace_id(tag): # "trace_" + 32 chars; the name rides in front return "trace_" + (tag + "0" + secrets.token_hex(16))[:32] # make_trace_id("wong") gives "trace_wong0a3f9...": the name, a 0 as the divider, then random letters. # Change the line in run_uncle to: with trace(f"{name}-trading", trace_id=make_trace_id(name.lower())): class FloorLog(TracingProcessor): def _who(self, x): # trace ids look like trace_<name>0<random> tag = x.trace_id.split("_")[1] return tag.split("0")[0] if "0" in tag else None def on_span_start(self, s): if (w := self._who(s)) and s.span_data: write_log(w, s.span_data.type, f"start {getattr(s.span_data, 'name', '')}") def on_trace_start(self, t): pass def on_trace_end(self, t): pass def on_span_end(self, s): pass def shutdown(self): pass def force_flush(self): pass add_trace_processor(FloorLog())

Takeaways要点回顾

• One MCP server per job (accounts, prices, push), one agent per uncle.
• A simulator behind the market server can be swapped for real data without touching the agents.
• A researcher is handed to the trader as a tool, so the trader stays in charge.
• A custom TracingProcessor plus the name in the trace id gives a log per agent.
• Real results fed back make a loop that learns. Timers cost money while you sleep, and this is pretend money only.

• 每项工作一个 MCP 服务端（账户、价格、推送），每位大叔一个智能体。
• 行情服务端背后的模拟器可换成真实数据，不用动智能体。
• 研究员作为工具交给交易员，交易员始终是主导。
• 自定义 TracingProcessor 加上 trace id 里的名字，就得到每个智能体各自的日志。
• 真实结果回流就成了会学习的循环。定时器在你睡觉时也在花钱，而且这只是模拟资金。
