Step 2 · One code shape, three swaps第 2 步 · 同一种代码，只换三样

Learn先学

Almost every provider has an endpoint (the web address your code sends requests to) that speaks OpenAI's language. Reuse the same OpenAI client and change only three values: the key (whose account pays), the base_url (where the request goes) and the model name (which brain answers). Keys come from an environment variable, a named setting kept outside your code (usually loaded from a .env file with load_dotenv()).

几乎每家厂商都有说 OpenAI 那套“语言”的接口（endpoint，你的代码发送请求的网址）。复用同一个 OpenAI 客户端，只改三个值：密钥（谁的账户付费）、base_url（请求发往哪里）和模型名（由哪个模型回答）。密钥来自环境变量（保存在代码之外、带名字的设置，通常用 load_dotenv() 从 .env 文件加载）。

import os from openai import OpenAI client = OpenAI(api_key=os.getenv("OPENAI_API_KEY")) response = client.chat.completions.create( model="gpt-5.4-nano", messages=messages) answer = response.choices[0].message.content

Local models本地模型

Ollama runs a model on your laptop: free, private, offline. After installing it from ollama.com, run ollama pull llama3.2. localhost:11434 is your own machine's port (a numbered door) for Ollama. Pick models of about 3 GB or less; avoid names ending in :cloud, which are hosted.

Ollama 在你的笔记本上运行模型：免费、私密、可离线。从 ollama.com 安装后，运行 ollama pull llama3.2。localhost:11434 是你自己电脑上 Ollama 的端口（带编号的“门”）。选 3 GB 左右或更小的模型；避开以 :cloud 结尾的名称，那是托管服务。

ollama = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama") # key is a placeholder ollama.chat.completions.create(model="llama3.2", messages=messages)

Step 3 · A model judges the rest第 3 步 · 让模型当裁判

Learn先学

Send one question to several models, then ask a strong model to rank the answers. Writing the question with one call and feeding it to the next is prompt chaining; asking every model independently is parallelization. The judge must reply in strict JSON (plain text of labels and values, like {"best": 2}) so code can read it. Step through the script.

把一个问题发给多个模型，再让强模型给回答排名。用一次调用写出问题再喂给下一次是提示链；让每个模型独立作答是并行化。裁判必须返回严格的 JSON（由标签和值组成的纯文本，如 {"best": 2}），代码才能读取。一步步走一遍脚本。

Be the judge yourself, on clarity and strength of argument. Three answers to “Which matters more to a society, truth or trust?”:

先自己当裁判，标准是表达清晰度和论证力度。对“对一个社会来说，真相和信任哪个更重要？”的三个回答：

#1 Both matter and it really depends on the situation and many factors.
#2 Trust. A truth nobody believes changes nothing, while trust lets a society keep finding and correcting its mistakes.
#3 Truth, because trust built on lies eventually collapses.

#1 两者都重要，这真的取决于具体情况和许多因素。
#2 信任。没人相信的真相改变不了什么，而信任能让社会不断发现并纠正自己的错误。
#3 真相，因为建立在谎言上的信任终将崩塌。

import json # the whole script, continuing from step 2: client is already created def ask(prompt, model): r = client.chat.completions.create(model=model, messages=[{"role": "user", "content": prompt}]) return r.choices[0].message.content question = ask("Write one hard, open question about society. Reply with only the question.", "gpt-5.4-mini") competitors = ["gpt-5.4-nano", "gpt-5.4-mini"] # model names answers = [ask(question, name) for name in competitors] # replies, in the same order together = "" for number, answer in enumerate(answers, start=1): together += f"# Response from competitor {number}\n\n{answer}\n\n" judge = f"""Rank these {len(answers)} competitors by clarity and strength of argument for this question: {question} {together} Reply only with JSON, best first, like {{"results": ["2", "1"]}}.""" reply = ask(judge, "gpt-5.4") # the judge's JSON, e.g. {"results": ["2", "1"]} results = json.loads(reply)["results"] # JSON text -> a Python list winner = competitors[int(results[0]) - 1] print(winner)
Know the limits了解局限A judge is one more model, so its ranking is an opinion. Use a strong model, hide who wrote what, and spot-check.裁判也是一个模型，排名只是一种意见。用强模型，隐藏回答者身份，并抽查结果。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Match size to the job: small for volume, large for hard thinking, local for privacy.
• Switching providers means changing the key, base_url and model name.
• Ollama runs the same client against your own machine.
• Ask a judge for JSON so your code can read the ranking.

• 按任务选大小：量大用小模型，难题用大模型，隐私用本地模型。
• 换厂商只需改密钥、base_url 和模型名。
• Ollama 用同一个客户端指向你自己的电脑。
• 让裁判返回 JSON，代码才能读取排名。
