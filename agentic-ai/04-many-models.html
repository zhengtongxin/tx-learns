One code shape, three swaps同一种代码，只换三样

Almost every provider offers an endpoint (the web address your code sends its requests to) that speaks the same language as OpenAI. So you reuse the same OpenAI client and only change where it points. Click a provider.

几乎每家厂商都提供与 OpenAI 说同一种“语言”的接口（endpoint，也就是你的代码发送请求的网址）。所以你可以复用同一个 OpenAI 客户端，只改它指向的地址。点一个厂商看看。

Why can one OpenAI client talk to Anthropic, Gemini, DeepSeek and Groq?为什么同一个 OpenAI 客户端能调用 Anthropic、Gemini、DeepSeek 和 Groq？

The request format is the same, so the address, the key and the model name are the only things you swap.请求格式相同，所以只需替换地址、密钥和模型名。

Run a model on your own machine在自己的电脑上运行模型

Ollama is the same trick with the server on your laptop: free, private and offline. Step through the setup.

Ollama 用的是同样的办法，只是服务器就在你的笔记本上：免费、私密、可离线。逐步看一遍安装流程。

1

Install Ollama安装 Ollama

Download it from ollama.com and run the installer.

从 ollama.com 下载并运行安装程序。

2

Download a small model下载一个小模型

ollama pull llama3.2

Other handy commands: ollama ls lists your models, ollama rm <name> deletes one.

其他常用命令：ollama ls 列出已有模型，ollama rm <名称> 删除模型。

3

Check it is running确认它在运行

Open http://localhost:11434. You should see “Ollama is running”. If not, run ollama serve in a terminal.

打开 http://localhost:11434，应当看到 “Ollama is running”。如果没有，在终端运行 ollama serve。

4

Call it like any other provider像调用其他厂商一样调用它

ollama = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

Mind the size注意大小Many Ollama models are far too big for a home computer. Start with ones around 3 GB or less, such as llama3.2. Avoid names ending in :cloud, which are a hosted service, not local.很多 Ollama 模型对家用电脑来说太大。先从 3 GB 左右或更小的开始，例如 llama3.2。避开以 :cloud 结尾的名称，那是托管服务，不是本地运行。

Ollama is local, so why does the code still pass api_key="ollama"?Ollama 在本地运行，为什么代码里仍然传 api_key="ollama"？

Any placeholder works. Nothing leaves your machine.任何占位值都可以，数据不会离开你的电脑。

Build the competition搭建模型擂台

The script does six things in a fixed order. Tap the cards in the order the code runs them.

这段脚本按固定顺序做六件事。按代码执行的顺序依次点击卡片。

Be the judge当一次裁判

The question was: “Which matters more to a society, truth or trust? Answer in two sentences.” Rank these three answers from best to worst on clarity and strength of argument. Tap best first.

问题是：“对一个社会来说，真相和信任哪个更重要？用两句话回答。”按表达清晰度和论证力度给这三个回答排名，先点最好的。

Read the judge's verdict读懂裁判的结论

A judge model must reply in strict JSON (a plain-text format of labels and values, like {"best": 2}) so code can read it. Then the code maps numbers back to names.

裁判模型必须返回严格的 JSON（一种由标签和值组成的纯文本格式，比如 {"best": 2}），代码才能读取。然后代码把编号映射回模型名称。

competitors = ["model-A", "model-B", "model-C"] results = ["3", "1", "2"] # judge's reply, best first competitor = competitors[int(results[0]) - 1]
One after another逐个运行A plain for loop calls the models one at a time, so total time is the sum. Truly parallel calls need async. The pattern “parallelization” is about the idea, independent calls, not how this loop is written.普通的 for 循环一次只调用一个模型，总耗时是各次之和。真正并行需要 async。“并行”模式讲的是思路：彼此独立的调用，而不是这个循环的写法。

Who is rank 1?谁是第 1 名？

The judge numbers competitors from 1, Python lists start at 0, hence the - 1. “3” means competitors[2].裁判从 1 开始编号，而 Python 列表从 0 开始，所以要 - 1。“3” 对应 competitors[2]。
Know the limits了解局限A judge is one more model, so its ranking is an opinion. Use a strong model, hide who wrote what, and spot-check the result.裁判也是一个模型，所以它的排名只是一种意见。请用强模型，隐藏回答者身份，并抽查结果。

Name the patterns认出其中的模式

You met five workflow patterns in Lesson 2. Which one does each part of this script use?

第 2 课你认识了五种工作流模式。这段脚本的每个部分用的是哪一种？

Why it matters意义何在Sending one task to several models and evaluating the results is a common way to raise quality where accuracy is critical.把同一个任务发给多个模型再评估结果，是在准确性至关重要的场景下提升质量的常用办法。

Challenge: feed the judge's ranking back so the weakest model tries again with feedback. Which pattern is that?挑战：把裁判的排名反馈给最弱的模型，让它带着反馈重试。这是哪种模式？

One model produces, another evaluates, and the feedback loops back to improve the output.一个模型生成，另一个评估，反馈再回流以改进输出。

Takeaways要点回顾

• Pick the size to match the job: small for volume, large for hard thinking, local for privacy.
• Switching providers means changing base_url, the key and the model name.
• Ask a judge for JSON so your code can read the ranking.
• You do not need every provider. One key is enough to practise.

• 按任务选大小：量大用小模型，难题用大模型，隐私用本地模型。
• 换厂商只需改 base_url、密钥和模型名。
• 让裁判返回 JSON，代码才能读取排名。
• 不需要用遍所有厂商，一个密钥就足够练习。
