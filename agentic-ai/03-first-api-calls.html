Foundations · Lesson 3基础 · 第 3 课

First LLM calls初次调用大模型

Set up an API key, ask a model a question, chain three calls · ~10 min · hands-on配置 API 密钥，向模型提问，串联三次调用 · 约 10 分钟 · 动手实操

You need Python, a notebook (Jupyter, or VS Code's notebook view, a page of small code boxes called cells that you run top to bottom) and a virtual environment (a private folder of packages for one project) with pip install openai python-dotenv (pip is Python's package installer; you type the command in a terminal, the text window where you run commands).你需要 Python、一个笔记本（Jupyter 或 VS Code 的笔记本视图，一页小代码框，叫单元格，从上到下运行），以及装好 pip install openai python-dotenv 的虚拟环境（为单个项目准备的软件包文件夹）。pip 是 Python 的装包工具；命令要在终端（输入命令的文字窗口）里输入。

Step 1 · Keep your key safe第 1 步 · 安全保管密钥

Learn先学

An API key is a password that also bills your card. Create one on your model provider's developer site (for OpenAI: platform.openai.com, API keys), add a few dollars of credit and set a monthly spending limit there; this lesson costs a few cents. Never paste the key into code. Put it in a .env file in the project root, save it, and let Python read it from there.

API 密钥是个会扣你信用卡的密码。在模型厂商的开发者网站上创建（OpenAI 是 platform.openai.com 的 API keys 页面），充几美元额度，并在那里设好每月消费上限；这一课只花几美分。不要把密钥写进代码，放在项目根目录的 .env 文件里，保存后让 Python 从那里读取。

OPENAI_API_KEY=sk-...your-key...
Never share your key不要泄露密钥Don't save .env into Git (the tool that keeps and shares versions of your code), paste it in chat or screenshot it. If it leaks, delete it in your account and make a new one.不要把 .env 存进 Git（保存并分享代码版本的工具）、贴到聊天里或截图。一旦泄露，立刻在账户里删除并重建。

Step 2 · Make your first call第 2 步 · 完成第一次调用

Learn先学

Recap: an LLM call is messages in, text out (Anatomy of an LLM call shows what happens underneath). Four lines do the work: load the key, create a client (your connection to the model), send a list of messages, read the reply. Each call starts fresh: the model remembers nothing between calls, so an agent has to carry its own memory.

回顾：一次 LLM 调用就是输入消息、输出文本（底层发生了什么，见大模型调用解剖）。四行就够：加载密钥、创建客户端（你与模型的连接）、发送消息列表、读取回复。每次调用都从零开始：模型在两次调用之间什么都不记得，所以智能体要自己带着记忆。

# once, in a terminal: pip install openai python-dotenv import os # built into Python: lets code read settings such as keys from dotenv import load_dotenv from openai import OpenAI load_dotenv(override=True) # copy what is in .env into those settings if os.getenv("OPENAI_API_KEY") is None: # getenv looks one setting up; None means it is not there raise SystemExit("OPENAI_API_KEY not found: check your .env file") # stop here with a clear message client = OpenAI() messages = [{"role": "user", "content": "Tell me a fun fact"}] response = client.chat.completions.create(model="gpt-5.4-nano", messages=messages) print(response.choices[0].message.content)

response.choices[0].message.content reads: the response, its first choice, its message, the text.response.choices[0].message.content 的意思是：响应、第一个选项、其中的消息、文字。

Step 3 · Chain three calls第 3 步 · 串联三次调用

Learn先学

A chain feeds one reply into the next prompt. Store each reply in a variable and drop it in with an f-string (text starting with f, where {name} becomes that variable's value). Use a small model for easy steps (nano, mini) and the strongest (full) for the judge. Step through a simulated example; real replies differ.

调用链把一次的回复喂给下一次的提示词。把每次回复存进变量，再用 f-string（以 f 开头的文字，其中 {name} 会换成该变量的值）放进去。简单步骤用小模型（nano、mini），评判用最强的（full）。逐步看一个模拟示例；真实回复会不同。

# continues from step 2: client is already created def ask(prompt, model): messages = [{"role": "user", "content": prompt}] response = client.chat.completions.create(model=model, messages=messages) return response.choices[0].message.content question = ask("Write one hard, open question a customer might ask a kopitiam helper. Reply with only the question.", "gpt-5.4-mini") answer = ask(question, "gpt-5.4-mini") verdict = ask(f"""Here is a question: {question} And a possible answer, which may be right or wrong: {answer} Is the answer correct or incorrect?""", "gpt-5.4") print(verdict)

If something breaks遇到问题时

It stops with OPENAI_API_KEY not found程序停下并显示 OPENAI_API_KEY not found

Python did not find the file. Check it is named exactly .env, sits in the project root and is saved.

Python 没找到文件。检查文件名恰好是 .env、在项目根目录且已保存。

NameError or ImportErrorNameError 或 ImportError

Run cells top to bottom. For ImportError, make sure the notebook's kernel (the Python running behind it) is your project's virtual environment, then install the package there.

从上到下按顺序运行单元格。遇到 ImportError，确认笔记本的内核（背后运行的 Python）是项目的虚拟环境，再在其中安装缺少的包。

Now make it yours现在做成你的

Takeaways要点回顾

• An LLM API is a function: messages in, text out.
• Keep the key in .env; never print or share it.
• The reply text is at response.choices[0].message.content.
• Each call starts fresh, so you carry information forward yourself.
• Chaining: store a reply in a variable, paste it into the next prompt with an f-string.

• LLM API 就是一个函数：输入消息，输出文本。
• 密钥放在 .env，绝不打印或分享。
• 回复文字在 response.choices[0].message.content。
• 每次调用都从零开始，信息要由你自己带到下一步。
• 串联：把回复存进变量，再用 f-string 放进下一个提示词。
