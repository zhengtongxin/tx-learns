Agent-to-agent protocols智能体之间的协议

Let an agent in another process do a job for yours, like a stall next door · ~30 min · hands-on让另一个进程里的智能体替你的智能体干活，就像隔壁摊位 · 约 30 分钟 · 动手实践

Key point要点

A2A (Agent2Agent) lets your agent hand a job to an agent in another process and use it like a local sub-agent. Picture Mei at a night-market drinks stall. A customer wants satay, so she walks to Uncle Hock's stall, reads his signboard and passes the order on. The signboard is his agent card.

A2A（Agent2Agent）让你的智能体把任务交给另一个进程里的智能体，并像本地子智能体一样使用。想象夜市饮料摊的 Mei：顾客要沙爹，她走到 Hock 叔的摊位，读他的招牌，再把订单递过去。这块招牌就是他的智能体名片。

Step 1 · One agent in Google ADK第 1 步 · Google ADK 里的一个智能体

Learn先学
  • In Google's Agent Development Kit, an LlmAgent is a model plus an instruction.
  • A tool is a plain typed function with a docstring. No decorator: ADK reads the type hints and the docstring.
  • run_debug sends one message and prints the whole trace. Experiments only. The key comes from .env.
  • 在 Google 的智能体开发套件（ADK）里，LlmAgent 就是模型加一段 instruction。
  • 工具就是带类型标注和文档字符串的普通函数，不需要装饰器：ADK 会读类型标注和文档字符串。
  • run_debug 发一条消息并打印完整过程，只用于实验。密钥来自 .env。
pip install "google-adk[a2a]" python-dotenv requests
from dotenv import load_dotenv from google.adk.agents import LlmAgent from google.adk.runners import InMemoryRunner load_dotenv(override=True) # reads GOOGLE_API_KEY notepad = [] # Mei's notepad: a plain list def save_order(item: str, qty: int) -> str: """Write one customer order on the notepad. Use it after the customer confirms.""" notepad.append((item, qty)) return "saved" drinks = LlmAgent( model="gemini-2.5-flash", name="drinks_stall", instruction="You sell drinks at a night market. Take orders and write them down.", tools=[save_order], ) await InMemoryRunner(agent=drinks).run_debug("Two iced barley, please", verbose=True)

Step 2 · Put Uncle Hock behind a signboard第 2 步 · 把 Hock 叔放在招牌后面

Learn先学
  • Hock runs in his own process, behind his own port (a numbered door on your computer).
  • to_a2a wraps his agent in a small web app that serves the A2A endpoint and his agent card: a JSON file at a well-known address with his name, skills and where to reach him.
  • uvicorn is the server program that opens the port.
  • Hock 运行在他自己的进程里，有自己的端口（你电脑上带编号的门）。
  • to_a2a 把他的智能体包进一个小网页应用，提供 A2A 入口和他的智能体名片：一个放在固定地址的 JSON 文件，写着他的名字、技能和联系方式。
  • uvicorn 是打开端口的服务器程序。
from google.adk.agents import LlmAgent from google.adk.a2a.utils.agent_to_a2a import to_a2a hock = LlmAgent( model="gemini-2.5-flash", name="satay_hock", description="Takes satay orders and confirms them with a price in S$.", instruction="Confirm the satay order (how many sticks, chicken or beef) and give the price.", ) a2a_app = to_a2a(hock, port=8001) # serves the card and the endpoint
# in a terminal; curl fetches the card and prints it: uvicorn satay_server:a2a_app --host localhost --port 8001 curl http://localhost:8001/.well-known/agent-card.json

Step 3 · Mei walks over第 3 步 · Mei 走过去

Learn先学

On Mei's side Hock becomes a RemoteA2aAgent in her sub_agents. Nothing finds him for you: you give the full card URL.

在 Mei 这边，Hock 变成她 sub_agents 里的一个 RemoteA2aAgent。没有谁会替你找到他：你要给出完整的名片 URL。

from google.adk.agents.remote_a2a_agent import RemoteA2aAgent, AGENT_CARD_WELL_KNOWN_PATH hock_remote = RemoteA2aAgent( name="satay_hock", description="Remote stall that takes satay orders.", agent_card=f"http://localhost:8001{AGENT_CARD_WELL_KNOWN_PATH}", # the full card URL ) root_agent = LlmAgent( model="gemini-2.5-flash", name="mei_stall", instruction="Handle drinks yourself. For any satay order, hand it to satay_hock.", sub_agents=[hock_remote], )

Is each case a local sub-agent or a remote A2A agent? Sort them.

每种情况是本地子智能体，还是远程 A2A 智能体？请分类。

What I got wrong我犯过的错The port in to_a2a(..., port=8001) is only what the card advertises. When uvicorn ran on another port, calls failed quietly. Keep the two equal.to_a2a(..., port=8001) 里的端口只是名片上宣称的地址。uvicorn 跑在别的端口时，调用会悄悄失败。两者要一致。

Takeaways要点回顾

• An ADK LlmAgent is a model plus an instruction; a tool is a typed function with a docstring.
• A2A lets an agent in another process (or company) act like a local sub-agent.
• The agent card is the signboard: name, skills, address, at a well-known URL.
• No auto-discovery: give the full card URL, and keep the advertised port equal to the real one.

• ADK 的 LlmAgent 就是模型加指令；工具是带类型标注和文档字符串的函数。
• A2A 让另一个进程（或另一家公司）的智能体像本地子智能体一样工作。
• 智能体名片就是招牌：名字、技能、地址，放在固定 URL。
• 没有自动发现：要给完整名片 URL，宣称的端口要和实际端口一致。
