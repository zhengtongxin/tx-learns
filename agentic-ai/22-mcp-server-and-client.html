MCP server and clientMCP 服务端与客户端

Turn your own notebook into a tool any agent can plug in · ~30 min · hands-on把你自己的小本子变成任何智能体都能接上的工具 · 约 30 分钟 · 动手实践

Key point要点

Any plain Python can become an MCP server: put @mcp.tool() on a function and any agent, or a plain script, can call it. Example: a mamak's tab book for regulars (what each owes, what they ordered).

任何普通 Python 都能变成 MCP 服务端：在函数上加 @mcp.tool()，任何智能体或普通脚本都能调用它。示例：mamak 档口的熟客账本（每人欠多少、点过什么）。

Step 1 · Wrap the tab book as a server第 1 步 · 把账本包成服务端

Learn先学
  • The official mcp package gives FastMCP. The model never sees your code, only the name, docstring and type hints: write them for a new waiter.
  • A tool is an action the model decides to call. A resource is read-only data at a URI (tabs://book/tan) that the app fetches.
  • End the file with mcp.run(transport="stdio"). Never print to stdout: it is the wire.
  • 官方 mcp 包提供 FastMCP。模型从不看到你的代码，只看到名字、文档字符串和类型标注：要像给新服务员讲解一样去写。
  • 工具是由模型决定调用的动作。资源是 URI（tabs://book/tan）上的只读数据，由应用去取。
  • 文件最后写 mcp.run(transport="stdio")。千万别往标准输出 print：那是通信线路。

# tabs.py: the plain notebook, nothing MCP in it import json, pathlib FILE = pathlib.Path("tabs.json") PRICES = {"roti telur": 2.5, "teh-o": 1.8} class Tab: def __init__(self, name): self.name = name.lower() d = self._load().get(self.name, {}) self.balance, self.items = d.get("balance", 0.0), d.get("items", []) @staticmethod def _load(): return json.loads(FILE.read_text()) if FILE.exists() else {} @classmethod def get(cls, name): return cls(name) def _save(self): book = self._load() book[self.name] = {"balance": self.balance, "items": self.items} FILE.write_text(json.dumps(book)) def add(self, item, qty): self.items.append([item, qty]); self.balance += PRICES.get(item.lower(), 0) * qty self._save(); return self.balance def report(self): return json.dumps({"name": self.name, "balance": self.balance, "items": self.items})
from mcp.server.fastmcp import FastMCP from tabs import Tab mcp = FastMCP("tab_book") @mcp.tool() async def get_balance(name: str) -> float: """How much this regular currently owes, in S$. Args: name: the regular's name as written in the book """ return Tab.get(name).balance @mcp.tool() async def add_order(name: str, item: str, qty: int) -> float: """Add an order to a regular's tab and return the new balance. Args: name: the regular's name item: menu item, e.g. 'roti telur' qty: how many """ return Tab.get(name).add(item, qty) @mcp.resource("tabs://book/{name}") async def tab_page(name: str) -> str: """The full page for one regular: items and balance, as JSON.""" return Tab.get(name).report() if __name__ == "__main__": mcp.run(transport="stdio")

Tool (the model decides) or resource (the app fetches)? Sort each case.

工具（由模型决定）还是资源（由应用去取）？请逐项分类。

Step 2 · Use it from an agent and from a raw client第 2 步 · 从智能体和原始客户端使用它

Learn先学
  • Your server is now just another server: the agent framework starts it as a subprocess. Set cwd so it finds tabs.py.
  • A raw client does four things: open the transport, open a session, call initialize(), then ask. It needs no model, so reading a resource costs no tool call.
  • 你的服务端现在就是又一个服务端：智能体框架把它当子进程启动。设好 cwd，它才找得到 tabs.py。
  • 原始客户端做四件事：打开传输、打开会话、调用 initialize()、再提问。它不需要模型，所以读资源不花任何工具调用。
from agents import Agent, Runner, trace from agents.mcp import MCPServerStdio # run inside an async def or a notebook cell params = {"command": "uv", "args": ["run", "tab_server.py"], "cwd": "/path/to/tab_project"} # the folder that holds tab_server.py and tabs.py async with MCPServerStdio(params=params, client_session_timeout_seconds=30) as tab_book: agent = Agent(name="cashier", instructions="You manage regulars' tabs. Use the tab tools; never guess numbers.", model="gpt-4o-mini", mcp_servers=[tab_book]) with trace("cashier"): res = await Runner.run(agent, "Mr Tan had 2 roti telur and a teh-O. Add it, then tell me his balance.") print(res.final_output)
import mcp from mcp import StdioServerParameters from mcp.client.stdio import stdio_client params = StdioServerParameters(command="uv", args=["run", "tab_server.py"], env=None) async def read_tab(name: str) -> str: async with stdio_client(params) as (read, write): async with mcp.ClientSession(read, write) as session: await session.initialize() res = await session.read_resource(f"tabs://book/{name}") return res.contents[0].text

Takeaways要点回顾

• A server is decorated functions plus mcp.run(); a client is a session plus list_tools, call_tool and read_resource.
• The model sees only the name, docstring and type hints.
• Tools are actions the model calls; resources are read-only data the app fetches by URI.
• Your own server plugs in like a third-party one; a raw client needs no model.
• Pin mcp<2, start in the right folder, never print to stdout.

• 服务端就是加了装饰器的函数加 mcp.run()；客户端就是会话加 list_tools、call_tool 和 read_resource。
• 模型只看到名字、文档字符串和类型标注。
• 工具是模型调用的动作；资源是应用按 URI 取的只读数据。
• 你自己的服务端和第三方的接法一样；原始客户端不需要模型。
• 锁定 mcp<2，在正确的文件夹启动，别往标准输出 print。
