Step 1 · Wrap the notebook as tools第 1 步 · 把小本子包成工具

Learn先学

The notebook is plain Python with nothing MCP in it. The official mcp package gives you FastMCP: put @mcp.tool() on a function and it becomes a tool another program can call. You do not have to read the notebook line by line: the tools only call its get, add, pay and report methods. Install it with the version cap in the first line of the code (mcp[cli]<2); the last callout says why.

这本小本子只是普通的 Python，里面没有任何 MCP。官方的 mcp 包提供 FastMCP：在函数上加 @mcp.tool()，它就成了别的程序可以调用的工具。你不必逐行读这本小本子：工具只会用到它的 get、add、pay 和 report 方法。安装时用代码第一行的版本限制 mcp[cli]<2，原因写在最后的“我踩过的坑”里。

The model never sees your code. It sees the name, the docstring and the type hints. So write those as if you were explaining the tool to a new waiter.

模型看不到你的代码，它看到的只有名字、文档字符串和类型标注。所以要像给新来的服务员讲解那样，认真写好它们。

pip install "mcp[cli]<2" openai-agents python-dotenv
# tabs.py (the notebook, dimmed: plain Python you already have; the bright part is new) import json, pathlib FILE = pathlib.Path("tabs.json") PRICES = {"roti telur": 2.5, "teh-o": 1.8} class Tab: def __init__(self, name): self.name = name.lower() d = self._load().get(self.name, {}) self.balance, self.items, self.note = d.get("balance", 0.0), d.get("items", []), d.get("note", "") @staticmethod def _load(): return json.loads(FILE.read_text()) if FILE.exists() else {} @classmethod def get(cls, name): return cls(name) def _save(self): book = self._load() book[self.name] = {"balance": self.balance, "items": self.items, "note": self.note} FILE.write_text(json.dumps(book)) def add(self, item, qty): self.items.append([item, qty]); self.balance += PRICES.get(item.lower(), 0) * qty self._save(); return self.balance def pay(self, amount): self.balance -= amount; self._save(); return self.balance def report(self): return json.dumps({"name": self.name, "balance": self.balance, "items": self.items, "note": self.note})
# tab_server.py from mcp.server.fastmcp import FastMCP from tabs import Tab mcp = FastMCP("tab_book") @mcp.tool() async def get_balance(name: str) -> float: """How much this regular currently owes, in RM. Args: name: the regular's name as written in the book """ return Tab.get(name).balance @mcp.tool() async def add_order(name: str, item: str, qty: int) -> float: """Add an order to a regular's tab and return the new balance. Args: name: the regular's name item: menu item, e.g. 'roti telur' qty: how many """ return Tab.get(name).add(item, qty) @mcp.tool() async def settle(name: str, amount: float) -> float: """Record a cash payment and return what is still owed.""" return Tab.get(name).pay(amount)

Step 2 · Tools versus resources第 2 步 · 工具和资源

Learn先学

A tool is an action the model decides to call. A resource is read-only data with an address (a URI, an address written like a web link, such as tabs://book/tan). The app decides to fetch it, which is handy for pasting context straight into a prompt.

工具是由模型决定要不要调用的动作。资源是有地址（URI，一种像网址一样的地址写法，比如 tabs://book/tan）的只读数据，由应用决定去取，很适合把背景资料直接贴进提示词。

Then end the file with mcp.run(transport="stdio"). That is the whole server: decorated functions plus one line to start it.

最后用 mcp.run(transport="stdio") 收尾。整个服务端就是：加了装饰器的函数，再加一行启动。

# tab_server.py, continued @mcp.resource("tabs://book/{name}") async def tab_page(name: str) -> str: """The full page for one regular: items, balance and note, as JSON.""" return Tab.get(name).report() if __name__ == "__main__": mcp.run(transport="stdio")

Tool (the model decides) or resource (the app fetches)? Sort each case.

工具（模型决定）还是资源（应用去取）？逐个分类。

Step 3 · Use it from an agent第 3 步 · 从智能体里使用它

Learn先学

Your server is now just another server. The agent framework starts it as a subprocess, exactly like a third-party one from the last lesson. Tell the agent in its instructions to use the tab tools and never to guess numbers. The async with block must run inside an async def (or a notebook cell).

你的服务端现在和别的服务端没有区别。智能体框架会把它当作子进程启动，和上一课的第三方服务端一模一样。在指令里告诉智能体：用账本工具，不要瞎猜数字。async with 这段要放在 async def 里（或笔记本的单元格里）运行。

from agents import Agent, Runner, trace from agents.mcp import MCPServerStdio params = {"command": "uv", "args": ["run", "tab_server.py"], "cwd": "/path/to/tab_project"} # the folder that holds tab_server.py and tabs.py async with MCPServerStdio(params=params, client_session_timeout_seconds=30) as tab_book: print([t.name for t in await tab_book.list_tools()]) agent = Agent(name="cashier", instructions="You manage regulars' tabs. Use the tab tools; never guess numbers.", model="gpt-4o-mini", mcp_servers=[tab_book]) with trace("cashier"): res = await Runner.run(agent, "Mr Tan had 2 roti telur and a teh-O. Add it, then tell me his balance.") print(res.final_output)

Expected output (your wording will differ)预期输出（你的措辞会有所不同）

['get_balance', 'add_order', 'settle'] Mr Tan's tab now stands at RM6.80 (2 roti telur and 1 teh-O).

Step 4 · A raw client, no agent第 4 步 · 不用智能体的原始客户端

Learn先学

Underneath, a client does four things: open the transport, open a session, call initialize(), then ask. This is what the agent framework did for you in Step 3.

说到底，客户端只做四件事：打开通道、打开会话、调用 initialize()，然后提问。第 3 步里智能体框架替你做的就是这些。

Use it when you do not need a model. read_tab fetches Mr Tan's page so you can paste it into a prompt, and that costs no tool call at all.

不需要模型的时候就用它。read_tab 取出 Tan 先生那一页，你可以把它贴进提示词，完全不用一次工具调用。

# tab_client.py import mcp from mcp import StdioServerParameters from mcp.client.stdio import stdio_client params = StdioServerParameters(command="uv", args=["run", "tab_server.py"], env=None) async def read_tab(name: str) -> str: async with stdio_client(params) as (read, write): async with mcp.ClientSession(read, write) as session: await session.initialize() res = await session.read_resource(f"tabs://book/{name}") return res.contents[0].text async def list_tool_names() -> list[str]: async with stdio_client(params) as (read, write): async with mcp.ClientSession(read, write) as session: await session.initialize() return [t.name for t in (await session.list_tools()).tools]

Step 5 · MCP tools as plain function tools第 5 步 · 把 MCP 工具变成普通函数工具

Learn先学

Sometimes you want the MCP tools without keeping a server object in the agent, for example to mix them into a framework that only takes plain functions. With the raw session you can call any tool by name, then wrap it. Every call here starts the server again from scratch, which costs a moment, so this suits occasional calls, not a tight loop.

有时你想用 MCP 的工具，却不想在智能体里留着服务端对象，比如要把它们混进一个只接受普通函数的框架。有了原始会话，就能按名字调用任何工具，再包一层。这里每次调用都会把服务端重新启动一遍，要花一点时间，所以适合偶尔调用，不适合密集循环。

from agents import function_tool async def call_tool(tool: str, args: dict): async with stdio_client(params) as (read, write): async with mcp.ClientSession(read, write) as session: await session.initialize() return await session.call_tool(tool, args) @function_tool async def get_balance_plain(name: str) -> str: """How much a regular currently owes, in RM.""" return (await call_tool("get_balance", {"name": name})).content[0].text
What I got wrong我踩过的坑Three things cost me time. First, mcp<2 matters: from mcp.server.fastmcp import FastMCP is the classic import, and the 2.0 release removed that module. Some third-party servers import it without capping their dependency, so with uvx I add --with "mcp<2". Second, run the server from the right folder. My server imports a local tabs.py, and if the subprocess starts elsewhere it dies on import, and all I see is a timeout. Set cwd in the params, as in Step 3. Third, "Tan" and "tan" were different pages until Tab lowercased the name. On Windows in Jupyter, the raw stdio_client needs the errlog=subprocess.DEVNULL trick too (with import subprocess at the top; it throws away the server's error text so Jupyter does not choke).三件事浪费了我不少时间。第一，mcp<2 很重要：from mcp.server.fastmcp import FastMCP 是经典写法，而 2.0 版把这个模块删掉了。有些第三方服务端没有限制依赖版本也用这个导入，所以用 uvx 时我会加上 --with "mcp<2"。第二，要在正确的文件夹里运行服务端。我的服务端要导入本地的 tabs.py，子进程在别处启动就会在导入时崩掉，而我只看到超时。要像第 3 步那样在参数里设置 cwd。第三，在 Tab 把名字转成小写之前，“Tan”和“tan”是两页不同的账。在 Windows 的 Jupyter 里，原始的 stdio_client 同样需要 errlog=subprocess.DEVNULL 这个办法（文件开头要有 import subprocess；它把服务端的报错文字丢掉，免得 Jupyter 出问题）。

Common errors常见错误

• ModuleNotFoundError: No module named 'mcp': The package is not installed here. Fix: pip install "mcp[cli]<2" (keep the quotes).
• McpError: Connection closed: The server crashed on start, often an import error or print to stdout. Fix: run python tab_server.py alone to see the error, and use print(..., file=sys.stderr).
• FileNotFoundError: tabs.json: The server started in a different folder. Fix: use an absolute path, or set cwd in the server parameters.

• ModuleNotFoundError: No module named 'mcp'：这里没装这个包。解决：pip install "mcp[cli]<2"（引号要保留）。
• McpError: Connection closed：服务一启动就崩了，常见原因是导入错误，或往标准输出里 print。解决：单独运行 python tab_server.py 看错误，调试输出改用 print(..., file=sys.stderr)。
• FileNotFoundError: tabs.json：服务是在另一个文件夹启动的。解决：用绝对路径，或在服务参数里设置 cwd。

Takeaways要点回顾

• A server is decorated functions plus mcp.run(). A client is a session plus list_tools, call_tool and read_resource.
• The model sees the name, docstring and type hints, never your code. Write them with care.
• Tools are actions the model calls. Resources are read-only data the app fetches by URI.
• Your own server plugs into an agent exactly like a third-party one.
• A raw client needs no model, so reading a resource costs no tool call.
• Any MCP tool can be wrapped as a plain function tool through a session.
• Pin mcp<2, start the server in the right folder, and normalise names like "Tan" and "tan".

• 服务端就是加了装饰器的函数加上 mcp.run()；客户端就是一个会话加上 list_tools、call_tool 和 read_resource。
• 模型看到的是名字、文档字符串和类型标注，看不到你的代码，所以要认真写。
• 工具是模型调用的动作；资源是应用按 URI 去取的只读数据。
• 你自己的服务端接入智能体的方式，和第三方服务端完全一样。
• 原始客户端不需要模型，所以读取资源不用一次工具调用。
• 任何 MCP 工具都可以通过会话包装成普通函数工具。
• 固定 mcp<2，在正确的文件夹启动服务端，并统一“Tan”和“tan”这类名字的写法。

Recap三句回顾

• A server turns plain functions into tools with @mcp.tool() and pages with @mcp.resource().
• A client connects, lists the tools and calls them by name.
• Never print to stdout in a stdio server: it is the wire.

• 服务用 @mcp.tool() 把普通函数变成工具，用 @mcp.resource() 变成页面。
• 客户端负责连接、列出工具，并按名字调用。
• stdio 服务里不要往标准输出打印：那是通信线路。
