Step 1 · Be the agent第 1 步 · 亲自当智能体

Learn先学

You are the brain of an agent (the LLM, a large language model: AI that reads and writes text). Goal: find a Singapore → Tokyo flight price, total 2 tickets in SGD, email the total, then answer. Each turn you see the log so far and pick one tool.

你就是智能体的“大脑”（大模型 LLM，能读写文字的 AI）。目标：查新加坡→东京的机票价格，算出 2 张票的新元总价，把总价发邮件，然后给出答案。每一轮你看到目前的日志，选一个工具。

Your five tools你的五个工具
🔎 Search flight price搜索机票价格💱 Look up exchange rate查询汇率🧮 Calculate total计算总价📧 Send email发送邮件✅ Give final answer给出最终答案

Step 2 · Workflow vs agent第 2 步 · 工作流 vs 智能体

Learn先学

An agent is an LLM with tools, in a loop, working toward a goal. Each turn: think, act, observe. A workflow is the cousin where your code fixes the route and the LLM only fills in each step. (Tools like n8n also call any canvas of connected steps a “workflow”; here the word has this narrower meaning.) Both are agentic systems; the difference is who picks the next step.

智能体 = 带着工具、在循环中、为达成目标而工作的大模型。每一轮：思考、行动、观察。工作流是它的近亲：路线由你的代码定死，大模型只填每一步的内容。（n8n 这类工具也把画布上连起来的任何步骤叫“工作流”；这里用的是这个更窄的意思。）两者都叫智能体系统，区别在于由谁选下一步。

Python · workflow.py
# sketch: search_price, get_rate, send_email are plain functions you wrote; ask_llm(text) returns the model's reply price = search_price("Singapore to Tokyo") rate = get_rate("USD", "SGD") total = 2 * price * rate body = ask_llm(f"Write one line saying the total is SGD {total}") send_email(body)
Python · agent.py
# sketch: ask_llm and run_tool are stand-ins, not a real library goal = "Singapore to Tokyo: total for 2 tickets in SGD, email it, then answer" tools = ["search_price", "get_rate", "calculate", "send_email", "final_answer"] # each also carries a description the LLM reads (see “Autonomy and tools”) history = [goal] # the log the LLM reads for turn in range(8): # step limit: a guardrail choice = ask_llm(history, tools) # the LLM picks the next tool if choice.name == "final_answer": break result = run_tool(choice.name, choice.args) history.append(result) # the LLM sees this next turn

Step 3 · Five workflow patterns第 3 步 · 五种工作流模式

Learn先学

Most workflows are built from five shapes.

大多数工作流由五种形状搭成。

• Prompt chaining: a fixed sequence of small calls. Outline → article → translation.
• Routing: classify the input, send it to a specialist. Billing vs tech vs sales.
• Parallelization: independent pieces run at once, then combine. Security, style and speed checks.
• Orchestrator-worker: one LLM call, the orchestrator, splits the task at run time and hands each piece to another LLM call, a worker. “Fix this bug” may touch 2 files or 7. The model decides how many pieces, but your code still fixes the shape (split, work, combine), so it stays a workflow.
• Evaluator-optimizer: one LLM writes, another judges, loop until it passes.

• 提示链：一串固定顺序的小调用。大纲 → 文章 → 翻译。
• 路由：先分类，再交给专家。账单、技术、销售。
• 并行化：独立部分同时运行，再汇总。安全、风格、性能检查。
• 编排者-工作者：一次大模型调用（编排者）在运行时拆任务，把每一块交给另一次大模型调用（工作者）。“修这个 bug”可能涉及 2 个或 7 个文件。分成几块由模型决定，但形状（拆分、处理、汇总）仍由你的代码定死，所以它还是工作流。
• 评估者-优化者：一个大模型写，另一个评判，循环到通过。

Step 4 · Choose the simplest design第 4 步 · 选最简单的方案

Learn先学

Agents are powerful but unpredictable: path, output and cost vary. Start simple and climb only when a metric (a number you can check before and after, such as “minutes to answer a customer”) improves. Ask in order:

智能体强大，但路径、输出和成本都难以预测。从简单开始，只有指标（改动前后都能查看的数字，例如“回复客户要多少分钟”）改善，才往上走。按顺序问：

1 · Is there a metric?1 · 有指标吗？No: decide what “better” means first.没有：先想清楚“更好”是什么意思。
2 · Does one LLM call hit it?2 · 单次调用能达标吗？Yes: stop there.能：到此为止。
3 · Can you write every step?3 · 能写出每一步吗？Yes: a workflow. No: an agent, with traces (a step-by-step record of a run), tests and guardrails.能：工作流。不能：智能体，并配上 trace（一次运行的逐步记录）、测试和护栏。

Now make it yours现在换成你自己的

Takeaways要点回顾

• An agent is an LLM with tools, in a loop, working toward a goal.
• In a workflow your code picks the next step; in an agent the LLM does.
• Five patterns: chaining, routing, parallelization, orchestrator-worker, evaluator-optimizer.
• Agents add cost, variation and risk: decide with a metric, not hype.
• Add traces and guardrails, such as a step limit, before an agent runs free.

• 智能体 = 带着工具、在循环中、为达成目标而工作的大模型。
• 工作流里由你的代码选下一步，智能体里由大模型选。
• 五种模式：提示链、路由、并行化、编排者-工作者、评估者-优化者。
• 智能体增加成本、波动和风险：用指标做决定，别靠热度。
• 让智能体自由运行前，先加 trace 和护栏，比如步数上限。
