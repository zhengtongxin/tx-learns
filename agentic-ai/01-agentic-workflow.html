Foundations · Lesson 1基础 · 第 1 课

Agentic workflow智能体工作流

Build your first agent in n8n, no code · ~15 min · hands-on用 n8n 零代码搭建第一个智能体 · 约 15 分钟 · 动手实践

You'll need an n8n account, an OpenAI key (a password for using OpenAI's models from other tools; it is billed per use, and this lesson costs a few cents), a free key from Marketstack (a service that returns share prices) and a Google account for Sheets. Each tool may have a free tier; check before use.你需要 n8n 账号、OpenAI key（让其他工具使用 OpenAI 模型的密码；按用量计费，这一课只花几美分）、Marketstack（一个返回股价的服务）的免费 key，以及用于 Sheets 的 Google 账号。各工具可能有免费额度，使用前请先确认。

Step 1 · What an agent is made of第 1 步 · 智能体由什么组成

Learn先学

Agent = LLM + tools + a loop. An LLM (large language model) is AI that reads and writes text, like the model behind a chat app. In n8n, a visual tool where you connect nodes on a canvas, the AI Agent node is the loop.

Six parts: a chat trigger (starts it), the AI Agent node, a chat model (brain), memory (notebook) and two tools, Marketstack and Google Sheets (hands).

智能体 = 大模型 + 工具 + 循环。大模型（LLM，large language model）是会读写文字的 AI，就像聊天应用背后的那个模型。在 n8n（把节点在画布上连线的可视化工具）里，AI Agent 节点就是那个循环。

六个部分：聊天触发器（启动）、AI Agent 节点、聊天模型（大脑）、记忆（笔记本），以及 Marketstack 和 Google Sheets 两个工具（双手）。

Step 2 · Watch it run第 2 步 · 看它运行

Learn先学

The model only replies with text, such as a tool name and its inputs. n8n runs the tool and hands the result back. Think, act, observe repeats until the agent can answer. Step through one run, then read the log. A token is a small chunk of text, about three quarters of an English word; models charge by the token.

模型只回复文字，比如工具名和输入。n8n 运行工具并把结果交回。“思考、行动、观察”重复，直到智能体能回答。一步步看一次运行，再读日志。token 是一小段文字，约四分之三个英文单词；模型按 token 收费。

Simulated example: real numbers differ, and the model can be wrong. Not investment advice.模拟示例：实际数值会不同，模型也可能出错。不构成投资建议。

Step 3 · Build it第 3 步 · 动手搭建

1. Trigger1. 触发器

New blank workflow, then add “When chat message received”.

新建空白工作流，添加“When chat message received”。

2. Agent2. 智能体

Connect the trigger to an AI Agent node.

把触发器连接到 AI Agent 节点。

3. Model + memory3. 模型和记忆

Chat Model: OpenAI. Memory: Simple Memory.

Chat Model 选 OpenAI；Memory 选 Simple Memory。

4. Tools4. 工具

Add Marketstack, operation “Get many EoD data”: paste your Marketstack key when n8n asks for a credential (its word for a saved key or sign-in). Add Google Sheets, operation “Append row”: sign in with Google, then pick a sheet with two columns, Date and Close.

添加 Marketstack，操作选“Get many EoD data”：n8n 要凭证（credential，它对已保存的密钥或登录的叫法）时贴上你的 Marketstack 密钥。再添加 Google Sheets，操作选“Append row”：用 Google 登录，然后选一张有“Date”和“Close”两列的表。

5. Chat, then open Logs5. 聊天并看日志

Ask: “Check yesterday's closing price of AAPL and write it down.” Any ticker symbol works. You never name a tool: the model reads each tool's name and description and decides that “price” means Marketstack and “write it down” means Sheets. Then see which tools ran.

问它：“查一下 AAPL 昨天的收盘价并记下来。”换成任何股票代码都行。你不用点名工具：模型读了每个工具的名字和说明，自己判断“价格”要用 Marketstack，“记下来”要用 Sheets。然后看哪些工具运行了。

Now make it yours现在轮到你

Takeaways要点回顾

• Agent = LLM + tools + a loop; the AI Agent node is the loop.
• Model is the brain, tools the hands, memory the notebook.
• The agent repeats think, act, observe until it can answer.
• The log shows each step, its time and its tokens; tokens are cost.
• Simple Memory forgets everything when the workflow restarts. For real use, pick a memory node that saves to a database.

• 智能体 = 大模型 + 工具 + 循环；AI Agent 节点就是循环。
• 模型是大脑，工具是双手，记忆是笔记本。
• 智能体重复“思考、行动、观察”，直到能回答。
• 日志显示每一步、耗时和 token；token 就是成本。
• Simple Memory 在工作流重启后就全忘了。正式使用时，请换成把内容存进数据库的记忆节点。
