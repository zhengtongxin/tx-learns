Step 1 · What is n8n, and what is an agent made of?第 1 步 · n8n 是什么，智能体由什么组成？

Learn先学

n8n (n8n.io) is a visual workflow tool. You drag nodes onto a canvas and connect them; data flows from one node to the next. It has a built-in AI Agent node, so Aina can build an agent by connecting boxes instead of writing code.

Her agent has six parts: a chat trigger (starts it), the AI Agent node (the loop), a chat model (the brain), memory (the notebook) and two tools, Marketstack and Google Sheets (the hands). “LLM” means large language model, the AI that reads and writes text.

n8n（n8n.io）是可视化工作流工具。把节点拖到画布上并连线，数据就从一个节点流向下一个。它内置 AI Agent 节点，所以 Aina 不用写代码，连几个方块就能搭出智能体。

她的智能体有六个部分：聊天触发器（启动）、AI Agent 节点（循环）、聊天模型（大脑）、记忆（笔记本）和两个工具，Marketstack 与 Google Sheets（双手）。“LLM”即大语言模型，是能读写文字的 AI。

Step 2 · Watch the agent run第 2 步 · 看智能体运行

Learn先学

Uncle Lim's request goes through the chat trigger into the AI Agent node. The agent loads its memory, asks the model what to do, and if the model asks for a tool, n8n (not the model) runs it and hands the result back. Then the agent asks the model again to write the answer. That cycle of think (ask the model), act (run a tool) and observe (read the result) repeats until the agent can answer: it is the think, act, observe loop. Press the button to step through one run, then read the log that n8n would show.

Lim 叔叔的请求经聊天触发器进入 AI Agent 节点。智能体先读取记忆，问模型该怎么做；模型若要工具，就由 n8n（不是模型）去运行它并把结果交回。然后智能体再问模型写出回答。“思考（问模型）、行动（运行工具）、观察（读结果）”这一圈会重复，直到智能体能回答：这就是“思考、行动、观察”循环。点按钮一步步看一次运行，再读 n8n 会显示的日志。

Simulated example: real numbers will differ. Closing prices come from the tool, but the model can still be wrong, and this is not investment advice.模拟示例：实际数值会不同。收盘价来自工具，但模型仍可能出错，这不构成投资建议。

Read the execution log学会看执行日志 Every step the agent took appears in the log with its duration. n8n also shows total time and tokens (the run above ends at about 1.3k). A token is a small chunk of text, about three quarters of an English word. Models read and charge by the token, so tokens = cost. Watch them as you build. 智能体的每一步都会出现在日志中并显示耗时。n8n 还会显示总耗时和 token 数（上面这次运行最终约 1.3k）。token 是一小段文字，大约相当于四分之三个英文单词。模型按 token 读取和收费，所以 token 就是成本。搭建时要留意。

Step 3 · Build it yourself第 3 步 · 动手搭建

Learn先学

Aina builds the same six parts listed in Step 1, one at a time. Click through the steps.

Aina 把第 1 步列出的六个部分一个个搭出来。点击查看每一步。

1. New workflow1. 新建工作流

Sign in to n8n (cloud or self-hosted) and create a blank workflow.

登录 n8n（云端或自托管），新建空白工作流。

2. Add the trigger2. 添加触发器

3. Add the AI Agent node3. 添加 AI Agent 节点

把触发器连接到 AI Agent 节点。

4. Attach model + memory4. 接上模型和记忆

Chat Model: OpenAI. Memory: Simple Memory.

5. Add tools5. 添加工具

Marketstack (market data) and Google Sheets (read / append rows).

添加 Marketstack（行情数据）和 Google Sheets（读取 / 追加行）。

6. Chat and inspect6. 聊天并检查

Send a message, then open the Logs to see which tools it called.

发一条消息，再打开 Logs，看它调用了哪些工具。

Good to know注意Simple Memory keeps recent chat inside n8n itself. That is fine for learning; use database-backed memory for real use.Simple Memory 把最近的对话保存在 n8n 内部。学习够用，正式使用请换成基于数据库的记忆。

Now make it yours现在轮到你

The next problem is knowing when to use a fixed workflow and when to let the model choose the steps, which is what Lesson 2 sorts out.现在 Aina 的画布上有了一个能运行的智能体：Lim 叔叔的问题进来，智能体问模型，调用 Marketstack 取收盘价，在 Google Sheets 里追加一行，日志里能看到每一步。Kopi Corner 助手接下来用的就是这些部件。下一个问题是：什么时候用固定工作流，什么时候让模型自己选步骤，这正是第 2 课要讲清楚的。

Takeaways要点回顾

• n8n connects nodes on a canvas; data flows from one to the next.
• Agent = LLM + tools + a loop, and the AI Agent node is the loop.
• The model is the brain, tools are the hands, memory is the notebook.
• The agent repeats think, act, observe until it can answer.
• The execution log shows every step, its time and its tokens; tokens are cost.
• Simple Memory is for learning; use database-backed memory for real use.

• n8n 在画布上连接节点，数据从一个节点流向下一个。
• 智能体 = 大模型 + 工具 + 循环，AI Agent 节点就是循环。
• 模型是大脑，工具是双手，记忆是笔记本。
• 智能体重复“思考、行动、观察”，直到能给出答案。
• 执行日志显示每一步、耗时和 token；token 就是成本。
• Simple Memory 适合学习，正式使用请换成基于数据库的记忆。
