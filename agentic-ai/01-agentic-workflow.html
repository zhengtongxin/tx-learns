Make an agentic workflow搭建智能体工作流

Build your first agent in n8n, no code · ~5 min · includes a live simulator用 n8n 零代码搭建第一个智能体 · 约 5 分钟 · 含互动模拟器

What is n8n?n8n 是什么？

n8n (n8n.io) is a visual workflow tool. You drag nodes onto a canvas and connect them; data flows from one node to the next. It has a built-in AI Agent node, so you can build an agent by connecting boxes instead of writing code.

n8n（n8n.io）是可视化工作流工具。把节点拖到画布上并连线，数据就从一个节点流向下一个。它内置 AI Agent 节点，不用写代码，连几个方块就能搭出智能体。

Build it yourself动手搭建

1. New workflow1. 新建工作流

Sign in to n8n (cloud or self-hosted) and create a blank workflow.

登录 n8n（云端或自托管），新建空白工作流。

2. Add the trigger2. 添加触发器

Add “When chat message received” so you can chat with it.

添加“When chat message received”，这样就能和它聊天。

3. Add the AI Agent node3. 添加 AI Agent 节点

Connect the trigger to an AI Agent node.

把触发器连接到 AI Agent 节点。

4. Attach model + memory4. 接上模型和记忆

Chat Model: OpenAI. Memory: Simple Memory.

Chat Model 选 OpenAI；Memory 选 Simple Memory。

5. Add tools5. 添加工具

Marketstack (market data) and Google Sheets (read / append rows).

添加 Marketstack（行情数据）和 Google Sheets（读取 / 追加行）。

6. Chat and inspect6. 聊天并检查

Send a message, then open the Logs to see which tools it called.

发一条消息，再打开 Logs，看它调用了哪些工具。

Good to know注意Simple Memory keeps recent chat inside n8n itself — fine for learning; use database-backed memory for real use.Simple Memory 把最近的对话保存在 n8n 内部——学习够用，正式使用请换成基于数据库的记忆。

Quick check小测验

Which part lets the agent remember earlier messages?哪个部分让智能体记住之前的消息？

Memory is attached to the agent, so each new message arrives with the recent conversation.Memory 接在智能体上，所以每条新消息都带着最近的对话。

The agent needs yesterday’s closing price. What does it use?智能体需要昨天的收盘价，它会用什么？

Models don’t know live data; they call a tool to fetch it.模型本身不知道实时数据，需要调用工具获取。

What does the AI Agent node do?AI Agent 节点的作用是什么？

It ties the model, memory and tools together and repeats until it can answer.它把模型、记忆和工具串起来，重复直到能给出答案。
