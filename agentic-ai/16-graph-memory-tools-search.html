Key point要点

create_agent gives you last lesson's tool loop in one line. Add memory, structured output and middleware as options. For a big job (planning, many searches, a file) step up to a deep agent. Example: should a Jurong East tuition centre sell breakfast to parents?

create_agent 一行就给你上一课的工具循环。记忆、结构化输出和中间件都是可选项。遇到大任务（要计划、大量搜索、写文件），升级成深度智能体。示例：裕廊东的补习中心该不该卖早餐给家长？

Step 1 · create_agent, memory and structure第 1 步 · create_agent、记忆与结构

Learn先学
  • Give create_agent a "provider:model" string, tools and a system prompt. Underneath it is a real LangGraph graph: model node, tools node, loop.
  • Memory is a checkpointer plus a thread_id, as before.
  • response_format returns data instead of prose, in structured_response.
  • 给 create_agent 一个 "provider:model" 字符串、工具和系统提示词。底层就是真正的 LangGraph 图：模型节点、工具节点、回环。
  • 记忆还是检查点加 thread_id。
  • response_format 把回答变成数据，放在 structured_response 里，而不是文字。
from langchain.agents import create_agent from langchain_core.tools import tool from langgraph.checkpoint.memory import MemorySaver from pydantic import BaseModel, Field @tool def stall_price(item: str) -> str: """Typical price in S$ for a breakfast item near schools in Jurong East.""" return {"nasi lemak": "S$3.50", "kuih": "S$0.80 each", "milo ais": "S$2.80"}.get(item.lower(), "not sure") @tool def footfall(hour: int) -> str: """Rough number of parents passing the shop at a given hour (24h).""" return "about 120" if 7 <= hour <= 8 else "under 30" helper = create_agent( model="openai:gpt-5.4-mini", tools=[stall_price, footfall], system_prompt="You help a small shop owner plan a breakfast corner. Use your tools for numbers.", checkpointer=MemorySaver(), ) cfg = {"configurable": {"thread_id": "tuition-centre"}} out = helper.invoke({"messages": [{"role": "user", "content": "Is 7:30am busy, and what does nasi lemak go for?"}]}, cfg) print(out["messages"][-1].content) class Plan(BaseModel): items: list[str] = Field(description="Breakfast items to sell") est_daily_sales: str = Field(description="Rough daily sales estimate in S$") planner = create_agent(model="openai:gpt-5.4-mini", tools=[stall_price, footfall], response_format=Plan) plan = planner.invoke({"messages": [{"role": "user", "content": "Plan the menu."}]})["structured_response"]

Step 2 · Middleware第 2 步 · 中间件

Learn先学

Middleware is code that runs at fixed points in the loop (before the model call, around each tool call) without touching your tools. Ready-made ones summarise long chats, hide personal data, limit calls and retry. This one prints every tool call, a handy debugging trick.

中间件是在循环固定位置（模型调用前、每次工具调用外围）运行的代码，不用改你的工具。现成的有：总结长对话、隐藏个人数据、限制调用次数、重试。下面这个会打印每次工具调用，是个好用的调试技巧。

from langchain.agents.middleware import wrap_tool_call @wrap_tool_call def spy(request, handler): print("tool ->", request.tool_call["name"], request.tool_call["args"]) return handler(request) watched = create_agent(model="openai:gpt-5.4-mini", tools=[stall_price], middleware=[spy])

Step 3 · The big job: a deep agent第 3 步 · 大任务：深度智能体

Learn先学
  • A deep agent is create_agent plus a todo list, file tools and a task tool that delegates to sub-agents.
  • Each sub-agent starts with a fresh context, so the lead's stays small.
  • virtual_mode=True keeps every file inside one folder: /breakfast.md lands in workspace/.
  • 深度智能体就是 create_agent 加上待办清单、文件工具，以及能分派给子智能体的 task 工具。
  • 每个子智能体都从全新上下文开始，所以主智能体的上下文保持小。
  • virtual_mode=True 把所有文件限制在一个文件夹里：/breakfast.md 实际落在 workspace/。
import os from langchain_openai import ChatOpenAI from langchain_community.tools import GoogleSerperRun from langchain_community.utilities import GoogleSerperAPIWrapper from deepagents import create_deep_agent from deepagents.backends import FilesystemBackend box = os.path.abspath("workspace"); os.makedirs(box, exist_ok=True) search = GoogleSerperRun(api_wrapper=GoogleSerperAPIWrapper()) competitor_scout = { "name": "competitor-scout", "description": "Looks up one nearby breakfast competitor and returns three facts: menu, prices, hours.", "system_prompt": "Research the single shop you are given with the search tool. Return three short facts.", } lead = create_deep_agent( model=ChatOpenAI(model="gpt-5.4-mini"), tools=[search], subagents=[competitor_scout], system_prompt="Plan with your todos, delegate each competitor to competitor-scout, " "then write a one-page markdown briefing with a recommendation.", backend=FilesystemBackend(root_dir=box, virtual_mode=True), ) lead.invoke({"messages": [{"role": "user", "content": "Should a tuition centre in Jurong East sell breakfast to parents? Write breakfast.md."}]})
What I got wrong我搞错的地方I used a deep agent for a two-tool question. create_agent is cheaper and faster; step up only when it runs out of room.我用深度智能体去回答只要两件工具的小问题。create_agent 更便宜也更快；只有不够用时再升级。

Takeaways要点回顾

• create_agent is the model-and-tools loop in one line; underneath it is still a graph.
• Memory is a checkpointer plus thread_id; response_format returns structured_response.
• Middleware runs at fixed points in the loop without touching the tools.
• A deep agent adds todos, files and sub-agents with fresh contexts. Use it for big jobs only.

• create_agent 一行就是模型加工具的循环；底层仍是一张图。
• 记忆是检查点加 thread_id；response_format 返回 structured_response。
• 中间件在循环固定位置运行，不用改工具。
• 深度智能体加上待办、文件和全新上下文的子智能体，只用于大任务。
