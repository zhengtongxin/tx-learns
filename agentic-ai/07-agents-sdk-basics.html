Step 1 · Agent, and one keyword pair第 1 步 · Agent 与一对关键字

Learn先学

An Agent is one LLM plus a system prompt plus tools. In code it is four fields, each replacing something you hand-wrote earlier. Click each.

Agent 就是一个大模型加系统提示词再加工具。代码里是四个字段，每个都替代了你之前手写的东西。逐个点开。

Learn先学

Calling a model means waiting for the network. async def marks a function that may wait; await means “wait here for this result” and works only inside an async def. A Jupyter notebook already runs an event loop, so there await works at the top level. In a .py file, wrap it:

调用模型要等网络。async def 标记允许等待的函数；await 表示“在这里等这个结果”，只能写在 async def 里。Jupyter 笔记本已有事件循环，所以那里可以在最外层直接写 await。在 .py 文件里要包一层：

# pip install openai-agents (not "agents": that is a different, older library) import asyncio from agents import Agent, Runner agent = Agent(name="Quip", instructions="You tell short, friendly jokes", model="gpt-5.4-mini") async def main(): result = await Runner.run(agent, "Tell a joke") print(result.final_output) asyncio.run(main())

Step 2 · Runner: the loop, for free第 2 步 · Runner：现成的循环

Learn先学

The code above already ran the agent. Runner.run calls the model, runs any tools it asks for, and repeats until it stops asking: your old while loop, with a turn limit built in. final_output is the answer; result.to_input_list() is every message of the run. Wrap calls in with trace("name"): to inspect each step at platform.openai.com/traces.

上面的代码已经运行了智能体。Runner.run 调用模型、执行它请求的工具、重复，直到不再请求：就是你之前的 while 循环，还自带轮数上限。final_output 是答案；result.to_input_list() 是这次运行的所有消息。把调用放进 with trace("name"):，就能在 platform.openai.com/traces 查看每一步。

Step 3 · Tool: one decorator第 3 步 · 工具：一个装饰器

Learn先学

No more hand-written tool JSON. The SDK reads your function: the docstring becomes the description and the type hints become the inputs.

不用再手写工具 JSON。SDK 直接读你的函数：文档字符串变成描述，类型标注变成输入参数。

# push() is the Pushover helper from the career agent lesson from agents import function_tool @function_tool def push_tool(message: str) -> str: """Send this message to my phone as a push notification. Use it when the user asks to be notified.""" push(message) return "Push sent" notifier = Agent(name="Notifier", model="gpt-5.4-mini", instructions="You send the user a push message when asked", tools=[push_tool])

Step 4 · Memory and teamwork第 4 步 · 记忆与协作

Learn先学

Each Runner.run starts fresh. To remember, pass a session and the SDK stores and replays the history for you. Try it below.

每次 Runner.run 都是全新开始。想记住，就传入 session，SDK 替你保存并回放历史。在下面试试。

from agents import SQLiteSession session = SQLiteSession("mei-chat") # in memory; for a file: SQLiteSession("mei-chat", "memory.db") await Runner.run(agent, "Hey! I am Mei, nice to meet you.", session=session) await Runner.run(agent, "What's my name?", session=session)
Next up接下来

Agents combine in two ways, told apart by who talks to the user next: an agent as a tool returns its result and the manager stays in control; a handoff passes the whole conversation to another agent, which replies.

智能体有两种组合方式，区别在于接下来由谁和用户说话：智能体当工具是返回结果，主管继续掌控；交接（handoff）是把整段对话交给另一个智能体，由它回复。

Now make it yours现在把它变成你的

Takeaways要点回顾

• An Agent is a model, instructions and tools.
• Runner.run is the agent loop; final_output is the answer. await works only inside async def or at a notebook's top level.
• @function_tool builds the tool JSON from your function; the docstring is the description.
• Each run is stateless: pass a session to remember.
• Agents as tools keep control; handoffs pass it on.

• Agent = 模型 + instructions + 工具。
• Runner.run 就是智能体循环，final_output 是答案。await 只能写在 async def 里或笔记本最外层。
• @function_tool 根据函数生成工具 JSON，文档字符串就是描述。
• 每次运行无状态：传入 session 才能记住。
• 智能体当工具保持控制，交接把控制权交出去。
