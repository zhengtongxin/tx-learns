Step 0 · One new keyword pair: async / await第 0 步 · 一对新关键字：async / await

Learn先学

Calling a model means waiting for the network. Think of ordering a coffee: while it is being made, you do not freeze, you can still do other things. async def marks a function that is allowed to wait like that. await means “wait here for this result” and only works inside an async def. One twist: a Jupyter notebook already runs an event loop, so there you may write await at the top level. In a normal .py file you wrap it:

调用模型要等网络。就像点咖啡：等咖啡做好时你不会僵住，还可以做别的事。async def 标记一个允许这样等待的函数；await 表示“在这里等这个结果”，只能写在 async def 里面。一个特例：Jupyter 笔记本本身已经有事件循环，所以在那里可以直接在最外层写 await。普通 .py 文件里则要这样包一层：

# in a .py file async def main(): result = await Runner.run(agent, "Tell a joke") print(result.final_output) asyncio.run(main())

Learn先学

An Agent is just one LLM plus a system prompt plus tools. In code it is four fields, and each replaces something you wrote by hand earlier. Click each field to see which.

Agent 就是一个大模型加系统提示词再加工具。代码里是四个字段，每个都替代了你之前手写的某样东西。点开每个字段看看。

Step 2 · Runner: the agent loop, for free第 2 步 · Runner：现成的智能体循环

Learn先学

Quip exists, but nothing has run yet. Runner.run does the running: it calls the model, runs any tools it asks for, and repeats until the model stops asking. That is your old while loop, with a turn limit built in.

Quip 已经定义好了，但还没运行。Runner.run 负责运行：调用模型、执行它请求的工具、重复，直到模型不再请求。这就是你之前写的 while 循环，还自带轮数上限。

agent = Agent(name="Quip", instructions="You tell short, friendly jokes", model="gpt-5.4-mini") result = await Runner.run(agent, "Tell a joke about debugging on a Friday") print(result.final_output) # the answer result.to_input_list() # every message of the run
Install name安装名称The package is openai-agents (pip install openai-agents), imported with from agents import Agent, Runner. Do not pip install agents: that is a different, older library.安装包名是 openai-agents（pip install openai-agents），导入写 from agents import Agent, Runner。不要装 agents，那是另一个旧的库。
Learn先学

Two ways to see inside a run. trace groups your calls under one name so you can inspect every step at platform.openai.com/traces. Streaming hands you the text piece by piece as it is written, so a chat feels fast.

有两种方式看清一次运行的内部。trace 把你的调用归在一个名字下，可以在 platform.openai.com/traces 查看每一步。流式输出则边生成边把文字一段段交给你，让聊天显得很快。

with trace("Quip warm-up"): result = await Runner.run(agent, "Tell a joke") result = Runner.run_streamed(agent, input="Tell me 3 jokes about coffee") async for event in result.stream_events(): if event.type == "raw_response_event" and isinstance(event.data, ResponseTextDeltaEvent): print(event.data.delta, end="", flush=True)

Step 3 · Tool: one decorator第 3 步 · 工具：一个装饰器

Learn先学

Now Quip should buzz your phone. You already have a plain function, push, from the career agent. Back then you also wrote its JSON by hand. The SDK reads your function instead: the docstring becomes the description and the type hints become the inputs.

现在让 Quip 能震动你的手机。在职业智能体里你已经有了普通函数 push，而且当时还手写了它的 JSON。现在 SDK 直接读你的函数：文档字符串变成描述，类型标注变成输入参数。

@function_tool def push_tool(message: str) -> str: """Send this message to my phone as a push notification. Use it when the user asks to be notified.""" payload = {"user": pushover_user, "token": pushover_token, "message": message} status = requests.post(pushover_url, data=payload).status_code return f"Push sent, status {status}" notifier = Agent(name="Notifier", model="gpt-5.4-mini", instructions="You send the user a push message when asked", tools=[push_tool])

Step 4 · Memory: sessions第 4 步 · 记忆：Session

Learn先学

You tell Quip “My name is Mei”, then ask “What's my name?”. Each Runner.run starts fresh, just like the stateless calls in “Autonomy and tools”. Two ways to remember: by hand, pass response.to_input_list() plus the new message (the history you kept by hand before), or with a session, where the SDK stores and replays it for you.

你告诉 Quip“我叫 Mei”，然后问“我叫什么？”。每次 Runner.run 都是全新开始，和《自主性与工具》里讲的无状态调用一样。有两种记住的方式：手动，把 response.to_input_list() 加上新消息传回去（就是你之前手动维护的历史记录）；或者用 session，由 SDK 替你保存并回放。

session = SQLiteSession("mei-chat") # in memory. For a file: SQLiteSession("mei-chat", "memory.db") response = await Runner.run(agent, "Hey! I am Mei, nice to meet you.", session=session) response = await Runner.run(agent, "What's my name?", session=session)

Expected output (your wording will differ)预期输出（你的措辞会有所不同）

Nice to meet you, Mei! Your name is Mei.

Step 5 · Preview: agents working together第 5 步 · 预览：智能体如何协作

Learn先学

One agent is only the start. The next lessons combine agents in two ways, and one question tells them apart: who talks to the user next? With an agent as a tool, a manager calls another agent like a function, gets the result back and stays in control. With a handoff, one agent passes the whole conversation to another, which takes over and replies.

一个智能体只是开始。后面的课会用两种方式把智能体组合起来，用一个问题就能分辨：接下来由谁来和用户说话？智能体当工具时，主管像调用函数一样调用另一个智能体，拿回结果并继续掌控；交接（handoff）时，一个智能体把整段对话交给另一个，由后者接手并回复。

Learn先学

Guardrails are checks that can stop a run. An input guardrail checks what comes in, before the main work. An output guardrail checks what goes out, before the user sees it.

护栏（guardrail）是可以叫停运行的检查。输入护栏在主要工作开始前检查传入内容；输出护栏在用户看到之前检查传出内容。

Common errors常见错误

• ModuleNotFoundError: No module named 'agents': The package is installed as openai-agents but imported as agents. Fix: pip install openai-agents.
• RuntimeError: asyncio.run() cannot be called from a running event loop: A notebook already runs an event loop. Fix: in a notebook write await main(); in a .py file keep asyncio.run(main()).
• SyntaxError: 'await' outside function: await only works inside an async def in a script. Fix: wrap the lines in async def main().
• openai.AuthenticationError: Error code: 401: The SDK cannot find your key. Fix: put OPENAI_API_KEY in .env and call load_dotenv(override=True) before you build the agent.

• ModuleNotFoundError: No module named 'agents'：包的安装名是 openai-agents，导入名却是 agents。解决：pip install openai-agents。
• RuntimeError: asyncio.run() cannot be called from a running event loop：notebook 里已经有一个事件循环在运行。解决：notebook 里写 await main()；.py 文件里保留 asyncio.run(main())。
• SyntaxError: 'await' outside function：脚本里 await 只能写在 async def 里。解决：把这些代码放进 async def main()。
• openai.AuthenticationError: Error code: 401：SDK 找不到你的密钥。解决：把 OPENAI_API_KEY 写进 .env，并在创建智能体之前调用 load_dotenv(override=True)。

Takeaways要点回顾

• await waits for the model. Only inside async def, or at the top level of a notebook.
• An Agent is a model, instructions (the system prompt) and tools.
• Runner.run is the agent loop. final_output is the answer.
• trace shows every step. Streaming shows text as it is written.
• @function_tool builds the tool JSON from your function. The docstring is the description.
• Each run is stateless. Pass a session to remember.
• Agents as tools keep control, handoffs pass it on, guardrails check inputs and outputs.

• await 用来等模型，只能写在 async def 里，或笔记本最外层。
• Agent = 模型 + instructions（系统提示词）+ 工具。
• Runner.run 就是智能体循环，final_output 是最终答案。
• trace 展示每一步，流式输出边写边显示。
• @function_tool 根据函数生成工具 JSON，文档字符串就是描述。
• 每次运行都是无状态的，传入 session 才能记住。
• 智能体当工具会保持控制，交接会把控制权交出去，护栏检查输入和输出。
