Step 1 · Rows and columns第 1 步 · 行与列

Learn先学

Most data is a table: each row is one thing (an order, a person) and each column is one fact about it (city, amount). Before any analysis, name what one row stands for. If you cannot say it, you cannot trust any total built on it.

大多数数据是一张表：每一行代表一件事（一个订单、一个人），每一列是它的一项事实（城市、金额）。分析之前，先说清一行代表什么。说不清，就不能相信任何基于它算出来的总数。

Step 2 · CSV is a table as text第 2 步 · CSV 是文本形式的表格

Learn先学

A CSV file (comma-separated values) writes a table as plain text: one line per row, commas between columns, the first line holding the column names. Every spreadsheet can export it and every language can read it. Python’s csv.DictReader turns each row into a dictionary keyed by column name.

CSV 文件（逗号分隔值）把表格写成纯文本：每行一条记录，列之间用逗号隔开，第一行是列名。所有电子表格都能导出它，所有语言都能读它。Python 的 csv.DictReader 把每一行变成以列名为键的字典。

import csv, io text = "name,city,sales\nMei,Singapore,120\nRavi,Penang,80" rows = list(csv.DictReader(io.StringIO(text))) print(rows[0]["city"])

Takeaways要点回顾

• Name what one row stands for before anything else.
• A CSV is a table as text; DictReader gives dictionaries by column name.
• CSV values are text until you convert them.

• 先说清一行代表什么。
• CSV 是文本形式的表格；DictReader 按列名给出字典。
• CSV 的值在转换之前都是文本。
