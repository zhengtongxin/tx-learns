Grouping and counting分组与计数

Answer “how many per city” and “total per product” by grouping rows · ~10 min · reading and practice通过给行分组，回答“每个城市多少个”和“每种产品总共多少” · 约 10 分钟 · 阅读加练习

Step 1 · Group, then summarise第 1 步 · 先分组，再汇总

Learn先学

Most real questions are “per something”: sales per city, tickets per week, errors per page. The recipe is always the same: group the rows by that something, then summarise each group (count them or add a number up). In spreadsheets this is a pivot table; in Python a dictionary does it in three lines.

大多数真实问题都是“每个什么”：每个城市的销售额、每周的工单、每个页面的错误数。做法永远一样：按那个“什么”把行分组，再汇总每一组（数个数，或把某个数加起来）。电子表格里这叫数据透视表；Python 里用字典三行就能做到。

Step 2 · Count with Counter第 2 步 · 用 Counter 计数

Learn先学

collections.Counter counts how often each value appears: Counter(cities). .most_common(2) lists the top two. To total a number per group, use a dictionary: for each row add its amount to totals[city], starting from totals.get(city, 0).

collections.Counter 数每个值出现的次数：Counter(cities)。.most_common(2) 列出出现最多的前两个。要按组累加一个数，就用字典：对每一行，把金额加到 totals[city] 上，起点是 totals.get(city, 0)。

from collections import Counter rows = [("Singapore", 120), ("Penang", 80), ("Singapore", 100)] print(Counter(c for c, _ in rows)) totals = {} for city, amount in rows: totals[city] = totals.get(city, 0) + amount print(totals)

Takeaways要点回顾

• Group the rows, then summarise each group.
• Counter counts how often values appear; a dictionary totals a number.
• get(key, 0) lets a new group start at zero.

• 先给行分组，再汇总每一组。
• Counter 数值出现的次数；字典累加一个数。
• get(key, 0) 让新的一组从零开始。
