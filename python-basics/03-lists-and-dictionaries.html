Lists and dictionaries列表与字典

Hold many values in a list, label values in a dictionary, and pick the right one · ~10 min · reading and practice用列表装很多个值，用字典给值贴标签，并选对合适的那一种 · 约 10 分钟 · 阅读加练习

Step 1 · A list keeps things in order第 1 步 · 列表按顺序存放

Learn先学

A list holds several values in square brackets: ["tea", "milk"]. Items have a position, counted from 0, so shop[0] is the first and shop[-1] is the last. append adds to the end and len counts the items.

列表用方括号装着若干个值：["tea", "milk"]。每一项有位置，从 0 开始数，所以 shop[0] 是第一个，shop[-1] 是最后一个。append 在末尾追加，len 数项数。

Use a list when the order matters or when you have many of the same kind of thing.

顺序重要，或者有很多同类的东西时，用列表。

shop = ["tea", "milk"] shop.append("eggs") print(len(shop), shop[0], shop[-1]) prices = {"tea": 3, "milk": 4} prices["eggs"] = 5 print(prices["milk"], len(prices))

Step 2 · A dictionary labels values第 2 步 · 字典给值贴标签

Learn先学

A dictionary stores pairs of a key and a value in curly brackets: {"tea": 3}. You look a value up by its key, prices["tea"], instead of by a position. Setting a new key adds it, and setting an existing key replaces its value.

字典用花括号存放“键和值”的配对：{"tea": 3}。你通过键来查值，prices["tea"]，而不是通过位置。设置一个新键就是添加，设置已有的键就是替换它的值。

Use a dictionary when each value has a name, such as a record with a name and a price.

每个值都有名字时用字典，比如带名称和价格的一条记录。

Step 3 · Pick the right container第 3 步 · 选对容器

Learn先学

Ask one question: do I find things by position or by name? Position and order point to a list. A name or label points to a dictionary.

只问一个问题：我是按位置找，还是按名字找？看位置和顺序就用列表，看名字或标签就用字典。

Choose a container for each need.

为每种需求选一个容器。

Sort each one.

给每一项分类。

More practice再练一练

Now make it yours现在把它变成你的

Takeaways要点回顾

• A list is ordered and read by position from 0.
• A dictionary is read by key.
• append adds to a list; setting a key adds or replaces in a dictionary.
• Ask: position or name?

• 列表有顺序，按位置从 0 读取。
• 字典按键读取。
• append 往列表里加；给字典键赋值是添加或替换。
• 先问：按位置，还是按名字？
