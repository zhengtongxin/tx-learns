Files and JSON文件与 JSON

Read and write text files, and turn JSON text into lists and dictionaries and back · ~10 min · reading and practice读写文本文件，并在 JSON 文字与列表、字典之间互相转换 · 约 10 分钟 · 阅读加练习

Step 1 · Read and write files第 1 步 · 读写文件

Learn先学

Use with open(path, ...) as f: to work with a file. The with closes the file for you even if something fails. The mode says what you want: "r" to read (the default), "w" to write (this erases what was there) and "a" to add to the end. Give encoding="utf-8" so that 中文 and emoji survive.

用 with open(path, ...) as f: 来操作文件。with 会在用完后帮你关闭文件，哪怕中途出错。模式说明你要做什么："r" 读（默认），"w" 写（会清掉原有内容），"a" 追加到末尾。写上 encoding="utf-8"，中文和表情符号才不会乱码。

The path is relative to where you run the program, so “file not found” usually means you are in a different folder than you thought.

路径是相对于你运行程序的位置的，所以“找不到文件”通常是因为你所在的文件夹和你以为的不一样。

with open("notes.txt", "w", encoding="utf-8") as f: f.write("first line\n") f.write("second line\n") with open("notes.txt", encoding="utf-8") as f: for line in f: print(line.strip())

Step 2 · JSON is text for data第 2 步 · JSON 是数据的文字形式

Learn先学

JSON is a plain-text format for data that looks like Python dictionaries and lists. Almost every web service speaks it. json.loads(text) turns JSON text into Python values, and json.dumps(value) turns Python values into JSON text.

JSON 是一种纯文本的数据格式，长得像 Python 的字典和列表。几乎所有网络服务都使用它。json.loads(text) 把 JSON 文字变成 Python 值，json.dumps(value) 把 Python 值变成 JSON 文字。

Small differences to remember: JSON needs double quotes, and it writes true, false and null where Python writes True, False and None.

要记住几个小差别：JSON 必须用双引号，并且把 Python 的 True、False、None 写成 true、false、null。

import json raw = '{"name": "Mei", "scores": [80, 90]}' data = json.loads(raw) print(data["name"], sum(data["scores"])) print(json.dumps({"ok": True, "n": 2}))

Step 3 · Pick the right tool第 3 步 · 选对工具

Learn先学

For one-off notes, use a plain text file. For structured data you will read again, use JSON. For a spreadsheet of rows, a CSV file is the usual choice. The same rule applies to the data that your AI programs save: plain text for logs, JSON for settings and results.

一次性的笔记，用纯文本文件。以后还要读取的结构化数据，用 JSON。表格式的一行行数据，一般用 CSV。你的 AI 程序保存的数据也适用同样的规则：日志用纯文本，设置和结果用 JSON。

Takeaways要点回顾

• Use with open(...) so the file is always closed.
• "w" erases, "a" adds; add encoding="utf-8".
• json.loads reads JSON text; json.dumps writes it.
• JSON uses double quotes, true, false and null.

• 用 with open(...)，文件总会被关闭。
• "w" 清空，"a" 追加；加上 encoding="utf-8"。
• json.loads 读 JSON 文字；json.dumps 写 JSON 文字。
• JSON 用双引号，以及 true、false、null。
