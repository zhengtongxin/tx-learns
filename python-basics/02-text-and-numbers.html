Text and numbers文字与数字

Join and format text, do arithmetic, and turn text into numbers and back · ~10 min · reading and practice拼接和格式化文字，做算术，并在文字和数字之间转换 · 约 10 分钟 · 阅读加练习

Step 1 · Work with text第 1 步 · 处理文字

Learn先学

Text has built-in methods, which are actions you call with a dot: name.upper() makes capitals, name.title() capitalises each word, and len(name) counts the characters. Text values never change in place: a method gives you a new one, so store it if you want to keep it.

文字自带一些方法，也就是用点来调用的动作：name.upper() 变大写，name.title() 让每个词首字母大写，len(name) 数字符个数。文字不会原地改变：方法会返回一个新的值，想留住就要存起来。

An f-string puts values into text: write f"..." and put the value in curly brackets. It is the clearest way to build a message.

f-string 能把值放进文字里：写成 f"..."，把值放在花括号里。这是拼出一条消息最清楚的办法。

name = "mei" shout = name.upper() print(shout) print(len(name)) print(f"Hello, {name.title()}!")

Step 2 · Arithmetic第 2 步 · 算术

Learn先学

The operators are + - * /, plus // for division that drops the remainder, % for the remainder, and ** for powers. A plain / always gives a float, even for 6 / 3.

运算符有 + - * /，另外 // 是去掉余数的除法，% 取余数，** 是乘方。普通的 / 永远得到浮点数，即使是 6 / 3。

Match each job to the operator.

把每项任务配到对应的运算符。

Step 3 · Convert between text and numbers第 3 步 · 文字与数字互转

Learn先学

Input from a file, a form or a user arrives as text. To calculate with it, convert it: int("42") gives 42 and float("3.5") gives 3.5. To put a number into text, use str(42) or an f-string.

来自文件、表单或用户的输入都是文字。要拿它计算，先转换：int("42") 得到 42，float("3.5") 得到 3.5。要把数字放进文字，用 str(42) 或 f-string。

If the text is not a valid number, the conversion fails with an error. You will learn to handle that in a later lesson.

如果文字不是合法的数，转换会报错。你会在后面的课学到怎么处理。

price = "12" qty = 3 print(int(price) * qty) print(price * qty)

Takeaways要点回顾

• String methods return new text; store it to keep it.
• An f-string puts values into a sentence.
• / keeps decimals, // drops the remainder, % is the remainder.
• Convert text input with int() or float() before calculating.

• 字符串方法返回新文字；想保留就存起来。
• f-string 把值放进句子里。
• / 保留小数，// 去掉余数，% 是余数。
• 先用 int() 或 float() 转换文字输入，再计算。
