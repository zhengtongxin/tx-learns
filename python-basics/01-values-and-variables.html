Values and variables值与变量

Store values under names, change them, and print what you stored · ~10 min · reading and practice把值存在名字下，修改它们，并把存下的内容打印出来 · 约 10 分钟 · 阅读加练习

Step 1 · Run a line, read the output第 1 步 · 运行一行，读懂输出

Learn先学

A program is a list of instructions that Python carries out from top to bottom. print(...) is an instruction that shows something on the screen. Run each line and read what comes back before you move on.

程序就是一串指令，Python 从上到下依次执行。print(...) 这条指令把内容显示在屏幕上。每运行一行，先看清输出，再往下走。

Text goes inside quotes. Numbers do not. Python ignores everything after a # on a line, so you can leave notes for yourself.

文字要放在引号里，数字不用。一行里 # 后面的内容 Python 会忽略，可以用来给自己写备注。

print("Hello") print(2 + 3) # a number, no quotes print("2 + 3") # text, shown as written

Step 2 · Variables hold values第 2 步 · 变量存放值

Learn先学

A variable is a name that points to a value. age = 30 stores 30 under the name age. The single = means “store”, not “equals”. Later lines can use the name, and you can store a new value under it any time.

变量是一个指向某个值的名字。age = 30 把 30 存在名字 age 下面。单个 = 的意思是“存进去”，不是“等于”。后面的行可以使用这个名字，你也可以随时往里存新的值。

Choose names that say what the value is: total_price, not x. Names cannot start with a digit or contain spaces.

名字要说明这个值是什么：用 total_price，别用 x。名字不能以数字开头，也不能含空格。

age = 30 name = "Mei" print(name, age) age = age + 1 print(age)

Step 3 · Every value has a type第 3 步 · 每个值都有类型

Learn先学

Every value has a type. The four to know first are int (whole numbers), float (numbers with a decimal point), str (text) and bool (True or False). type(x) tells you which one you have.

每个值都有类型。最先要认识四种：int（整数）、float（带小数点的数）、str（文字）和 bool（True 或 False）。type(x) 会告诉你它是哪一种。

Types decide what you can do: you can add two numbers, but adding a number to text is an error. Sort each value by its type.

类型决定你能做什么：两个数可以相加，但把数字和文字相加会报错。给每个值按类型分类。

Sort each one.

给每一项分类。

More practice再练一练

Now make it yours现在把它变成你的

Takeaways要点回顾

• A program runs top to bottom; print shows a value.
• A variable is a name for a value; = stores it.
• Four first types: int, float, str, bool.
• You cannot add text and a number with +.

• 程序从上到下运行；print 显示一个值。
• 变量是值的名字；= 表示存进去。
• 最先要认识的四种类型：int、float、str、bool。
• 不能用 + 把文字和数字相加。
