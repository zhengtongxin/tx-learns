Decisions and loops判断与循环

Step 1 · Choose with if第 1 步 · 用 if 做选择

Learn先学

An if runs its block only when a condition is true. Add elif for more cases and else for everything left. Conditions use comparisons such as >, <, == (equal) and != (not equal). A single = stores, a double == compares.

if 只在条件为真时才运行它的代码块。要加情况用 elif，剩下的全部用 else。条件用比较符，如 >、<、==（等于）和 !=（不等于）。单个 = 是存值，双 == 才是比较。

The block is the lines indented under the if. Indentation is how Python knows what belongs inside.

代码块就是 if 下面缩进的那些行。Python 靠缩进来判断哪些属于里面。

score = 72 if score >= 80: grade = "A" elif score >= 60: grade = "B" else: grade = "C" print(grade)

Step 2 · Repeat with for第 2 步 · 用 for 重复

Learn先学

A for loop runs its block once for each item in a list. The loop variable takes the next item each time. Combine it with an if inside to filter, and with a variable outside to add things up.

for 循环对列表里的每一项各运行一次代码块。循环变量每次取下一项。里面配合 if 可以筛选，外面配合变量可以累加。

Read the loop below line by line before you run it.

运行之前，先一行一行读懂下面这个循环。

total = 0 for n in [3, 5, 8]: if n > 4: total = total + n print(total)

Step 3 · Repeat with while第 3 步 · 用 while 重复

Learn先学

A while loop repeats as long as its condition stays true. Something inside the loop must change the condition, or it never stops. Use for when you know what to go through, and while when you repeat until something happens.

while 循环在条件一直为真时重复。循环里面必须有东西改变条件，否则永远停不下来。知道要遍历什么时用 for，要一直重复直到某件事发生时用 while。

Takeaways要点回顾

• if, elif and else pick one path; == compares, = stores.
• Indentation marks what is inside.
• for goes through a list; while repeats until something changes.
• A while loop needs something that makes it stop.

• if、elif、else 选一条路径；== 比较，= 存值。
• 缩进标出哪些在里面。
• for 遍历列表；while 一直重复到某件事改变。
• while 循环里必须有让它停下来的东西。
