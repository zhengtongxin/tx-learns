Errors and debugging报错与调试

Read an error message, catch errors you expect, and track down a bug step by step · ~10 min · reading and practice读懂报错信息，捕获你预料到的错误，并一步步查出 bug · 约 10 分钟 · 阅读加练习

Step 1 · Read the error第 1 步 · 读懂报错

Learn先学

When Python fails it prints a traceback. Read it from the bottom: the last line names the kind of error and says what went wrong, and the lines above point to the file and line number. Most errors are one of a few kinds: NameError (a name that does not exist), TypeError (the wrong type for an operation), ValueError (the right type, a bad value) and IndexError or KeyError (a missing position or key).

Python 出错时会打印一份 traceback。要从最后一行往上读：最后一行说明错误的种类和出了什么问题，往上几行指出文件和行号。大多数错误就是那么几种：NameError（用了不存在的名字）、TypeError（运算用错了类型）、ValueError（类型对但值不对）、IndexError 或 KeyError（位置或键不存在）。

Match each message to its cause.

把每条信息配到它的原因。

Sort each one.

给每一项分类。

Step 2 · Catch what you expect第 2 步 · 捕获预料中的错误

Learn先学

If a line may fail in a way you can predict, wrap it in try and name the error in except. The program then carries on instead of stopping. Name the specific error, such as ValueError, so a different, unexpected error is still shown.

如果某一行可能以你能预料的方式失败，就把它包进 try，并在 except 里写出具体的错误。这样程序会继续运行而不是停下来。要写具体的错误名，比如 ValueError，这样别的、没预料到的错误仍然会显示出来。

Do not hide every error with a bare except: you would lose the clue that tells you what is wrong.

不要用一个什么都接的 except 把所有错误都藏起来：你会丢掉提示你哪里出错的线索。

def to_int(text): try: return int(text) except ValueError: return None print(to_int("42")) print(to_int("forty"))

Step 3 · Find the bug第 3 步 · 找出 bug

Learn先学

A bug is code that does not do what you meant. Find it by narrowing down: print the values at key points, check each step against what you expected, and test the smallest input that fails. Change one thing at a time and run again.

bug 就是没有按你的本意工作的代码。用缩小范围的办法去找：在关键位置打印出值，对照预期检查每一步，并用最小的会失败的输入来测。每次只改一处再运行。

Say what you expect before you run. When the result differs, you have found where to look.

运行之前先说出你预期的结果。结果和预期不同的地方，就是该查的地方。

def average(nums): total = 0 for n in nums: total = total + n return total / len(nums) print(average([4, 6])) # expect 5.0 print(average([])) # what happens?

Takeaways要点回顾

• Read a traceback from the bottom: the last line names the error.
• Catch a specific, expected error with try and except.
• Do not hide all errors with a bare except.
• Find bugs by narrowing down, one change at a time.

• traceback 从下往上读：最后一行写着错误名。
• 用 try 和 except 捕获具体的、预料中的错误。
• 不要用一个什么都接的 except 藏起所有错误。
• 用缩小范围的办法找 bug，每次只改一处。
