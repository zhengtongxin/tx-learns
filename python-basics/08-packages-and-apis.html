Packages and APIs包与 API

Install a package, call a web API for data, and keep your key out of the code · ~10 min · reading and practice安装一个包，调用网络 API 取数据，并把密钥放在代码之外 · 约 10 分钟 · 阅读加练习

Step 1 · Use other people’s code第 1 步 · 使用别人写好的代码

Learn先学

A package is code written by someone else that you can use. Python ships with many (json, os, math) and you add more with pip install name in a terminal. Then import name at the top of your file makes it available.

包是别人写好、你可以直接用的代码。Python 自带很多（json、os、math），其余的在终端里用 pip install 包名 来装。然后在文件开头写 import 包名 就能用了。

Use a virtual environment per project, a private folder of packages, so one project’s versions do not clash with another’s: python -m venv .venv.

每个项目用一个虚拟环境，也就是一个私有的包文件夹，这样一个项目的版本不会和另一个冲突：python -m venv .venv。

python -m venv .venv source .venv/bin/activate # Windows: .venv\Scripts\activate pip install requests python my_script.py

Step 2 · Call a web API第 2 步 · 调用网络 API

Learn先学

An API is a way for your program to ask another service for something. With the requests package you send a request to a URL and get a reply, usually JSON. Check the status first: 200 means success, 401 or 403 means your key was refused, 404 means not found.

API 是让你的程序向另一个服务索取东西的方式。用 requests 包向一个网址发请求，就会得到回复，通常是 JSON。先看状态码：200 表示成功，401 或 403 表示密钥被拒绝，404 表示找不到。

Always set a timeout, so a slow service cannot freeze your program forever.

一定要设置 timeout，这样慢的服务不会让你的程序永远卡住。

import requests url = "https://api.example.com/weather" reply = requests.get(url, params={"city": "Singapore"}, timeout=10) reply.raise_for_status() # stops here if the status is an error data = reply.json() # JSON text becomes a dictionary print(data["temperature"])

Step 3 · Keep secrets out of code第 3 步 · 把机密放在代码之外

Learn先学

Many APIs need a key, a secret that proves it is you and may cost money. Never type it into your code or commit it to a shared repository. Put it in an environment variable and read it with os.environ, so the code stays safe to share.

很多 API 需要一把密钥，那是证明“是你”的机密，用量还可能要花钱。千万不要把它写进代码，也不要提交到共享仓库。把它放进环境变量，用 os.environ 读取，这样代码就可以放心分享。

Decide what belongs in the code and what does not.

判断哪些该放进代码，哪些不该。

import os key = os.environ.get("TX_SURELY_UNSET", "fallback") print(key)

Sort each one.

给每一项分类。

More practice再练一练

Now make it yours现在把它变成你的

Takeaways要点回顾

• pip install adds a package; import uses it.
• Use a virtual environment per project.
• Check the status, set a timeout, then read the JSON.
• Keys live in environment variables, never in code.

• pip install 添加一个包；import 使用它。
• 每个项目一个虚拟环境。
• 先看状态码，设超时，再读 JSON。
• 密钥放环境变量，不要写进代码。
