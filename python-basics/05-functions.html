Functions函数

Wrap steps in a function, pass values in, and get a result back with return · ~10 min · reading and practice把步骤包进函数，传值进去，再用 return 取回结果 · 约 10 分钟 · 阅读加练习

Step 1 · Define once, call many times第 1 步 · 定义一次，调用多次

Learn先学

A function is a named block of steps. def defines it, and the indented lines are its body. Nothing runs until you call it by name with brackets. Functions save you from copying the same lines again and again, and give each idea a name.

函数是一段有名字的步骤。def 用来定义它，缩进的那些行是函数体。只有用名字加括号去调用它，它才会运行。函数让你不必一遍遍复制同样的几行，也给每个想法起了名字。

A good function does one job, and its name says which: add_tax, clean_name.

好的函数只做一件事，名字说明是哪件：add_tax、clean_name。

def add_tax(price, rate=0.09): return round(price * (1 + rate), 2) print(add_tax(10)) print(add_tax(10, 0.1))

Step 2 · Parameters and return第 2 步 · 参数与 return

Learn先学

Parameters are the names a function gives to the values you pass in. A parameter can have a default, used when you leave it out, like rate=0.09. return sends a result back to the caller, who can store it or print it.

参数是函数给你传进来的值起的名字。参数可以有默认值，你不传时就用它，比如 rate=0.09。return 把结果送回给调用的人，对方可以存起来或打印出来。

print only shows something on the screen. return hands a value back. A function with no return gives back None.

print 只是把东西显示在屏幕上，return 是把一个值交回去。没有 return 的函数交回的是 None。

Step 3 · Return or print第 3 步 · return 还是 print

Learn先学

If another line of code needs the answer, return it. If a person needs to read it, print it, ideally outside the function. A function that returns can be reused anywhere, while one that only prints cannot be calculated with.

如果别的代码要用这个结果，就 return。如果是要给人看，就 print，最好放在函数外面。会 return 的函数可以到处复用，只会 print 的函数则不能拿去计算。

Decide which one each situation needs.

判断每种情况需要哪一种。

Sort each one.

给每一项分类。

Takeaways要点回顾

• def defines a function; calling it runs it.
• Parameters take values in; defaults fill gaps.
• return hands a value back; print only displays.
• One function, one job, a clear name.

• def 定义函数；调用它才会运行。
• 参数接收传入的值；默认值补上空缺。
• return 把值交回去；print 只是显示。
• 一个函数一件事，名字要清楚。
