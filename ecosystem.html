      03Recent activity最近动态

        The agents check, the checks decide. Every change is one pull request that merges by itself only when every check is green. If a merge breaks the site, it is undone by itself; if something gets stuck, I hear about it once.Agent 负责检查，检查结果说了算。每个改动是一个 pull request，只有全部检查通过才会自动合并。如果某次合并弄坏了网站，它会被自动撤销；如果卡住了，我会收到一次通知。
