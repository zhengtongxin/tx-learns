  2. 2

    1. 1Notes. Raw notes in a folder called agent-runtime-in-minutes.笔记。一个叫 agent-runtime-in-minutes 的文件夹，里面是原始笔记。
    2. 2First draft. The content creator agent wrote the lesson in the site's story voice.第一版。内容创作者 agent 用网站的讲故事口吻写成这一课。
    3. 3The intern got lost. It added plain-word help where a newcomer would stall. Three of its changes:实习生读不懂的地方。它在新手会卡住的地方补上大白话。其中三处：
    Before之前

    An agent with a system prompt.一个带系统提示词的智能体。

    After之后

    An agent with a system prompt (the standing instructions that tell it who it is and how to answer).一个带系统提示词（先给它的一段固定指示，告诉它是谁、该怎么回答）的智能体。

    Before之前

    …and a data-models library.……和一个数据模型库。

    After之后

    …and a data-models library (pydantic, which checks that your data has the right shape).……和一个数据模型库（pydantic，检查你的数据形状对不对）。

    Before之前

    Switch on observability in the console, so that traces can be recorded later.在控制台里打开可观测性，这样之后才能记录调用轨迹。

    After之后

    Switch on observability in the console. The service then keeps a record of each call, called a trace, that you can read later.在控制台里打开可观测性。服务会记下每次调用的过程，这份记录叫轨迹，之后可以读。

    1. 4The usual checks. The same checks as every change ran, and auto-merge published it once the two required checks were green.照常检查。和每个改动一样的检查跑了一遍，两项必需检查都通过后，自动合并把它发布了。
    2. 5What checks cannot catch. They see wording, code, links and rules. Whether the lesson teaches what I actually need is still my own read.检查查不到的。它们看得到措辞、代码、链接和规则。这一课是不是教了我真正需要的东西，还得我自己读。
