Progress and closing进展与收尾

Report progress with a few plain numbers, handle changes in the open and close the project properly · ~10 min · reading and practice用几个简单的数字汇报进展，公开处理变更，并把项目好好收尾 · 约 10 分钟 · 阅读加练习

Step 1 · Track progress simply第 1 步 · 简单跟踪进展

Learn先学

Check progress against the plan at regular points, in percentages. Count what is truly done, not “almost done”. If 8 of 20 tasks are done and the plan said 10 should be, you are at 40% against 50% planned, so you are behind. A plain number gives an early warning while there is still time to act.

在固定的时间点，用百分比对照计划检查进展。数真正完成的，不数“差不多完成”。如果 20 个任务完成了 8 个，而计划是应该完成 10 个，那么你是 40%，计划是 50%，落后了。一个简单的数字能在还有时间采取行动时发出预警。

Step 2 · Handle changes openly第 2 步 · 公开处理变更

Learn先学

Changes will come. A change request is a formal ask to change what the project delivers. Do not let one slip in without the plan changing. For each change request, write down what it is, what it does to time, cost and risk, and who decides. If it is approved, update the plan so everyone works from the same version. If not, say so and why. A written trail avoids “I thought we agreed”.

变更总会来。不要悄悄吞下。变更请求是要求改变项目交付内容的正式请求。对每个变更请求，写下它是什么、对时间、成本和风险有什么影响、由谁决定。批准了，就更新计划，让大家依据同一个版本工作；没批准，就说明并解释原因。有书面记录，就不会出现“我还以为我们说好了”。

Is each one good practice or weak practice?

每一项是好做法，还是薄弱的做法？

Step 3 · Close and learn第 3 步 · 收尾与总结

Learn先学

A project is not finished until it is closed. Hand over the result to the people who will use it, with what they need to run it. Check the goal against the result. Hold a short lessons-learned session: what worked, what did not, what to do next time. Tell the team the work is done, and thank them. If you want to go further, the PMP track (a project management exam track on this site) builds on exactly these ideas.

项目收了尾才算结束。把成果交给要用它的人，并附上他们运行所需的东西。对照目标检查结果。开一个简短的经验总结会：什么有效，什么无效，下次怎么做。告诉团队工作已经完成，并感谢他们。想更进一步，PMP 路线（本站的项目管理考试路线）正是在这些想法的基础上展开的。

Takeaways要点回顾

• Count only what is fully done.
• Compare progress with the plan at regular points.
• Handle changes openly and update the plan.
• Close with a handover and a goal check.
• Hold a lessons-learned session.

• 只数完全完成的。
• 定期对照计划检查进展。
• 公开处理变更并更新计划。
• 用交接和目标核对来收尾。
• 开一次经验总结会。
