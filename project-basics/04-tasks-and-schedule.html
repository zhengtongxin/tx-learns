Tasks and schedule任务与进度

Break the work into tasks, put them in order and find the chain of tasks that sets the finish date · ~10 min · reading and practice把工作拆成任务，排好顺序，并找出决定完成日期的那条任务链 · 约 10 分钟 · 阅读加练习

Step 1 · Break it into tasks第 1 步 · 拆成任务

Learn先学

Split the work until each piece is small enough to estimate and give to one person, for example “order the parts”, not “build the thing”. Estimate each task in time, and ask the person who will do it. Add up the estimates and you have the total effort. The finish date comes from the order of the tasks, which the next steps cover.

把工作拆到每一块都小到可以估算、可以交给一个人，比如“订购零件”，而不是“把东西做出来”。估算每个任务的时间，并请要做的人来估。把估算加起来，就得到总工作量。完成日期取决于任务的顺序，后面的步骤会讲。

Step 2 · Order and dependencies第 2 步 · 顺序与依赖

Learn先学

Some tasks cannot start until another finishes: you cannot test before you build. That is a dependency. Name a path by its tasks in order, so A-B-D means A, then B, then D. Draw the tasks in order, with arrows from each task to the ones that wait for it. Tasks that do not depend on each other can run in parallel, which saves time.

有些任务必须等另一个完成才能开始：没做出来就没法测试。这就是依赖关系。路径用任务的顺序来命名，A-B-D 就是先 A，再 B，再 D。按顺序画出任务，用箭头从每个任务指向等它的任务。互不依赖的任务可以并行，这样能省时间。

Is each one good practice or weak practice?

每一项是好做法，还是薄弱的做法？

Step 3 · The critical path第 3 步 · 关键路径

Learn先学

The critical path is the longest chain of dependent tasks, and it sets the earliest finish date. A delay on it delays the whole project. Tasks off the path have float: spare time they can slip without moving the end. Watch the critical path closely, and add a small buffer for surprises.

关键路径是依赖任务中最长的那条链，它决定最早的完成日期。关键路径上的任务延误，整个项目就会延误。路径之外的任务有浮动时间：可以拖一点而不影响终点。要盯紧关键路径，并为意外留一点缓冲。

Task Days Starts after A Plan 2 - B Build 3 A C Order parts 4 A D Test 1 B and C A-B-D = 2+3+1 = 6 days A-C-D = 2+4+1 = 7 days <- critical path B has 1 day of float

Takeaways要点回顾

• Break work into tasks small enough to estimate.
• A dependency means one task waits for another.
• The critical path is the longest chain and sets the end date.
• Tasks off the path have float.
• Add a small buffer for surprises.

• 把工作拆到小得可以估算。
• 依赖关系是一个任务等另一个。
• 关键路径是最长的链，决定完成日期。
• 路径之外的任务有浮动时间。
• 给意外留一点缓冲。
