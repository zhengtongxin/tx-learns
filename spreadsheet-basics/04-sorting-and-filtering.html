Sorting and filtering排序与筛选

Reorder a table without scrambling it, show only the rows you need and keep the originals safe · ~10 min · reading and practice在不弄乱表格的前提下重新排序，只显示需要的行，并保护好原始数据 · 约 10 分钟 · 阅读加练习

Step 1 · Sort whole rows第 1 步 · 整行一起排序

Learn先学

Sorting reorders the rows by one column, such as amount from largest to smallest. Select the whole table (click any cell inside the table and the program usually selects the whole block) so each row moves as one piece. If only one column is sorted, the values slide away from their partners and the table tells lies.

排序是按某一列给各行重新排序，比如按金额从大到小。要选中整张表（点一下表里任意单元格，程序通常会自动选中整块），这样每一行作为一个整体移动。如果只排了一列，数值就会与同行的其他内容错位，表格就在说谎。

Step 2 · Filter, do not delete第 2 步 · 筛选，而不是删除

Learn先学

A filter hides the rows that do not match, such as amount above 4, and leaves the data in place. Clear the filter and everything is back. Deleting rows to “tidy up” is permanent. Be careful with totals: SUM still adds hidden rows. If you want a total of only the rows you can see, use =SUBTOTAL(109,B2:B6): the 109 tells it to add and to skip hidden rows.

筛选会隐藏不符合条件的行，比如金额大于 4，数据仍在原处。清除筛选后一切恢复。为了“整理”而删除行是永久的。求合计要当心：SUM 仍然会加上被隐藏的行。如果只想合计看得见的行，用 =SUBTOTAL(109,B2:B6)：其中的 109 表示求和并跳过隐藏行。

Sort each one.

给每一项分类。

Step 3 · Work on a copy第 3 步 · 在副本上操作

Learn先学

Before a big sort or clean-up, save a copy of the file or add a column that numbers the original order (1, 2, 3...). Then you can always return to how the data arrived.

在大规模排序或清理之前，先另存一份文件，或加一列给原始顺序编号（1、2、3……）。这样你随时能回到数据最初的样子。

Takeaways要点回顾

• Sort whole rows together.
• Filter instead of deleting.
• Keep a copy of the original.

• 整行一起排序。
• 用筛选，而不是删除。
• 保留一份原始副本。
