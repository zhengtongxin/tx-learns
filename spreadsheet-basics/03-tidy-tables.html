Tidy tables整洁的表格

Lay data out as one row per record and one column per property, so sorting, filtering and formulas just work · ~10 min · reading and practice把数据排成一行一条记录、一列一种属性，让排序、筛选和公式都能顺利工作 · 约 10 分钟 · 阅读加练习

Step 1 · One row, one record第 1 步 · 一行一条记录

Learn先学

A tidy table has a header row, then one row for each thing you record, such as one sale. Each column is one property of it: date, item, amount. Put each fact in its own cell, and do not leave blank rows or columns in the middle, because tools read a gap as the end of the data.

整洁的表格有一行表头，之后每条记录占一行，比如一笔销售。每一列是它的一种属性：日期、品名、金额。每个事实放进自己的单元格，中间不要留空行或空列，因为工具会把空白当成数据的结尾。

Step 2 · One kind of value per column第 2 步 · 一列一种值

Learn先学

Keep a column to one kind of value in one format: all dates written the same way, all amounts as plain numbers in the same unit. Do not mix “3” and “three dollars” in one column, and do not put notes inside number cells. Put notes in a separate column.

一列只放一种值，格式统一：所有日期写法一致，所有金额都是同一单位的纯数字。不要在一列里混用“3”和“三元”，也不要在数字单元格里夹带备注，备注放进单独的一列。

Sort each one.

给每一项分类。

Step 3 · Keep the layout plain第 3 步 · 让版面保持朴素

Learn先学

Merged cells (one cell stretched across several), totals in the middle of the data and colour used as the only label all confuse sorting, filtering and formulas. Keep totals in a separate place above or beside the table, and write what a colour means in its own column if it matters.

合并单元格（一个格子横跨好几格）、夹在数据中间的合计、只靠颜色当标签，都会让排序、筛选和公式出错。把合计放在表格上方或旁边的单独位置；如果颜色有意义，就把含义写进单独的一列。
