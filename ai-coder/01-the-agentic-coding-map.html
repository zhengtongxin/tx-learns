Step 1 · From autocomplete to agents第 1 步 · 从补全到智能体

Learn先学

AI coding tools come in three levels. Autocomplete finishes the line you are typing. Chat answers questions and writes a snippet you paste in. An agent does the work itself: it reads your files, edits them, runs commands and checks the result.

AI 编程工具分三个层次。补全帮你写完正在敲的那一行。对话回答问题、给你一段代码让你自己粘贴。智能体自己动手：读你的文件、改文件、运行命令、检查结果。

The jump is the last one. An agent has tools (read a file, edit a file, run a command) and keeps going until the task is done or it gets stuck.

真正的跳跃在最后一步。智能体手里有工具（读文件、改文件、运行命令），会一直做到任务完成或卡住为止。

Step 2 · The loop an agent runs第 2 步 · 智能体的循环

Learn先学

Every agent runs the same loop: read the relevant files, plan a change, edit, run something (tests, the app), then check the output and go round again.

每个智能体都在跑同一个循环：读相关文件、计划一处改动、编辑、运行点什么（测试、应用），再检查输出，然后再来一轮。

Your job moves from typing code to setting the goal, giving a way to check, and judging the result. A goal with a check ("make npm test pass") works far better than a goal without one ("make it better").

你的工作从敲代码，变成定目标、给出检查办法、评判结果。带检查的目标（“让 npm test 通过”）远比不带检查的目标（“做得更好”）有效。

Step 3 · Steer by feel, or by design第 3 步 · 凭感觉，还是靠设计

Learn先学

Vibe coding means describing what you want and judging the result by running it, without reading every line. It is great for throwaway tools, prototypes and learning.

Vibe coding（凭感觉编程）是说出你想要什么，靠运行结果来判断，不逐行阅读代码。适合一次性小工具、原型和学习。

Vibe engineering keeps you as the owner: you set the design, read the diff and insist on tests. Agentic engineering goes one step further and designs systems of agents with limits, checks and a person approving risky steps.

Vibe engineering（专业级氛围工程）里你仍然是负责人：你定设计、读改动、坚持要有测试。智能体工程再进一步：设计一群智能体，带限制、带检查，高风险的步骤由人批准。

The more a mistake costs, the more you move from feel towards design. This track walks that road in three stages.

出错的代价越大，就越要从“凭感觉”走向“靠设计”。这条路线分三个阶段，带你走完这段路。

Takeaways要点回顾

• Autocomplete finishes lines, chat answers, an agent acts with tools.
• An agent loops: read, plan, edit, run, check.
• Vibe coding suits throwaway work; engineering suits work that must last.
• The costlier a mistake, the more you design instead of feel.

• 补全写完一行，对话给出回答，智能体用工具动手做。
• 智能体循环：读、计划、改、运行、检查。
• 凭感觉编程适合用完即弃的活；要长久的活要靠工程。
• 出错越贵，就越要设计而不是凭感觉。
