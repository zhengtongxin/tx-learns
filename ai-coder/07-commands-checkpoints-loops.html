Commands, checkpoints and loops命令、检查点与循环

Reuse prompts as commands, undo safely with checkpoints, and run the same brief in a loop · ~12 min · hands-on把常用提示词做成命令，用检查点放心撤销，让同一份简报循环运行 · 约 12 分钟 · 动手做

Step 1 · Commands you reuse第 1 步 · 可复用的命令

Learn先学

Built-in slash commands manage the session: clear it, compact it to free space, check cost, list what is loaded. Learn the few you use daily.

内置的斜杠命令用来管理会话：清空、压缩以腾出空间、查看花费、列出已加载的内容。先学会每天用的那几个。

You can also save a prompt you repeat as your own command: in Claude Code, a Markdown file in .claude/commands/ becomes /name. Commit it, and the whole team gets it.

你也可以把重复用的提示词存成自己的命令：在 Claude Code 里，.claude/commands/ 下的一个 Markdown 文件就变成 /名字。提交进仓库，整个团队都能用。

Review the changes on this branch against main. Check: tests exist for new logic, no secrets, no new dependency without a reason. Reply with a short list: must fix, should fix, fine.

Step 2 · Checkpoints: safe to try第 2 步 · 检查点：放心去试

Learn先学

A checkpoint is a save point you can return to. Some agents save one automatically before each edit, so you can rewind a bad turn. These cover the agent's file edits, not everything a command did to the outside world.

检查点是可以回到的存档。有些智能体在每次编辑之前自动存一个，所以坏的一轮可以倒回去。它们只覆盖智能体对文件的编辑，不包括命令对外部世界做的事。

The reliable checkpoint is git. Commit before a risky task, and again after each step that works. If it goes wrong, you step back one commit and lose nothing.

最可靠的检查点是 git。风险大的任务之前先提交一次，每一步成功之后再提交。出了岔子，退一个提交，什么也不损失。

Step 3 · The loop: same brief, fresh agent第 3 步 · 循环：同一份简报，全新的智能体

Learn先学

A Ralph loop runs an agent again and again on the same brief file. Each round starts fresh, so context never gets muddy, and the progress lives in files and git, not in memory.

Ralph 循环是让智能体对同一份简报文件一遍遍地运行。每一轮都全新开始，上下文不会变乱；进度存在文件和 git 里，不在记忆里。

It works when the brief has a checklist the agent ticks off and a test that tells it when it is done. Always set a round limit and watch the cost.

它适用的前提是：简报里有智能体逐项勾掉的清单，和一个告诉它“做完了”的测试。一定要设轮数上限，并盯着花费。

#!/usr/bin/env bash # Same brief, fresh agent each round. Stop when TODO.md has no unchecked boxes. for round in 1 2 3 4 5 6 7 8; do claude -p "$(cat PROMPT.md)" --allowedTools "Edit" "Bash(npm test:*)" git add -A && git commit -m "round $round" --allow-empty -q grep -q '\[ \]' TODO.md || break done

Takeaways要点回顾

• Slash commands manage the session; your own commands reuse prompts.
• Checkpoints cover agent edits; git is the one you trust.
• A Ralph loop = same brief, fresh agent, progress in files.
• Loops need a checklist, a test, a round limit and a cost watch.

• 斜杠命令管理会话；自己的命令复用提示词。
• 检查点覆盖智能体的编辑；你最信得过的是 git。
• Ralph 循环 = 同一份简报、全新的智能体、进度放在文件里。
• 循环需要清单、测试、轮数上限和花费监控。
