Step 1 · What JSON looks like第 1 步 · JSON 长什么样

Learn先学

JSON is plain text that holds structured data. It has objects in braces {} with "key": value pairs, lists in brackets [], and values that are strings, numbers, true, false or null. Keys and strings use double quotes only. No trailing commas and no comments.

JSON 是装着结构化数据的纯文本。花括号 {} 里是 "键": 值 的对象，方括号 [] 里是列表，值可以是字符串、数字、true、false 或 null。键和字符串只能用双引号。不允许末尾多余的逗号，也不允许注释。

{ "id": 42, "items": ["tea", "cake"], "paid": true, "note": null }

Step 2 · JSON and Python第 2 步 · JSON 与 Python

Learn先学

In Python the json module converts both ways: json.loads(text) turns JSON text into dictionaries and lists, and json.dumps(data) turns them back into text. true becomes True and null becomes None.

在 Python 里，json 模块能双向转换：json.loads(文本) 把 JSON 文本变成字典和列表，json.dumps(数据) 再变回文本。true 会变成 True，null 会变成 None。

import json text = '{"id": 42, "items": ["tea", "cake"], "paid": true}' order = json.loads(text) print(order["items"][1], order["paid"])

Step 3 · Common slips第 3 步 · 常见的小错

Learn先学

Most “invalid JSON” errors are the same few slips: single quotes, a trailing comma, an unquoted key, or a comment. A parser refuses the whole text for any of them, so read the error’s position.

大多数“JSON 无效”都是那几个小错：单引号、末尾多余的逗号、没加引号的键，或写了注释。解析器会因其中任何一个拒绝整段文本，所以看一下报错指出的位置。
