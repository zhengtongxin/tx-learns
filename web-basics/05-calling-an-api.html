Make a request from code, check the status, read the JSON and handle a failure · ~10 min · reading and practice用代码发出请求，检查状态，读取 JSON，并处理失败 · 约 10 分钟 · 阅读加练习

Step 1 · A first call第 1 步 · 第一次调用

Learn先学

With the requests package a call is a few lines: pick the method, pass the URL, read the answer. response.status_code is the number and response.json() turns the body into Python data. Always check the status before using the body.

用 requests 包，一次调用只要几行：选方法、传网址、读结果。response.status_code 是状态码，response.json() 把正文变成 Python 数据。使用正文之前，一定要先检查状态。

import requests r = requests.get( "https://api.example.com/menu/tea", params={"size": "large"}, timeout=10, ) if r.status_code == 200: print(r.json()["price"]) else: print("failed:", r.status_code)

Step 2 · Sending data第 2 步 · 发送数据

Learn先学

To create something, send a POST with a JSON body: requests.post(url, json=data) sets the Content-Type header and writes the JSON for you. Add a timeout to every call so a slow server cannot hang your program forever.

要创建东西，就发送带 JSON 正文的 POST：requests.post(url, json=data) 会替你设好 Content-Type 头并写出 JSON。每次调用都加上超时，这样慢吞吞的服务器就不会让你的程序永远卡住。

Step 3 · When it fails第 3 步 · 失败的时候

Learn先学

Networks fail. Wrap the call so a failure becomes a clear message, not a crash: check the status, catch exceptions such as a timeout, and for 5xx or 429 retry a few times with a growing pause.

网络是会失败的。把调用包起来，让失败变成一条清楚的信息，而不是崩溃：检查状态，捕获超时等异常；遇到 5xx 或 429，用逐渐变长的间隔重试几次。

Takeaways要点回顾

• Check the status before reading the body.
• Use json= to send JSON and always set a timeout.
• Retry 5xx and 429; fix 401 and 404.

• 读取正文之前先检查状态。
• 用 json= 发送 JSON，并始终设置超时。
• 重试 5xx 和 429；修正 401 和 404。
