Step 1 · Turn a good prompt into a template第 1 步 · 把好提示词变成模板

Learn先学

When a prompt works, do not throw it away. Mark the parts that change each time with brackets and keep the parts that stay the same. Next time you only fill in the blanks.

一条提示词好用，别丢掉。把每次会变的部分用括号标出来，不变的部分保留。下次只需要填空。

Fixed parts are usually the role, the format and the limits. Blanks are usually the task details and the pasted material.

不变的部分通常是角色、格式和限制；要填的空通常是任务细节和粘贴的材料。

Sort these parts of a meeting-summary prompt.

把一条会议纪要提示词的各部分分类。

Summarise the meeting notes below for [READER]. Use [NUMBER] bullet points, then list the actions with owners. If something is not stated, write "unclear". Notes: ----- [PASTE NOTES] -----

Sort each one.

给每一项分类。

Step 2 · Keep a short list第 2 步 · 留一份简短清单

Learn先学

Keep five to ten templates for jobs you repeat: a weekly update, a reply to a common question, a study summary. For each, note a name, when to use it and the last change that helped. A short list you use beats a long list you forget.

为反复要做的事保留五到十个模板：每周汇报、常见问题的回复、学习小结。每个记下名字、什么时候用，以及上次起作用的改动。一份你真在用的短清单，胜过一份你会忘的长清单。

A notes app or a shared document is enough. No tool is needed.

记事本或共享文档就够了，不需要任何专门工具。

Step 3 · Test, improve and prune第 3 步 · 测试、改进、精简

Learn先学

Try a template on new input before you trust it. If an answer misses, change the template, not just that one answer, so the fix helps next time. Once in a while delete templates you have stopped using.

在信任一个模板之前，先在新输入上试一试。如果答案不对，改模板，而不是只改那一个答案，这样下次也受益。偶尔删掉你已经不用的模板。

Remember that tools and their settings change, so a template that worked last year may need a tweak.

别忘了工具和它们的设置会变，去年好用的模板，今年可能需要微调。

Takeaways要点回顾

• Keep what works as a template with bracketed blanks.
• Fixed parts: role, format, limits. Blanks: details and material.
• A short list you use beats a long list you forget.
• Test on new input and improve the template, not one answer.

• 把好用的留成带括号空格的模板。
• 固定部分：角色、格式、限制；要填的空：细节和材料。
• 真在用的短清单，胜过会遗忘的长清单。
• 在新输入上测试，改进模板，而不是只改一个答案。
