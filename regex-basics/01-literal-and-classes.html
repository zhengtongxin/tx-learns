Step 1 · Shape, not spelling第 1 步 · 看形状，不看拼写

Learn先学

Searching for “2024” finds one year. A regular expression (regex) describes a shape: “four digits in a row” finds every year, phone prefix and order number at once. It is a tiny language for text patterns, and almost every programming language and editor understands it. In Python it lives in the re module.

搜索“2024”只能找到一个年份。正则表达式（regex）描述的是一种形状：“连续四个数字”能一次找出所有年份、电话前缀和订单号。它是一种描述文本模式的小语言，几乎所有编程语言和编辑器都认识它。在 Python 里它位于 re 模块。

Step 2 · Literal characters and classes第 2 步 · 普通字符与字符类

Learn先学

Most characters match themselves: cat matches “cat”. Special ones stand for a class of characters: \d any digit, \w a letter, digit or underscore, \s a space or tab, and . any one character. Square brackets make your own class: [aeiou] any vowel, [0-9] a digit. Write patterns as raw strings, r"\d", so Python leaves the backslash alone.

大多数字符匹配它们自己：cat 匹配“cat”。特殊符号代表一类字符：\d 任意数字，\w 字母、数字或下划线，\s 空格或制表符，. 任意一个字符。方括号可以自定义字符类：[aeiou] 任意元音，[0-9] 一个数字。模式要写成原始字符串 r"\d"，这样 Python 不会动反斜杠。

import re print(re.search(r"\d\d", "room 42")) print(re.search(r"[aeiou]", "rhythm and blues").group())

Takeaways要点回顾

• A regex describes the shape of text, not exact words.
• \d, \w, \s and . each stand for a class of characters.
• Write patterns as raw strings: r"\d".

• 正则描述文本的形状，而不是确切的词。
• \d、\w、\s 和 . 各代表一类字符。
• 把模式写成原始字符串：r"\d"。
