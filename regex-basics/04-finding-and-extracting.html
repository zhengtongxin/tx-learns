Pull the dates, numbers and names you need out of a block of text · ~10 min · reading and practice从一大段文本里取出你需要的日期、数字和名字 · 约 10 分钟 · 阅读加练习

Step 1 · One match or all of them第 1 步 · 找一个还是全部

Learn先学

re.search returns the first match (or None if there is none, so check before calling .group()). re.findall returns every match as a list of strings, and if the pattern has groups, the list holds the groups. re.finditer gives full match objects one at a time, handy for positions.

re.search 返回第一个匹配（没有则返回 None，所以调用 .group() 前要先检查）。re.findall 以字符串列表返回所有匹配；如果模式里有分组，列表里放的就是各个分组。re.finditer 一次给出一个完整的匹配对象，需要位置时很方便。

import re text = "Invoice 301 due 2026-12-01; invoice 302 due 2026-12-15" print(re.findall(r"\d{4}-\d{2}-\d{2}", text)) print(re.findall(r"nvoice (\d+)", text))

Step 2 · Name your groups第 2 步 · 给分组起名

Learn先学

Numbers get confusing past two groups. A named group, (?P<year>\d{4}), lets you ask for m.group("year") or call m.groupdict() to get all of them as a dictionary. Code that says "year" explains itself.

分组超过两个，编号就容易混乱。命名分组 (?P<year>\d{4}) 让你可以用 m.group("year")，或调用 m.groupdict() 把它们全部变成字典。写着 "year" 的代码自己就能说明意思。

Takeaways要点回顾

• search finds the first match, findall all of them, finditer with positions.
• search returns None when nothing matches; check before .group().
• Named groups make extracted parts self-explaining.

• search 找第一个，findall 找全部，finditer 带位置。
• 没有匹配时 search 返回 None；调用 .group() 前先检查。
• 命名分组让提取出的部分自己说明含义。
