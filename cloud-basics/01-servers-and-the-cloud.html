Servers and the cloud服务器与云

Know what a server is, what “the cloud” really means and what you rent when you use it · ~10 min · reading and practice知道服务器是什么，“云”到底指什么，以及用云时你租的是什么 · 约 10 分钟 · 阅读加练习

Step 1 · A server is a computer that waits第 1 步 · 服务器是一台等着的电脑

Learn先学

A server is just a computer that runs a program which waits for requests and answers them, all day, without anyone sitting at it. Your laptop can be a server. The difference is that a server stays on, stays connected and has a stable address (a name or number that always leads to it, like a street address), so other people can reach it at any hour.

服务器就是一台电脑，上面运行着一个等待请求并作出回应的程序，全天候运行，不需要有人守着。你的笔记本也可以当服务器。区别在于服务器一直开着、一直联网、有固定的地址（一个始终指向它的名字或数字，就像门牌号），别人在任何时间都能访问到它。

Step 2 · The cloud is rented computers第 2 步 · 云就是租来的电脑

Learn先学

“The cloud” means computers in someone else’s data centre that you rent by the hour or by use instead of buying. Nothing floats: it is real machines, real cables and a bill. You gain speed (a server in minutes) and give up some control and, if you are careless, a lot of money.

“云”指的是别人数据中心里的电脑，你按小时或按用量租，而不是买下来。没有什么飘在天上：都是真实的机器、真实的线缆和一张账单。你得到了速度（几分钟就有一台服务器），放弃了一部分控制权；不小心的话，还要多付很多钱。

Step 3 · How much do you manage?第 3 步 · 你要管多少

Learn先学

Providers sell the same thing at different heights. Rent a machine and you install and patch everything. A managed platform runs your code and handles the machine. A ready-made service (a database, or an AI model you call over the internet) is used as it comes. Each step up means less work and less control. Sort each need.

云服务商用不同的“高度”卖同一样东西。租一台机器，一切要自己安装、打补丁；托管平台帮你运行代码、管理机器；现成服务（数据库，或通过网络调用的 AI 模型）拿来就用。每上一层，就更省事、也更少控制。给每个需求分类。

Takeaways要点回顾

• A server is a computer that waits for requests, always on.
• The cloud is rented machines, billed by use.
• Higher levels mean less work and less control.

• 服务器是一台一直开着、等待请求的电脑。
• 云是按用量计费、租来的机器。
• 层级越高，越省事，控制也越少。
