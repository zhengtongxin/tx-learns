Branches分支

Work on an idea in its own branch, switch between branches and bring the work back with a merge · ~10 min · reading and practice在自己的分支上做一个想法，在分支间切换，并用合并把成果带回来 · 约 10 分钟 · 阅读加练习

Step 1 · A branch is a movable label第 1 步 · 分支是一个可移动的标签

Learn先学

A branch is a named line of commits. Your repository starts on one called main. When you start a new idea, make a branch for it. The commits you make there do not touch main until you decide to bring them back. That lets you experiment, or work on two things at once, without breaking the working version.

分支是一条有名字的提交线。你的仓库一开始在叫 main 的分支上。开始一个新想法时，为它建一个分支。你在那里做的提交，在你决定带回来之前不会碰到 main。这样你就能做实验，或同时做两件事，而不会弄坏能用的版本。

Branches are cheap. Make one for every idea.

分支很轻。每个想法都建一个。

git switch -c sale # make a branch and move to it # edit, add, commit as usual git switch main # go back to main git merge sale # bring the sale work into main git branch --show-current # which branch am I on?

Step 2 · Switching changes your files第 2 步 · 切换会改变你的文件

Learn先学

When you switch branches, Git rewrites the files in your folder to match the branch you move to. A file you added on the sale branch disappears when you go back to main, and comes back when you return. Nothing is lost: the commits are still there.

切换分支时，Git 会改写你文件夹里的文件，使其和你要去的分支一致。你在 sale 分支上加的文件，回到 main 后会消失，回去后又会出现。什么都没丢，提交都还在。

Always commit, or set aside, your work before you switch, so you do not carry half-done edits into another branch.

切换之前，一定要先提交或收好你的改动，别把做到一半的修改带进别的分支。

Step 3 · Merge the work back第 3 步 · 把成果合并回来

Learn先学

git merge sale, run while on main, brings the commits from sale into main. If the two branches changed different things, Git combines them by itself. When they changed the same lines, Git stops and asks you to decide, which is a conflict (next lesson).

在 main 上运行 git merge sale，会把 sale 上的提交带进 main。如果两个分支改的是不同的地方，Git 会自己合并。如果改了同样的几行，Git 会停下来让你来决定，这就是冲突（下一课）。

Takeaways要点回顾

• A branch is a named line of commits.
• Switching rewrites your files to match the branch.
• git merge brings another branch’s commits into the current one.
• Make a branch for every idea.

• 分支是一条有名字的提交线。
• 切换会改写你的文件，使其和分支一致。
• git merge 把另一个分支的提交带进当前分支。
• 每个想法都建一个分支。
