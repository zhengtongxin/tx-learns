Context layer service上下文层服务

Keep the business’s definitions and rules in a read-only service with an owner, so they can change without a deployment · ~30 min · concept with one runnable idea把业务的定义和规则放进一个有主人的只读服务里，改它们不用重新部署 · 约 30 分钟 · 概念课，带一段能跑的代码

Step 1 · Governed context in its own read-only service第 1 步 · 放进独立只读服务的受治理上下文

Learn先学
  • The agent reads from three places: the context layer (shared definitions and rules, owned by data governance, read-only), its own memory (it may write) and the database (the system of record).
  • A rule pasted into a prompt has no owner. So each context file gets a manifest entry: source, owner, last review date.
  • Serve the files from a service with its own key and only read routes. It opens a file fresh on every request, so governance can change a rule without a deployment, and only manifest names are served.
  • 智能体从三个地方读：上下文层（共享的定义和规则，归数据治理部门，只读）、自己的记忆（可以写）和数据库（权威记录）。
  • 贴进提示词的规则没有主人。所以每个上下文文件在清单里有一条记录：来源、负责人、上次复核日期。
  • 用一个有自己密钥、只有读路由的服务提供这些文件。每次请求都重新打开文件，所以治理部门改规则不用部署；而且只提供清单里有的名字。

Install with pip install flask requests; you also need the gateway from the last lesson.

用 pip install flask requests 安装；还需要上一课的网关。

下面每个事实属于哪个来源？来分一分。

# make_context.py: stands in for data governance's export import json, pathlib FILES = { "plans": ("policy admin system", {"P003": {"name": "Trip Care", "baggage_limit": 1000, "excess": 100}}), "glossary": ("data governance", {"excess": "The part of a claim the customer pays first."}), "manual": ("claims manual", {"version": "2026.3", "text": "Baggage claims are paid after the excess, up to the plan limit."}), } root = pathlib.Path("context") root.mkdir(exist_ok=True) manifest = {} for name, (source, content) in FILES.items(): (root / (name + ".json")).write_text(json.dumps(content, indent=2)) manifest[name] = {"source": source, "owner": "data governance", "reviewed": "2026-11-02"} (root / "manifest.json").write_text(json.dumps(manifest, indent=2)) # context_service.py import hmac, os from flask import Flask, jsonify, request if len(os.environ.get("CONTEXT_KEY", "")) < 32: raise SystemExit("CONTEXT_KEY is missing or too short: refusing to start") app = Flask(__name__) ROOT = pathlib.Path(os.environ.get("CONTEXT_DIR", "context")) def manifest(): return json.loads((ROOT / "manifest.json").read_text()) @app.before_request def need_key(): sent = request.headers.get("X-API-Key", "") if not hmac.compare_digest(sent.encode(), os.environ["CONTEXT_KEY"].encode()): return jsonify(error="missing or wrong key"), 401 @app.get("/context/<name>") def one(name): meta = manifest().get(name) if meta is None: return jsonify(error="unknown file"), 404 # only manifest names open: no ../secrets content = json.loads((ROOT / (name + ".json")).read_text()) return jsonify(name=name, meta=meta, content=content) # try_it.py: with CONTEXT_KEY set, client = app.test_client() # client.get("/context/glossary", headers=key).status_code # 200 # client.post("/context/glossary", json={"excess": "x"}, headers=key).status_code # 405: no write route

Step 2 · Behind the same gateway第 2 步 · 放在同一个网关后面

Learn先学

The agent should not hold this service's key either. Add the context service as a second target of the action gateway: it checks the agent's key, then forwards the read with the context key only it holds. Reads pass the same door and the same log as actions.

智能体也不该持有这个服务的密钥。把上下文服务加成动作网关的第二个目标：网关核对智能体的密钥，再用只有它才有的上下文密钥转发这次读取。读取和动作走同一扇门、同一份日志。

# action_gateway.py: add below the existing routes (re, requests, jsonify and os are already imported) CONTEXT_URL = os.environ.get("CONTEXT_URL", "http://127.0.0.1:5002") CONTEXT_KEY = os.environ["CONTEXT_KEY"] # only the gateway holds this @app.get("/context/<name>") def read_context(name): if not re.fullmatch(r"[a-z_]{1,40}", name): return jsonify(error="bad name"), 400 reply = requests.get(CONTEXT_URL + "/context/" + name, headers={"X-API-Key": CONTEXT_KEY}, timeout=10) return jsonify(reply.json()), reply.status_code

Step 3 · A decision record you could audit第 3 步 · 一份经得起审计的判定记录

Learn先学

Because every read has an owner and a date, a decision record can be complete: the calculation as numbers, who or what decided, the manual version, and each file read with its source and review date. Store the facts as they were that day, not pointers to files that may change.

既然每次读取都有主人和日期，判定记录就能做到完整：用数字记下计算过程，写明是谁或什么做的决定、手册版本，以及读过的每个文件、它的来源和复核日期。要把当天的事实存下来，而不是存指向可能会变的文件的指针。

# record.py import datetime def calculate(claimed, plan): payout = max(0, min(claimed - plan["excess"], plan["baggage_limit"])) return payout, "min(%s - %s, %s) = %s" % (claimed, plan["excess"], plan["baggage_limit"], payout) def build_record(claim_id, claimed, plan_id, ctx, decided_by): """ctx holds what the agent read: file name -> the service's reply (meta and content).""" payout, calculation = calculate(claimed, ctx["plans"]["content"][plan_id]) return { "claim_id": claim_id, "payout": payout, "calculation": calculation, "decided_by": decided_by, "manual_version": ctx["manual"]["content"]["version"], "read": [{"file": n, "source": c["meta"]["source"], "reviewed": c["meta"]["reviewed"]} for n, c in ctx.items()], "at": datetime.datetime.now(datetime.timezone.utc).isoformat(), } # meta = {"source": "claims manual", "owner": "data governance", "reviewed": "2026-11-02"} # ctx = {"plans": {"meta": meta, "content": {"P003": {"baggage_limit": 1000, "excess": 100}}}, # "manual": {"meta": meta, "content": {"version": "2026.3"}}} # print(build_record("C007", 1400, "P003", ctx, "agent")["calculation"]) # min(1400 - 100, 1000) = 1000

405 Method Not Allowed
Cause: you tried to write to the context layer. Fix: that is on purpose; changes go to its owner.

Takeaways要点回顾

• Context, memory and the database have different owners.
• Context carries an owner, a source and a review date in a manifest.
• The agent only reads context; a fix goes to the owner.
• Serve it with its own key and no write routes, behind the same gateway.
• A decision record keeps the calculation, the decider, the manual version and the files read, as they were that day.

• 上下文、记忆和数据库的主人各不相同。
• 上下文在清单里带着负责人、来源和复核日期。
• 智能体对上下文只读；要改就找主人。
• 用自己的密钥、没有写入路由来提供，并放在同一个网关后面。
• 判定记录保存算式、决定者、手册版本和读过的文件，都是当天的样子。
