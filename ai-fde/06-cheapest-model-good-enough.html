Picking the model for the job · Project为任务挑模型 · 项目

Cheapest good-enough model够用的最便宜模型

Choose the claims desk’s model with a written reason: the cheapest one that clears a bar the customer agreed to · ~25 min · hands-on为理赔台选模型，并写下理由：客户同意的那条标准之上，最便宜的那个 · 约 25 分钟 · 动手实践

Step 1 · Agree the bar first第 1 步 · 先谈好标准线

Learn先学
  • A bar is the minimum a model must reach to be allowed on the claims desk. Write it as numbers before anyone runs, or you will pick a bar your favourite passes.
  • Include accuracy, what must never happen, and speed. A big payout here is one over S$800, the sign-off limit.
  • 标准线是模型想上理赔台必须达到的最低要求。在开跑之前写成数字，否则你定出的线一定是你最爱的那个能过的。
  • 要包含准确率、绝不能发生的事和速度。这里的大额赔付指超过 S$800 的赔付，也就是签字上限。
SIGNOFF_LIMIT = 800 # S$, the same limit as the pilot's queue BAR = {"easy": 0.90, # matches the handlers on at least 90% of easy claims "big_wrong": 0, # never approves a big payout the handlers did not approve "secs": 5.0} # at most 5 seconds per claim, for a busy queue

下面哪些该写进标准线？来分一分。

Step 2 · Run each candidate twice, in one table第 2 步 · 候选各跑两遍，汇成一张表

Learn先学
  • Pick three or four candidates (small and cheap, mid-priced, strong). Run each twice on all 25 claims with the small prompt.
  • Turn the two runs into one row: accuracy by difficulty, cost per 1,000 claims, seconds per claim, and wrongly approved big payouts.
  • This reuses bench.py. Importing it runs its top-level lines, so keep one-off experiments under if __name__ == "__main__":. Prices are invented: copy your gateway’s real ones.
  • 挑三四个候选（小而便宜的、中等价位的、强的），每个用小提示词在 25 份理赔上跑两遍。
  • 把两遍结果变成一行：分难度的准确率、每 1,000 份理赔的成本、每份用几秒，以及错批的大额赔付次数。
  • 这里复用 bench.py。导入它会把顶层代码跑一遍，所以一次性的实验要放到 if __name__ == "__main__": 下面。价格是编的，请换成你的网关上的真实价格。
from collections import defaultdict from bench import claims, key, matches, small_prompt, ask, gateway # ask(client, model, prompt) returns (decision, input tokens, output tokens, seconds) # US$ per million tokens: (input, output). Invented: copy your gateway's real list. CANDIDATES = { "meta-llama/llama-3.3-70b-instruct": (0.10, 0.30), "openai/gpt-5.4-mini": (0.40, 1.60), "anthropic/claude-haiku-5-5": (1.00, 5.00), "anthropic/claude-sonnet-5-5": (3.00, 15.00)} def run_twice(model): return [[(c["id"], *ask(gateway, model, small_prompt(c))) for c in claims] for _ in range(2)] def row(model, runs): price_in, price_out = CANDIDATES[model] tally = defaultdict(lambda: [0, 0]) # difficulty -> [right, total] cost = secs = 0 big_wrong = 0 for run in runs: for cid, decision, tin, tout, seconds in run: want = key[cid] tally[want["difficulty"]][0] += matches(decision, want) tally[want["difficulty"]][1] += 1 cost += (tin * price_in + tout * price_out) / 1_000_000 secs += seconds if (decision["action"] == "approve" and float(decision["payout"]) > SIGNOFF_LIMIT and want["action"] != "approve"): big_wrong += 1 n = sum(total for _, total in tally.values()) return {"model": model, "by_level": {level: right / total for level, (right, total) in tally.items()}, "cost_1000": cost / n * 1000, "secs": secs / n, "big_wrong": big_wrong} rows = [row(model, run_twice(model)) for model in CANDIDATES]

Step 3 · Pick the cheapest that clears the bar第 3 步 · 选过线里最便宜的

Learn先学
  • A model must pass every line: one failure is out, however good the rest. The most accurate model can lose by being too slow.
  • Among those that pass, take the cheapest. Keep a stronger model as a fallback: a router asks the cheap one first and only sends a claim on when it says “refer”.
  • Write the decision in half a page: the bar, the pick, the numbers, the fallback, and what would make you look again.
  • 模型必须过每一条：只要有一条没过就出局，别的再好也没用。最准的模型也可能因为太慢而输掉。
  • 在过线的里面取最便宜的。再留一个更强的模型做后备：路由器先问便宜的那个，只有它回答“转交”时才把理赔交给强的。
  • 用半页纸写下决定：标准线、选了谁、背后的数字、后备方案，以及什么情况会让你重新看一遍。
def clears(r): return (r["by_level"]["easy"] >= BAR["easy"] and r["big_wrong"] <= BAR["big_wrong"] and r["secs"] <= BAR["secs"]) passing = [r for r in rows if clears(r)] if not passing: raise SystemExit("nobody clears the bar: change the prompt, or revisit the bar with the customer") pick = min(passing, key=lambda r: r["cost_1000"])["model"] STRONG = "anthropic/claude-sonnet-5-5" def decide_routed(claim): decision = ask(gateway, pick, small_prompt(claim))[0] # ask() returns a tuple; [0] is the decision if decision["action"] == "refer": # the cheap model is unsure decision = ask(gateway, STRONG, small_prompt(claim))[0] return decision # a refer from the strong model still goes to a handler

The bar: 90% on easy claims, no wrongly approved big payouts, at most 5 seconds. These five results are made up for practice. Sort them.

标准线：简单理赔 90%，没有错批的大额赔付，每份最多 5 秒。这五组结果是为练习编的。给它们分一分。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Agree the bar with the customer before the contest, in numbers, with speed and safety as well as accuracy.
• Run each candidate twice before you trust a row.
• A model must pass every line; pick the cheapest that does.
• Name a stronger fallback for the claims it is unsure of.
• Write the reason in half a page.

• 比赛前先和客户用数字谈好标准线，除了准确率还要有速度和安全。
• 每个候选跑两遍，再相信那一行。
• 模型必须过每一条；选过线里最便宜的。
• 为它拿不准的理赔指定一个更强的后备。
• 用半页纸写下理由。
