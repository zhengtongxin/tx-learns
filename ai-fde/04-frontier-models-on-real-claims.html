Frontier models on claims大模型处理理赔

Compare several top models fairly on the same claims, and see what each one costs, before anyone picks a favourite · ~20 min · concept with one runnable idea在同样的理赔上公平地比较几个顶级模型，并看清各自的花费，再决定谁是最爱 · 约 20 分钟 · 概念课，附一个可动手的做法

Step 1 · Change only the model第 1 步 · 只换模型

Learn先学
  • A frontier model is one of the biggest, most capable models, rented over the internet. To compare them fairly, change one thing: the model. Same claims, same prompt, same marking.
  • A gateway is one service in front of many labs: one key, one bill, one way to call them all. Here it is OpenRouter. Run pip install openai and set GATEWAY_API_KEY.
  • 前沿模型就是最大、最强的那批模型，通过网络租用。要公平比较，只能换一样东西：模型。同样的理赔、同样的提示词、同样的评分。
  • 网关是站在许多实验室前面的一个服务：一把密钥、一张账单、一种调用方式。这里用 OpenRouter。运行 pip install openai，并设置 GATEWAY_API_KEY。
# bench.py import json, os from openai import OpenAI claims = json.load(open("data/claims.json")) # the 25 invented claims POLICIES = json.load(open("data/policies.json")) WORDING = open("data/policy_wording.txt").read() def build_prompt(claim): policy = POLICIES[claim["policy_id"]] return f"""You help a travel insurer's claims desk. Policy wording: {WORDING} This customer's policy: {json.dumps(policy)} The claim: {json.dumps(claim)} Reply with JSON only: {{"action": "approve" or "decline" or "refer", "payout": a number in S$, "reason": two or three short sentences}}""" gateway = OpenAI(base_url="https://openrouter.ai/api/v1", api_key=os.environ["GATEWAY_API_KEY"]) # check the exact names on your gateway's model list MODELS = ["openai/gpt-5.4-mini", "anthropic/claude-haiku-5-5", "anthropic/claude-sonnet-5-5"] def decide(model, claim): reply = gateway.chat.completions.create( model=model, messages=[{"role": "user", "content": build_prompt(claim)}]) text = reply.choices[0].message.content # keep only the {...} part, in case a model adds chatter around it decision = json.loads(text[text.index("{"): text.rindex("}") + 1]) return decision, reply.usage.prompt_tokens, reply.usage.completion_tokens def run_model(model): return {c["id"]: decide(model, c) for c in claims}

Step 2 · Score it, and put the cost beside it第 2 步 · 打分，并把成本放在旁边

Learn先学
  • A claim is right when the action matches the handler’s and the payout is within S$1. Score each difficulty (easy, medium, tricky) separately: one overall number hides where a model is weak.
  • Models read and write in tokens (about four letters). You pay per million tokens, a higher price for output than input. Work out cost per 1,000 claims, a number people can picture.
  • 动作和理赔员一致，并且赔付金额相差不超过 S$1，才算对。按难度（简单、中等、刁钻）分别打分：只看一个总数，会藏住模型弱在哪里。
  • 模型读写的单位是 token（约四个字母）。按每百万 token 收费，输出比输入贵。算成每 1,000 份理赔的成本，这个数人们想象得出来。
# bench.py, continued from collections import defaultdict # {"C007": {"action": "approve", "payout": 420, "difficulty": "easy"}, ...} key = json.load(open("answer_key/handler_decisions.json")) # only scoring reads this def matches(decision, want): return (decision["action"] == want["action"] and abs(float(decision["payout"]) - want["payout"]) <= 1) def score(run): tally = defaultdict(lambda: [0, 0]) # difficulty -> [right, total] for cid, (decision, _, _) in run.items(): want = key[cid] tally[want["difficulty"]][0] += matches(decision, want) tally[want["difficulty"]][1] += 1 return dict(tally) # US$ per million tokens: (input, output). Invented numbers: copy your gateway's real list. PRICE = { "openai/gpt-5.4-mini": (0.40, 1.60), "anthropic/claude-haiku-5-5": (1.00, 5.00), "anthropic/claude-sonnet-5-5": (3.00, 15.00)} def cost_per_1000(model, run): price_in, price_out = PRICE[model] total = sum(tin * price_in + tout * price_out for _, tin, tout in run.values()) / 1_000_000 return total / len(run) * 1000

Step 3 · Run twice before you believe a gap第 3 步 · 先跑两遍，再信差距

Learn先学

The same question twice can get slightly different answers, so a one-claim gap can be luck. Run every model twice and trust only a gap bigger than how much a model moves against itself.

同一个问题问两遍，答案可能略有不同，所以差一份理赔可能只是运气。每个模型跑两遍，只信比“自己和自己的波动”更大的差距。

runs = {m: [run_model(m), run_model(m)] for m in MODELS} for model, two in runs.items(): rights = [sum(right for right, _ in score(run).values()) for run in two] print(model, "right per run:", rights, f"US${cost_per_1000(model, two[0]):.2f} per 1,000 claims")

每个模型在 25 份理赔上跑了两遍。每个差距是真的，还是只是噪声？

Now make it yours现在把它变成你的

Takeaways要点回顾

• Same task, data and scoring for every model: only the model changes.
• A gateway lets one script call many models by changing just the name.
• Report accuracy by difficulty, with cost per 1,000 claims beside it.
• Run twice before believing a small gap.

• 每个模型的任务、数据和评分都一样：只有模型在变。
• 有了网关，一个脚本只改名字就能调用许多模型。
• 按难度汇报准确率，旁边放上每 1,000 份理赔的成本。
• 差距很小时，先跑两遍再相信。
