A memory over MCP通过 MCP 给智能体记忆

Give the agent a long-term memory it reaches through an MCP server, so it can recall a customer’s past claims · ~25 min · concept + one runnable idea给智能体一个通过 MCP 服务端访问的长期记忆，让它能回想起客户过去的理赔 · 约 25 分钟 · 概念 + 一个能跑的想法

Where we left off上回讲到

Last time the pilot could look up the right clause in the policy manual before deciding. Today it fails when Mr Tan files a second lost-bag claim: it starts from nothing, though Auntie Siew remembers him. We fix it by putting a memory behind an MCP server that the pilot can call.

上回，试点在判定前能先到保单手册里查出对应的条款。今天的问题是：Tan 先生第二次提交丢行李理赔时，它又从零开始，而 Siew 阿姨一眼就认得他。我们的办法是把记忆放在一个 MCP 服务端后面，让试点随时调用。

The story故事

Every claim, the agent starts from nothing. Auntie Siew, at the front desk, does not: she remembers that Mr Tan filed two lost-bag claims and always had full receipts. Mei Ling wants the agent to have that kind of memory. She will not build it into the agent. She will put it behind an MCP server, a small program that offers tools the agent can plug into. If you have not met MCP, think of it as a standard wall socket for tools.

每一份理赔，智能体都是从零开始。前台的 Siew 阿姨不是：她记得 Tan 先生提过两次丢行李的理赔，而且收据一向齐全。Mei Ling 想让智能体也有这样的记忆。她不打算把记忆造进智能体里，而是放在一个 MCP 服务端后面，也就是一个小程序，提供智能体可以接上的工具。如果你没见过 MCP，就把它想成工具的标准插座。

Words in this lesson这一课用到的词MCP: a standard way for an agent to use tools that live in another program, so one tool server works with many agents.
stdio: the server runs as a child program and talks over its input and output, with no network port.
Memory note: a short line the agent saves about a customer, to be read in a later claim.MCP：智能体使用另一个程序里的工具的标准方式，同一个工具服务可以配给很多智能体。
stdio：服务作为子程序运行，通过输入输出交谈，不开网络端口。
记忆笔记：智能体存下的关于某位客户的一句话，下一份理赔时再读。

Step 1 · A small memory server第 1 步 · 一个小小的记忆服务端

Learn先学

The server has two tools: one saves a note about a customer, one returns all notes for that customer. Notes live in a file, so they survive after the agent stops. The tool’s docstring is what the model reads to decide when to use it. The @mcp.tool() line is a decorator: it tells the server to offer the function below as a tool. Install with pip install mcp.

服务端只有两个工具：一个给客户存一条笔记，一个返回该客户的全部笔记。笔记存在文件里，所以智能体停了它们也还在。工具的说明文字（docstring）就是模型用来判断何时使用它的依据。@mcp.tool() 这一行是装饰器，它告诉服务端把下面这个函数当作工具提供出去。用 pip install mcp 安装。

# memory_server.py import json, os from mcp.server.fastmcp import FastMCP FILE = "memory.json" mcp = FastMCP("kaya_memory") def load(): return json.load(open(FILE)) if os.path.exists(FILE) else {} @mcp.tool() def save_note(customer_id: str, fact: str) -> str: """Save one fact about a customer, so the next claim can use it.""" data = load() data.setdefault(customer_id, []).append({"fact": fact}) json.dump(data, open(FILE, "w"), indent=2) return "saved" @mcp.tool() def get_notes(customer_id: str) -> list: """Return every note saved for this customer (an empty list if none).""" return load().get(customer_id, []) if __name__ == "__main__": mcp.run(transport="stdio")

Step 2 · Connect the agent over MCP第 2 步 · 通过 MCP 把智能体接上

Learn先学

The agent starts the server as a child program, and the two talk through stdio (plain text in and out, like a pipe). The agent asks which tools the server has. You never write a save_note function on the agent’s side. Each claim starts a new agent and a new server process. The notes still carry over, because they are in the file. The functions are async: the agent waits for the server, and await means “wait here for the answer”. Run them with asyncio.run(...). Install with pip install openai-agents.

智能体把服务端当作子程序启动，两者通过 stdio 交谈（就是纯文字的进出，像一根管子）。智能体会问服务端有哪些工具。你不用在智能体这边写 save_note 函数。每份理赔都会启动一个新的智能体和新的服务端进程，笔记依然能传下去，因为它们在文件里。函数前的 async 表示它要等服务端回话；await 的意思是“在这里等结果”。用 asyncio.run(...) 来运行它们。用 pip install openai-agents 安装。

import asyncio, json from agents import Agent, Runner from agents.mcp import MCPServerStdio memory_params = {"command": "python", "args": ["memory_server.py"]} BASE = """You decide travel insurance claims for Kaya Travel Cover. Reply with JSON only: {"action": "approve" or "decline" or "refer", "payout": a number in S$, "reason": two or three short sentences}""" async def run_claim(claim, instructions): async with MCPServerStdio(params=memory_params, client_session_timeout_seconds=60) as server: agent = Agent(name="Claims agent", instructions=instructions, model="gpt-5.4-mini", mcp_servers=[server]) result = await Runner.run(agent, json.dumps(claim)) return json.loads(result.final_output)

Step 3 · Write down what is worth remembering第 3 步 · 记下值得记住的

Learn先学

A memory that keeps everything is as bad as a desk piled with paper. Tell the agent what to save: a few facts that help on a future claim. Leave out anything private (card or passport numbers) and anything that is only a feeling or a guess. After it decides, the agent saves at most two notes.

什么都留的记忆，就像堆满纸的桌子一样糟。告诉智能体该存什么：几条对以后的理赔有帮助的事实。私密的东西（银行卡号、护照号）和只是感觉或猜测的东西都不要。决定之后，智能体最多存两条笔记。

SAVE = """ After you decide, call save_note at most twice with short facts that would help on this customer's next claim. Never save card or passport numbers, and never save a guess.""" claim1 = {"id": "C041", "customer_id": "K-0412", "customer": "Mr Tan", "story": "My checked bag never arrived. Receipts for everything inside are attached.", "amount": 420} print(asyncio.run(run_claim(claim1, BASE + SAVE)))

预期输出 （示例：你的数字和措辞会不同）

{'action': 'approve', 'payout': 420, 'reason': 'First bag claim, receipts match.'}

Step 4 · Look the notes up first第 4 步 · 先查笔记

Learn先学

Saving is half the job. On the next claim from the same customer the agent must read the notes before it decides. Add one line to the instructions, and the agent will call get_notes with the customer id from the claim.

只存不够。同一位客户的下一份理赔，智能体必须在决定之前先读笔记。在指令里加一行，智能体就会用理赔里的客户编号去调用 get_notes。

LOOK = "\nBefore you decide, call get_notes with the claim's customer_id." claim2 = {"id": "C042", "customer_id": "K-0412", "customer": "Mr Tan", "story": "My bag was lost again on the flight home. Receipts attached.", "amount": 380} print(asyncio.run(run_claim(claim2, BASE + LOOK + SAVE)))

Expected output (an example: your numbers and wording will differ)

预期输出 （示例：你的数字和措辞会不同）

{'action': 'refer', 'payout': 0, 'reason': 'Second lost-bag claim in a short time; the earlier note says one prior claim, C041.'}

Step 5 · Facts only, with a source and a date第 5 步 · 只存事实，带出处和日期

Learn先学

A note can go out of date: “receipts always complete” was true last year. So every note carries where it came from (the claim id) and the day it was saved. The server stamps the date itself, because the agent should not guess it. The agent then treats an old note as a lead to check, not a fact to trust.

笔记会过时：“收据一向齐全”是去年的事实。所以每条笔记都带上出处（理赔编号）和存入的日期。日期由服务端自己盖章，因为不该让智能体去猜。这样智能体就把旧笔记当成待核实的线索，而不是可以直接相信的事实。

import datetime # at the top of memory_server.py @mcp.tool() def save_note(customer_id: str, fact: str, source: str) -> str: """Save one fact about a customer. source is the claim id the fact comes from.""" data = load() data.setdefault(customer_id, []).append({"fact": fact, "source": source, "saved": datetime.date.today().isoformat()}) json.dump(data, open(FILE, "w"), indent=2) return "saved" # in the agent's instructions SAVE = """ After you decide, call save_note at most twice, with a short fact and the claim id as source. Facts only: never a guess, never card or passport numbers.""" LOOK = """ Before you decide, call get_notes with the claim's customer_id. Each note has a saved date. Treat a note as a lead, and check it against today's claim. Say in your reason when you used one."""

Step 6 · Does memory actually help?第 6 步 · 记忆真的有用吗？

Learn先学

Do not guess: run both on the same claims. Agent A has only a payout tool. Agent B has the payout tool and memory. Count how often each agrees with the handlers. Usually memory helps on repeat customers and on claims where history matters, and does nothing on one-off claims. It also adds a new way to be wrong: an old note that is no longer true. Agent B also saves notes while it runs, so delete memory.json before you compare again.

别靠猜：在同样的理赔上两个都跑一遍。智能体 A 只有一个赔付工具。智能体 B 有赔付工具，再加上记忆。数一数各自和理赔员一致的次数。通常记忆对回头客、对历史重要的理赔有帮助，对只来一次的理赔毫无作用。它还带来一种新的出错方式：一条已经不再成立的旧笔记。智能体 B 运行时也会存笔记，所以每次重新比较前，先删掉 memory.json。

from agents import function_tool @function_tool def payout(amount: float, limit: float) -> float: """The amount to pay: the claim amount, capped at the policy limit.""" return min(amount, limit) key = json.load(open("answer_key/handler_decisions.json")) # {claim id: handler's action} async def agreement(claims, with_memory): right = 0 async with MCPServerStdio(params=memory_params, client_session_timeout_seconds=60) as server: for c in claims: agent = Agent(name="Claims agent", model="gpt-5.4-mini", tools=[payout], instructions=BASE + (LOOK + SAVE if with_memory else ""), mcp_servers=[server] if with_memory else []) result = await Runner.run(agent, json.dumps(c)) right += json.loads(result.final_output)["action"] == key[c["id"]] return right / len(claims) # claims = the list of claim dicts from before, each with an "id" # print(await agreement(claims, False), await agreement(claims, True)) # in a notebook

Where does memory help? Sort the situations.

记忆在哪里有帮助？给这些情形分一分。

What I got wrong我当时想错了My agent stored too much, including guesses like “seems nervous”. Later claims trusted them. Now every note needs a source and a date, and the instructions say “facts only”.我的智能体存得太多，连“看起来很紧张”这种猜测也存了，后来的理赔还相信它们。现在每条笔记都要有出处和日期，指令里写明“只存事实”。

Common errors常见错误

ModuleNotFoundError: No module named 'mcp'
Cause: the MCP library is not installed. Fix: pip install mcp openai-agents.

ModuleNotFoundError: No module named 'mcp'
原因：没有安装 MCP 库。解决：pip install mcp openai-agents。

McpError: Connection closed
Cause: the memory server crashed on start, often from a typo in memory_server.py. Fix: run python memory_server.py alone and read its error.

McpError: Connection closed
原因：记忆服务启动时崩溃了，多半是 memory_server.py 里有笔误。解决：单独运行 python memory_server.py 看它的报错。

FileNotFoundError: [Errno 2] No such file or directory: 'python'
Cause: the client cannot find the command that starts the server. Fix: give the full path of your Python in the server settings.

FileNotFoundError: [Errno 2] No such file or directory: 'python'
原因：客户端找不到启动服务的命令。解决：在服务设置里写 Python 的完整路径。

Recap小结

• Put the memory behind MCP, so any agent can read and write it the same way.
• Save a short note after each claim, and read the notes before the next one.
• A note is a lead, not a fact: check it against today's claim.

• 把记忆放在 MCP 后面，任何智能体都能用同样的方式读写。
• 每份理赔之后存一条短笔记，下一份之前先读笔记。
• 笔记只是线索，不是事实：要和今天这份理赔核对。

Takeaways要点回顾

• MCP is a plug: the memory lives in a server, not inside the agent.
• Notes survive because they are stored outside the agent’s conversation.
• Tell the agent what to save and what never to save.
• Store facts only, each with a source and a date.
• Look the notes up before deciding, and treat them as leads.
• Memory helps where history matters and does nothing on one-off claims.
• A stale note is a new risk, so decide when notes expire.

• MCP 是个插头：记忆住在服务端，不在智能体内部。
• 笔记能留下来，因为它们存在智能体对话之外。
• 告诉智能体该存什么、绝不能存什么。
• 只存事实，每条都带出处和日期。
• 决定之前先查笔记，并把它们当成线索。
• 记忆在历史重要的地方有用，对只来一次的理赔没用。
• 过时的笔记是新的风险，所以要定好笔记何时过期。
