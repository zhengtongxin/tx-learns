Memory over MCP基于 MCP 的记忆

Give the agent a long-term memory it reaches through an MCP server, so it can recall a customer’s past claims · ~25 min · concept + one runnable idea给智能体一个通过 MCP 服务端访问的长期记忆，让它能回想起客户过去的理赔 · 约 25 分钟 · 概念 + 一个能跑的想法

Step 1 · A memory server第 1 步 · 记忆服务端

Learn先学

An agent forgets everything between claims. Put the memory in an MCP server (a small program that offers tools to any agent) and it survives.

  • Two tools: save a note, get all notes for a customer.
  • Notes sit in a file, so they outlive the agent.
  • Each note carries a source (the claim id) and a date the server stamps itself.

智能体在两份理赔之间会忘掉一切。把记忆放进 MCP 服务端（一个给任何智能体提供工具的小程序），它就能留下来。

  • 两个工具：存一条笔记，取出某客户的全部笔记。
  • 笔记存在文件里，智能体停了还在。
  • 每条笔记带出处（理赔编号）和由服务端自己盖的日期。
# pip install mcp import json, os, datetime from mcp.server.fastmcp import FastMCP FILE = "memory.json" mcp = FastMCP("kaya_memory") def load(): return json.load(open(FILE)) if os.path.exists(FILE) else {} @mcp.tool() def save_note(customer_id: str, fact: str, source: str) -> str: """Save one fact about a customer. source is the claim id it comes from.""" data = load() data.setdefault(customer_id, []).append( {"fact": fact, "source": source, "saved": datetime.date.today().isoformat()}) json.dump(data, open(FILE, "w"), indent=2) return "saved" @mcp.tool() def get_notes(customer_id: str) -> list: """Return every note saved for this customer (an empty list if none).""" return load().get(customer_id, []) if __name__ == "__main__": mcp.run(transport="stdio")

Step 2 · Connect the agent第 2 步 · 接上智能体

Learn先学

The agent starts the server as a child program and talks to it over stdio; you never write save_note on the agent's side. Two lines of instructions do the rest: read notes before deciding, save at most two facts after.

智能体把服务端当子程序启动，通过 stdio 对话；智能体这边不用写 save_note。两行指令搞定其余：决定前先读笔记，决定后最多存两条事实。

# pip install openai-agents import asyncio, json from agents import Agent, Runner from agents.mcp import MCPServerStdio memory_params = {"command": "python", "args": ["memory_server.py"]} INSTRUCTIONS = """You decide travel insurance claims for Kaya Travel Cover. Before you decide, call get_notes with the claim's customer_id. Treat a note as a lead and check it against today's claim. After you decide, call save_note at most twice: a short fact, and the claim id as source. Facts only: never a guess, never card or passport numbers. Reply with JSON only: {"action": "approve" or "decline" or "refer", "payout": number in S$, "reason": short}""" async def run_claim(claim): async with MCPServerStdio(params=memory_params, client_session_timeout_seconds=60) as server: agent = Agent(name="Claims agent", instructions=INSTRUCTIONS, model="gpt-5.4-mini", mcp_servers=[server]) result = await Runner.run(agent, json.dumps(claim)) return json.loads(result.final_output) claim = {"id": "C042", "customer_id": "K-0412", "story": "My bag was lost again. Receipts attached.", "amount": 380} print(asyncio.run(run_claim(claim)))

Step 3 · Notes are leads, not facts第 3 步 · 笔记是线索，不是事实

Learn先学
  • A note can go stale, so the date matters: an old note is something to check.
  • Memory helps on repeat customers and does nothing on one-off claims.
  • To test it, run the same claims with and without memory and compare agreement with handlers. Delete memory.json between runs.
  • 笔记会过时，所以日期很重要：旧笔记要拿来核实。
  • 记忆对回头客有帮助，对只来一次的理赔没用。
  • 要测试，就用同样的理赔分别在有、无记忆下运行，比较与理赔员的一致程度。两次运行之间删掉 memory.json。

Takeaways要点回顾

• Put memory behind MCP, outside the agent's conversation.
• Tell the agent what to save and what never to save.
• Store facts only, each with a source and a date.
• Read notes before deciding, and treat them as leads.
• Decide when a note expires.

• 把记忆放在 MCP 后面，放在智能体对话之外。
• 告诉智能体该存什么、绝不能存什么。
• 只存事实，每条带出处和日期。
• 决定前先读笔记，并把它们当线索。
• 定好笔记何时过期。
