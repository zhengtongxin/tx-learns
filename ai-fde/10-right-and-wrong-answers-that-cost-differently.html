Unequal cost of errors错误的不同代价

Two agents can agree with the handlers equally often and still cost very different amounts: learn to name each kind of mistake and price it · ~20 min · concept with one runnable idea两个智能体和理赔员一致的次数可以一样多，花费却天差地别：学会给每一种错误起名字、标价格 · 约 20 分钟 · 概念课，附一个可动手的做法

Step 1 · Lay out the mistakes and name them第 1 步 · 摆出错误并起名字

Learn先学
  • One percentage hides which answers were wrong. A confusion matrix is a grid: each row is what the handler decided, each column what the agent decided. The diagonal is agreement; everything else is a mistake.
  • Name mistakes by what the agent did: a wrongful payment (it approves, the handler would not have: money is out), a wrongful decline (it says no, the handler would not have: a customer is let down), a needless referral (only handler time is wasted).
  • Approving a claim a handler would have referred counts as a wrongful payment on purpose: money moved before a human looked.
  • 一个百分比会藏起“哪些答案错了”。混淆矩阵是一张格子：每一行是理赔员的决定，每一列是智能体的决定。对角线是一致，其余都是错误。
  • 按智能体做了什么给错误起名：错付（它批准了，理赔员不会批准：钱已出门）、错拒（它说不，理赔员不会拒：客户被辜负）、白转交（浪费的只是理赔员的时间）。
  • 理赔员本会转交、智能体却批准，也算错付，这是有意的：钱在人看过之前就动了。
# scoring.py from collections import Counter ACTIONS = ["approve", "decline", "refer"] def matrix(pairs): """pairs: one (handler's decision, agent's decision) per claim.""" counts = Counter(pairs) return [[counts[(h, a)] for a in ACTIONS] for h in ACTIONS] # rows: handler, columns: agent # practice data as counts: rows = handler, columns = agent (approve, decline, refer) GRID_A = [[12, 0, 2], [3, 3, 0], [1, 0, 4]] GRID_B = [[10, 2, 2], [0, 5, 1], [0, 1, 4]] def accuracy(grid): total = sum(map(sum, grid)) return sum(grid[i][i] for i in range(3)) / total # (handler's decision, agent's decision) -> what kind of mistake KIND = {("decline", "approve"): "wrongful payment", ("refer", "approve"): "wrongful payment", ("approve", "decline"): "wrongful decline", ("refer", "decline"): "wrongful decline", ("approve", "refer"): "needless referral", ("decline", "refer"): "needless referral"} def mistakes(grid): found = Counter() for i, handler in enumerate(ACTIONS): for j, agent in enumerate(ACTIONS): if i != j: found[KIND[(handler, agent)]] += grid[i][j] return dict(found)

Step 2 · Three more numbers第 2 步 · 另外三个数

Learn先学
  • Precision: when the agent says approve, how often is it right? Recall: of the claims handlers approved, how many did it also approve?
  • Kappa is agreement beyond luck: an agent that approves everything already matches 56% of claims without reading a word. 0 means no better than chance, 1 is perfect.
  • Straight-through rate is the share the agent decides itself. An agent that refers everything never pays wrongly, and saves nobody any time.
  • 精确率：智能体说批准的时候，有多少次是对的？召回率：理赔员批准的那些理赔里，它也批准了多少？
  • Kappa 是扣掉运气之后的一致：一个什么都批准的智能体，一个字都没读就已经对上 56%。0 表示不比碰运气好，1 表示完美。
  • 直通率是智能体自己做决定的比例。一个把每份都转交的智能体永远不会错付，但也没替任何人省时间。
# scoring.py, continued def approval_precision_recall(grid): said_approve = sum(row[0] for row in grid) # the agent's approve column should_approve = sum(grid[0]) # the handler's approve row right = grid[0][0] return right / said_approve, right / should_approve def kappa(grid): total = sum(map(sum, grid)) seen = accuracy(grid) by_handler = [sum(row) for row in grid] # row totals by_agent = [sum(row[j] for row in grid) for j in range(3)] # column totals by_chance = sum(h * a for h, a in zip(by_handler, by_agent)) / total ** 2 return (seen - by_chance) / (1 - by_chance) def straight_through(grid): total = sum(map(sum, grid)) referred = sum(row[2] for row in grid) # the agent's refer column return 1 - referred / total

Step 3 · Price each mistake第 3 步 · 给每种错误标价

Learn先学

Agree with the owners what each kind of mistake costs, in S$ (these prices are invented), then multiply and add. The agent with the lower total is the better one for this desk.

和负责人谈好每种错误让公司花多少钱，用新元算（这里的价格是编的），然后相乘再相加。总数更低的智能体，才是适合这个理赔台的。

# scoring.py, continued PRICE = {"wrongful payment": 400, "wrongful decline": 150, "needless referral": 15} # S$, invented def mistake_cost(grid, price=PRICE): return sum(price[kind] * n for kind, n in mistakes(grid).items()) for name, grid in [("A", GRID_A), ("B", GRID_B)]: print(name, f"{accuracy(grid):.0%}", f"kappa {kappa(grid):.2f}", f"straight-through {straight_through(grid):.0%}", "cost S$", mistake_cost(grid))

Takeaways要点回顾

• One accuracy number hides which mistakes were made.
• Name the mistakes: wrongful payment, wrongful decline, needless referral.
• Add kappa (beyond luck) and the straight-through rate (work saved).
• Price each mistake with the owners: the cheaper total wins, even at equal accuracy.

• 一个准确率会藏起犯了哪些错。
• 给错误起名：错付、错拒、白转交。
• 加上 kappa（扣掉运气）和直通率（省下的活）。
• 和负责人给每种错误标价：总数更低的赢，哪怕准确率一样。
