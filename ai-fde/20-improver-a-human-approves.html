Human-approved improver人批准的改进者

Let a second agent suggest improvements, with a person saying yes and code deciding what stays · ~30 min · hands-on让第二个智能体提改进建议，由人点头，由代码决定哪些留下 · 约 30 分钟 · 动手实践

Step 1 · Numbered versions, and an improver that only proposes第 1 步 · 带编号的版本，和只会提议的改进者

Learn先学
  • Three things decide how the agent behaves: its extra instructions, its model and its reasoning effort. Keep them as one configuration.
  • Every change makes a new numbered version; old ones are never edited. Each records what changed, why, who proposed it and who approved it.
  • The improver reads failures on the practice claims (never the held-out ones) and proposes exactly one change to one field. Only one round can be open at a time.
  • 三样东西决定智能体的行为：额外的指令、模型和推理力度。把它们放成一份配置。
  • 每次改动都产生一个带编号的新版本；旧版本绝不修改。每个版本记下改了什么、为什么、谁提议、谁批准。
  • 改进者读练习理赔上的失败案例（绝不看留出的那些），对一个字段正好提一个改动。同一时间只能开一轮。

This uses bench.py and scoreboard.py from the scoreboard lesson (claims, key, small_prompt, ask, gateway, HELD_OUT, held_claims) and scoring.py (matrix, accuracy, mistake_cost).

这里用到计分板那课的 bench.py 和 scoreboard.py（claims、key、small_prompt、ask、gateway、HELD_OUT、held_claims），以及 scoring.py（matrix、accuracy、mistake_cost）。

# versions.py import json, os FILE = "versions.json" FIELDS = ("instructions", "model", "effort") def save(state): json.dump(state, open(FILE, "w"), indent=2) def load(): if not os.path.exists(FILE): save({"active": 1, "log": [], "versions": [{ "n": 1, "instructions": "", "model": "anthropic/claude-haiku-5-5", "effort": "low", "changed": "starting point", "why": "the agent as it ran on the scoreboard", "proposed_by": "Mei Ling", "approved_by": "Mei Ling", "status": "kept", "scores": None}]}) return json.load(open(FILE)) def find(state, n): return next(v for v in state["versions"] if v["n"] == n) def active(state): return find(state, state["active"]) # improver.py import json from versions import load, save, find, active, FIELDS from bench import gateway, claims, key, small_prompt, ask from scoreboard import HELD_OUT IMPROVER = "anthropic/claude-sonnet-5-5" practice = [c for c in claims if c["id"] not in HELD_OUT] # the improver never sees held-out claims class Busy(Exception): pass def run_config(config, claim): reply = gateway.chat.completions.create( model=config["model"], messages=[{"role": "user", "content": config["instructions"] + "\n" + small_prompt(claim)}], extra_body={"reasoning": {"effort": config["effort"]}}) # check your gateway's name for this text = reply.choices[0].message.content return json.loads(text[text.index("{"): text.rindex("}") + 1]) def propose(): state = load() if any(v["status"] in ("proposed", "testing") for v in state["versions"]): raise Busy("a round is already open") config = active(state) results = [{"story": c["story"], "agent": run_config(config, c)["action"], "handler": key[c["id"]]["action"]} for c in practice] prompt = f"""You improve a claims agent. Current setup: {json.dumps({f: config[f] for f in FIELDS})} Results on practice claims: {json.dumps(results)} Propose ONE change to ONE of: instructions, model, effort. Reply with JSON only: {{"field": "instructions" or "model" or "effort", "value": "the new value", "why": "one sentence"}}""" proposal = ask(gateway, IMPROVER, prompt)[0] if proposal["field"] not in FIELDS or not str(proposal["value"]).strip(): raise ValueError("the improver must change exactly one of: " + ", ".join(FIELDS)) n = len(state["versions"]) + 1 new = {f: config[f] for f in FIELDS} new[proposal["field"]] = proposal["value"] state["versions"].append({"n": n, **new, "changed": proposal["field"], "why": proposal["why"], "proposed_by": "improver", "approved_by": None, "status": "proposed", "scores": None}) save(state) return n

Step 2 · A person approves, code decides第 2 步 · 人批准，代码来定

Learn先学
  • A proposal sits as proposed until a person acts. Approving records the name and moves it to testing. Rejecting closes the round and changes nothing else.
  • After approval, code runs the held-out claims with the new version and compares with the one in use. Keep it only if agreement is no lower, mistake cost is no higher, and one is better. Otherwise roll back: the agent stays on the old version.
  • The improver never marks its own work.
  • 提议保持 proposed，直到有人动手。批准会记下名字并变成 testing。拒绝结束这一轮，其余什么都不变。
  • 批准之后，代码用新版本去跑留出的理赔，和正在用的版本比。只有一致率没有更低、错误代价没有更高、且其中一项更好才留下。否则回滚：智能体继续用旧版本。
  • 改进者从不给自己的作业打分。
# improver.py, continued from scoreboard import held_claims from scoring import matrix, accuracy, mistake_cost def approve(n, who): state = load() version = find(state, n) if version["status"] != "proposed": raise ValueError("this version is not waiting for approval") version["approved_by"], version["status"] = who, "testing" save(state) def reject(n, who): state = load() version = find(state, n) if version["status"] != "proposed": raise ValueError("this version is not waiting for approval") version["rejected_by"], version["status"] = who, "rejected" save(state) def evaluate(config): grid = matrix([(key[c["id"]]["action"], run_config(config, c)["action"]) for c in held_claims]) return {"agreement": accuracy(grid), "mistake_cost_sgd": mistake_cost(grid)} def keep_or_roll_back(old, new): no_worse = new["agreement"] >= old["agreement"] and new["mistake_cost_sgd"] <= old["mistake_cost_sgd"] better = new["agreement"] > old["agreement"] or new["mistake_cost_sgd"] < old["mistake_cost_sgd"] return no_worse and better def finish_round(n): state = load() version, current = find(state, n), active(state) if version["status"] != "testing": raise ValueError("this version has not been approved") if current["scores"] is None: current["scores"] = evaluate(current) version["scores"] = evaluate(version) if keep_or_roll_back(current["scores"], version["scores"]): version["status"] = "kept" state["active"] = n else: version["status"] = "rolled_back" save(state) return version["status"]

Step 3 · A way back第 3 步 · 一条回头路

Learn先学

Going back to an older kept version only moves the pointer, and the move is logged with the handler's name. Nothing is deleted.

回到更早的已留下版本，只是挪动指针，并连同理赔员的名字记一笔。什么都不删。

def put_back_in_use(n, who): state = load() if find(state, n)["status"] != "kept": raise ValueError("only a kept version can be put back in use") state["active"] = n state["log"].append({"handler": who, "put_back": n}) save(state)

Common errors常见错误

ValueError: only a kept version can be put back in use
Fix: pick a version whose status is “kept”.

ValueError: only a kept version can be put back in use
解决：选状态是“kept”的版本。

json.decoder.JSONDecodeError: Expecting value
Fix: ask the improver for JSON only, and skip a proposal you cannot read.

解决：只要求改进者输出 JSON，读不出来的提议直接跳过。

Takeaways要点回顾

• Keep instructions, model and effort as one configuration, in numbered versions that are never edited.
• The improver proposes one change at a time and never sees the held-out claims.
• A person approves; rejecting changes nothing.
• Code, not the improver, decides keep or roll back.
• Going back moves a pointer and is logged.

• 把指令、模型和力度放进同一份配置，存成带编号、从不修改的版本。
• 改进者一次只提一个改动，并且看不到留出的理赔。
• 由人批准；拒绝不会改变任何东西。
• 留下还是回滚，由代码定，不由改进者定。
• 回头只是挪指针，并留有记录。
