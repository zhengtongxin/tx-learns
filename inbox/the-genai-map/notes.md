## Goal
Hold one simple picture of the generative AI world so new product names stop sounding like new planets.

## Points
1. Layer 1, chips and cloud: the machines that train and run models. Layer 2, models: text, image, speech and code models, some closed (sold by an API), some open (you can run them yourself). Layer 3, tools and platforms: where models are stitched to your data, such as search over documents (RAG), agents, and workflow builders. Layer 4, applications: finished products people use.
2. Technologies to name in plain words: large language model (predicts the next piece of text), multimodal (also reads images or audio), embeddings (turn text into numbers so similar things sit close), retrieval (look up facts before answering), fine-tuning (extra training on your examples), agents (a model that uses tools in a loop).
3. A buying question maps to a layer: 'which model?' is layer 2, 'how do I connect it to our files?' is layer 3, 'can we just buy something?' is layer 4.
4. Things change monthly at layer 2 and 3; the layers themselves change slowly. Learn the layers.

## What I got wrong (common slip-ups; tell them through Mdm Rohani or Mr Tan)
- Treating each new tool as a new category when it is one more thing at the same layer.
- Choosing a model before knowing what data it must reach.
- Believing 'open' means free of cost; running it still costs people and machines.

## Try it yourself
Draw the four layers on one page and place five AI products you have heard of. Then place two you could build yourself.

## Takeaways
Four layers: chips and cloud, models, tools and platforms, applications. Place any new name on a layer and it stops being scary.
