Protecting data · Lesson 3保护数据 · 第 3 课

Untrusted input不可信的输入

Treat everything a user sends as data, never as code, and stop injection · ~10 min · reading and practice把用户发来的一切当作数据而非代码，防住注入 · 约 10 分钟 · 阅读加练习

Step 1 · Input can become code第 1 步 · 输入可能变成代码

Learn先学

Anything that comes from outside is untrusted input: form fields, URLs, files, API calls, even text a model returns. The classic mistake is gluing it into a command, such as a SQL query. If the input contains query syntax, it changes what the query means. That is injection.

凡是来自外部的都是不可信的输入：表单字段、网址、文件、API 调用，甚至模型返回的文字。经典错误是把它直接拼进命令，比如 SQL 查询。如果输入里带有查询语法，就会改变查询的含义，这就是注入。

import sqlite3 db = sqlite3.connect(":memory:") db.execute("create table u(name text, pin text)") db.execute("insert into u values('ann','1111'),('bob','2222')") name = "x' OR '1'='1" sql = "select name from u where name='" + name + "'" print(len(db.execute(sql).fetchall()))

Step 2 · Use placeholders第 2 步 · 使用占位符

Learn先学

The fix is to keep the command and the data apart. With a placeholder (?), the database receives the query and the value separately and treats the value only as text to match, never as syntax. Do this for every query built from outside values, with no exceptions for “safe-looking” input.

办法是把命令和数据分开。用占位符（?）时，数据库分别接收查询和值，只把值当作要匹配的文本，从不当作语法。凡是用外部值构造的查询都这样做，不要因为输入“看起来安全”就例外。

Step 3 · Check what you accept第 3 步 · 检查你接受什么

Learn先学

Placeholders protect the query; validation protects the rest. Decide what a valid value looks like (a number between 1 and 100, an email-shaped string, one of three choices), accept only that, and reject everything else with a clear message. Prefer an allow-list of what is good over a block-list of what is bad, because you will never think of every bad case. Sort each practice.

占位符保护查询；校验保护其余部分。先决定合法的值长什么样（1 到 100 的数字、像邮箱的字符串、三个选项之一），只接受这些，其余一律明确拒绝。优先用“允许什么”的清单，而不是“禁止什么”的清单，因为你永远想不全所有坏情况。给每种做法分类。

Takeaways要点回顾

• Everything from outside is untrusted.
• Use placeholders so data never becomes syntax.
• Validate with an allow-list of what is valid.

• 一切来自外部的内容都不可信。
• 用占位符，让数据永远变不成语法。
• 用“合法值清单”做校验。
