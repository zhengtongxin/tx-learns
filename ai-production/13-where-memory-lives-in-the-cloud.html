Step 1 · The request path第 1 步 · 请求的路径

Learn先学
  • A bucket is a cloud folder for files, with no server. A CDN is a fast front door that caches pages near the visitor and gives them HTTPS. An API gateway is the public door for the backend.
  • Path: the browser asks the CDN; the CDN gets the page from a site bucket; the page calls the gateway; the gateway runs the function; the function calls the model and reads or writes the memory bucket.
  • 存储桶是云上存放文件的文件夹，不挂服务器。CDN 是很快的前门，把页面缓存在离访客近的地方并提供 HTTPS。API 网关是后端对外的公开入口。
  • 路径：浏览器问 CDN；CDN 从网站桶取页面；页面调用网关；网关运行函数；函数调用模型，并读写记忆桶。

Step 2 · Memory becomes bucket objects第 2 步 · 记忆变成存储桶对象

Learn先学
  • A serverless function has no durable disk: files vanish between calls and copies do not share them.
  • So store one object per session, named by the session id, using boto3 (pip install boto3). The bucket name comes from an environment variable.
  • One variable, USE_BUCKET, switches the same load_history / save_history between local files and the bucket. Keep the session id check.
  • 无服务器函数没有持久磁盘：文件在两次调用之间会消失，副本之间也不共享。
  • 所以每个会话存一个对象，名字用会话 id，用 boto3（pip install boto3）。桶名来自环境变量。
  • 一个变量 USE_BUCKET 让同样的 load_history / save_history 在本地文件和存储桶之间切换。保留会话 id 检查。
import json import os import boto3 from botocore.exceptions import ClientError s3 = boto3.client("s3") BUCKET = os.environ["MEMORY_BUCKET"] def load_from_bucket(session_id: str) -> list: try: obj = s3.get_object(Bucket=BUCKET, Key=f"{session_id}.json") return json.loads(obj["Body"].read()) except ClientError as err: if err.response["Error"]["Code"] == "NoSuchKey": return [] # a new visitor raise # anything else is a real problem def save_to_bucket(session_id: str, history: list) -> None: s3.put_object(Bucket=BUCKET, Key=f"{session_id}.json", Body=json.dumps(history).encode("utf-8"), ContentType="application/json")

Step 3 · Least privilege第 3 步 · 最小权限

Learn先学
  • Package the function: install libraries for the cloud's chip type, add your code, zip. A small adapter (mangum) lets FastAPI answer function calls.
  • Give the function a role that allows only what it needs: read and write objects in the memory bucket, plus list it (without list, a missing object reads "access denied" and a new visitor crashes the code).
  • 打包函数：按云的芯片类型安装库，加上你的代码，打成 zip。一个小适配库（mangum）让 FastAPI 能回应函数调用。
  • 给函数一个只允许它需要的事的角色：读写记忆桶里的对象，外加列出它（没有列出权限，对象不存在时会变成“拒绝访问”，新访客会让代码崩溃）。

Step 4 · CORS on the gateway第 4 步 · 网关上的 CORS

Learn先学

The page now comes from the CDN address and the API from another. The browser blocks the call unless the gateway answers with CORS headers allowing the page's address. Set it on the gateway; otherwise calls fail in the browser console while the function itself is fine.

页面现在来自 CDN 地址，API 来自另一个地址。除非网关用 CORS 头回应并允许页面的地址，否则浏览器会拦下调用。要在网关上设置；不然调用在浏览器控制台里失败，而函数本身其实没事。

API gateway → CORS Allowed origins: https://twin.example.com (the CDN address of the page) Allowed methods: POST, OPTIONS Allowed headers: content-type

Now make it yours现在把它变成你的

Common errors常见错误

• ClientError: AccessDenied: the role cannot read or write the bucket. Fix: match the bucket name exactly, with /* for objects.
• KeyError: 'MEMORY_BUCKET': not set on the function. Fix: add MEMORY_BUCKET and USE_BUCKET=true.
• Unable to import module 'server': wrong zip layout or libraries. Fix: rebuild with the --platform line and zip from inside package/.
• CORS error in the console: the gateway does not allow the page. Fix: add the CDN address as an allowed origin.

• ClientError: AccessDenied：角色不能读写该桶。 解决：桶名要完全一致，对象部分带 /*。
• KeyError: 'MEMORY_BUCKET'：函数上没设置。 解决：添加 MEMORY_BUCKET 和 USE_BUCKET=true。
• Unable to import module 'server'：压缩包结构或库不对。 解决：用带 --platform 的命令重新构建，并在 package/ 里面打包。
• 控制台 CORS 报错：网关没允许该页面。 解决：把 CDN 地址加进允许的来源。

Takeaways要点回顾

• Path: browser, CDN, site bucket, gateway, function, model, memory bucket.
• A function has no durable disk, so memory is one bucket object per session.
• One variable switches the same code between local files and the bucket.
• Give the function only the permissions it needs.
• The gateway needs CORS, or the browser blocks the calls.

• 路径：浏览器、CDN、网站桶、网关、函数、模型、记忆桶。
• 函数没有持久磁盘，所以记忆是桶里每个会话一个对象。
• 一个变量让同一份代码在本地文件和存储桶之间切换。
• 只给函数它需要的权限。
• 网关需要 CORS，否则浏览器会拦下调用。
