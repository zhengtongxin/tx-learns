What production means“生产环境”是什么

Get a tiny AI service onto a real public address before you learn anything fancy · ~20 min · hands-on先把一个小小的 AI 服务放到真实的公开地址上，再学别的花样 · 约 20 分钟 · 动手实践

Key point要点

Ship the smallest thing that works at a real address first. Add the model after.

先把最小的可用东西放到真实地址上，之后再加模型。

Step 1 · What "production" means第 1 步 · “生产环境”是什么

Learn先学

Production is not about size. It is three things:

  • Others can reach it.
  • It runs when your laptop is shut.
  • Secrets are not in the files.

“生产环境”与规模无关，只有三件事：

  • 别人能访问到它。
  • 合上笔记本它照样运行。
  • 密钥不在文件里。

Step 2 · Ship one route第 2 步 · 上线一个路由

Learn先学
  • A route is an address your service answers, like /api. FastAPI turns a function into one.
  • The host (someone else's computer) reads two notes: requirements.txt lists packages to install; vercel.json says what to build and sends every URL to it.
  • vercel deploys a preview (test copy). vercel --prod makes the real one.
  • 路由是服务能回应的地址，比如 /api。FastAPI 能把函数变成路由。
  • 托管平台（别人的电脑）读两张纸条：requirements.txt 列出要装的包；vercel.json 说明构建什么，并把所有网址交给它。
  • vercel 部署预览（测试副本），vercel --prod 才是正式版。
# api/index.py from fastapi import FastAPI app = FastAPI() @app.get("/api") def hello(): return {"message": "Hello from Tanjong Pagar"}
# requirements.txt fastapi uvicorn
# vercel.json { "builds": [{ "src": "api/index.py", "use": "@vercel/python" }], "routes": [{ "src": "/(.*)", "dest": "api/index.py" }] }
# once (needs Node) npm install -g vercel vercel login # every deploy vercel # preview address vercel --prod # production address

Step 3 · Add the model, keep the key out第 3 步 · 加上模型，把密钥放在外面

Learn先学

Each model call costs money, so it needs a key. The client reads it from an environment variable, a setting kept outside your files. Set it on the host with vercel env add, add openai to requirements.txt, then redeploy.

每次调用模型都要花钱，所以需要一把密钥。客户端从环境变量（放在文件之外的设置）里读取它。用 vercel env add 在平台上设置，把 openai 加进 requirements.txt，再重新部署。

# api/index.py from fastapi import FastAPI from openai import OpenAI app = FastAPI() client = OpenAI() # reads OPENAI_API_KEY from the environment @app.get("/api") def hello(): reply = client.chat.completions.create( model="gpt-5.4-mini", messages=[{"role": "user", "content": "Write a one-line welcome for a hawker centre."}], ) return {"message": reply.choices[0].message.content}
# terminal vercel env add OPENAI_API_KEY vercel --prod

Now make it yours现在把它变成你的

Common errors常见错误

• ModuleNotFoundError: No module named 'openai': it is missing from requirements.txt. Fix: add it and redeploy.
• AuthenticationError: Incorrect API key: the key is unset on the host or has a stray space. Fix: run vercel env add OPENAI_API_KEY again and redeploy.
• 404: NOT_FOUND: vercel.json does not point at api/index.py. Fix: check "src" and "dest".

• ModuleNotFoundError: No module named 'openai'：没写进 requirements.txt。 解决：加上并重新部署。
• AuthenticationError: Incorrect API key：平台上没设置密钥，或多了空格。 解决：重新运行 vercel env add OPENAI_API_KEY 并重新部署。
• 404: NOT_FOUND：vercel.json 没有指向 api/index.py。 解决：检查 "src" 和 "dest"。

Takeaways要点回顾

• Production: reachable by others, runs with your laptop shut, secrets outside the files.
• Ship a tiny route first, then add the model.
• requirements lists what to install; the config says what to build.
• A preview is a test copy; --prod is the real one.
• Secrets live in the host's environment settings, never in the repo.

• 生产环境：别人能访问、合上笔记本也运行、密钥在文件之外。
• 先上线一个小路由，再加模型。
• requirements 说明装什么；配置说明构建什么。
• 预览是测试副本，--prod 才是正式版。
• 密钥放在平台的环境设置里，绝不放进仓库。
