An AI twin with memory · Lesson 1有记忆的 AI 分身 · 第 1 课

Models forget模型会忘

See why a chat model seems to forget, and add the memory yourself · ~30 min · hands-on看清为什么聊天模型好像会忘事，并自己把记忆加上去 · 约 30 分钟 · 动手实践

Step 1 · The model keeps nothing第 1 步 · 模型什么都不留

Learn先学

A chat model is stateless: every call starts blank. A chat looks continuous only because the app sends the earlier messages again. In this first version, each call sends one message, so the twin cannot remember a name from the call before.

聊天模型是无状态的：每次调用都从空白开始。聊天看起来连贯，只是因为应用把之前的消息又发了一遍。这个第一版每次只发一条消息，所以分身记不住上一次调用里的名字。

from fastapi import FastAPI from pydantic import BaseModel from openai import OpenAI app = FastAPI() client = OpenAI() class Chat(BaseModel): session_id: str message: str @app.post("/api/chat") def chat(body: Chat): result = client.chat.completions.create( model="gpt-5.4-mini", messages=[{"role": "user", "content": body.message}], # only this one message ) return {"reply": result.choices[0].message.content}

Step 2 · Send the history, saved per session第 2 步 · 发送历史，按会话保存

Learn先学
  • Keep a list of messages per session id (the page makes one with crypto.randomUUID()). Add the user message, send the whole list, add the reply.
  • A Python dictionary dies on restart, so write each session to its own JSON file.
  • The id comes from the browser, so check it holds only safe characters before using it as a file name.
  • 为每个会话 id 保存一份消息列表（页面用 crypto.randomUUID() 生成）。加入用户消息，发出整个列表，再加入回复。
  • Python 字典一重启就没了，所以把每个会话写进各自的 JSON 文件。
  • id 来自浏览器，用作文件名之前要检查它只含安全字符。
import json import re from pathlib import Path MEMORY_DIR = Path("memory") MEMORY_DIR.mkdir(exist_ok=True) def session_file(session_id: str) -> Path: if not re.fullmatch(r"[A-Za-z0-9-]{1,64}", session_id): raise ValueError("bad session id") return MEMORY_DIR / f"{session_id}.json" def load_history(session_id: str) -> list: path = session_file(session_id) return json.loads(path.read_text(encoding="utf-8")) if path.exists() else [] def save_history(session_id: str, history: list) -> None: session_file(session_id).write_text(json.dumps(history, ensure_ascii=False), encoding="utf-8")
from memory import load_history, save_history @app.post("/api/chat") def chat(body: Chat): history = load_history(body.session_id) history.append({"role": "user", "content": body.message}) result = client.chat.completions.create(model="gpt-5.4-mini", messages=history) reply = result.choices[0].message.content history.append({"role": "assistant", "content": reply}) save_history(body.session_id, history) return {"reply": reply}

Step 3 · Do not let it grow forever第 3 步 · 别让它无限增长

Learn先学
  • Every call sends the whole history, so a long chat costs more with every message.
  • Send only the latest part, such as the last 20 messages. The file keeps everything.
  • A conversation is personal data: decide how long files live and who can read them.
  • 每次调用都发整段历史，所以聊得越长，每条消息越贵。
  • 只发最近的部分，比如最近 20 条消息。文件里保留全部。
  • 对话是个人数据：要决定文件保留多久、谁能读。
# in chat(), change the call to: result = client.chat.completions.create( model="gpt-5.4-mini", messages=history[-20:], # only the latest 20 go to the model )

Now make it yours现在把它变成你的

Common errors常见错误

• 422 Unprocessable Entity: the body lacks session_id or message. Fix: send both as JSON.
• ValueError: bad session id: unsafe characters. Fix: use crypto.randomUUID().
• The twin forgets after a deploy: files lived in a wiped folder. Fix: store them somewhere that lasts (the next lessons do).

• 422 Unprocessable Entity：请求体缺少 session_id 或 message。 解决：两者都以 JSON 发送。
• ValueError: bad session id：含不安全字符。 解决：用 crypto.randomUUID()。
• 部署后分身忘事：文件放在会被清空的文件夹。 解决：存到能持久保存的地方（后面的课会做）。

Takeaways要点回顾

• A chat model is stateless: every call starts blank.
• Memory is your stored messages plus a session id, sent with each call.
• Save sessions to files and check the id before using it as a name.
• Cap what you send; keep the full record on disk.
• Decide what to keep, for how long, and who can read it.

• 聊天模型是无状态的：每次调用都从空白开始。
• 记忆就是你存下的消息加会话 id，随每次调用发出。
• 把会话存成文件，用作文件名前先检查 id。
• 限制发送的量；完整记录留在磁盘上。
• 要决定保留什么、保留多久、谁能读。
