Step 1 · A sandbox tool for running code第 1 步 · 跑代码的沙盒工具

Learn先学

Start from a working planner: an agent on Amazon Bedrock AgentCore (a managed service that runs your agent code in the cloud) with three tools, add_todo, mark_done and show_plan. Add one thing at a time. A code interpreter is a managed sandbox: a sealed box in the cloud that runs Python and hands back the output. A model wrote that code, so it could do anything; the sandbox keeps any damage inside the box. The result streams back in pieces, so the loop joins them. A region is the data-centre location your cloud resources live in (ap-southeast-1 is Singapore). Create the sandbox in the same region as your agent, or the call fails.

从一个能跑的规划智能体出发：它在 Amazon Bedrock AgentCore（在云上运行你的智能体代码的托管服务）上，有三个工具 add_todo、mark_done 和 show_plan。一次只加一样东西。代码解释器是托管沙盒：云上一个封闭的盒子，运行 Python 并把输出交回来。代码是模型写的，什么都可能做；沙盒把损害关在盒子里。结果分成小块陆续返回，所以循环要把它们拼起来。区域（region）是云资源所在的数据中心位置（ap-southeast-1 是新加坡）。沙盒要建在和智能体相同的区域，否则调用会失败。

# agent.py from the last lesson, continued: Agent, tool and the three plan tools are already there from bedrock_agentcore.tools.code_interpreter_client import code_session @tool def run_python(code: str) -> str: """Run Python code in a safe sandbox and return what it prints. Use it to check an answer. Always print the result.""" with code_session("ap-southeast-1") as sandbox: # the region you gave to: agentcore configure --region ... response = sandbox.invoke( "executeCode", {"code": code, "language": "python", "clearContext": False}, ) output = "" for event in response["stream"]: output += str(event["result"]) return output

Step 2 · Make the check a required to-do第 2 步 · 把验证写成必做的待办

Learn先学

Giving the agent a sandbox is not enough: it may skip it. In the system prompt, have it solve first without code, then add a to-do starting "Write Python code to..." and run it to check. As a line in the plan, the check is no longer optional. handle() is the function in agent.py that the service calls with each request; make it call checker, then run agentcore launch again to deploy the change.

光给智能体沙盒不够：它可能跳过。在系统提示词里，让它先不用代码自己解，再加一条以“Write Python code to...”开头的待办并运行它来验证。写进计划之后，验证就不再是可选的了。handle() 是 agent.py 里每来一个请求、服务就会调用的函数；让它改调 checker，再运行一次 agentcore launch 把改动部署上去。

checker = Agent( system_prompt=( # the standing instruction the model reads before every request "Make a plan with add_todo. Solve the task yourself first, without code. " "Then add one more to-do that starts with 'Write Python code to' " "and use run_python to check your answer. " "If the check disagrees, fix the answer. Mark each step done, then reply." ), tools=[add_todo, mark_done, show_plan, run_python], ) # in handle(), call checker in place of the old agent, then: agentcore launch

Step 3 · Try a puzzle, read the trace, clean up第 3 步 · 出一道谜题，读轨迹，清理

Learn先学

Invoke it with a puzzle whose answer you know: four crane operators swapping shifts so nobody keeps their own. Such a shuffle is called a derangement: of the 24 ways to order four people, 9 leave nobody in place. Read the plan, the answer and the check. Turn on observability in the console before the run, and the trace records each tool call, its time and its tokens, so you can find the slowest step. When you finish, delete the deployed agent, its image and its roles.

用一道你知道答案的谜题调用它：四个吊机司机互换班次、谁都不留在自己的班次。这样的排法叫错排（derangement）：四个人共有 24 种排法，其中 9 种没有任何人留在原位。读计划、答案和验证。运行之前先在控制台打开可观测性，轨迹会记下每次工具调用的耗时和 token，让你找出最慢的一步。做完之后，删掉部署的智能体、它的镜像和角色。

1. [x] Work out the answer by reasoning: 9 2. [x] Write Python code to check the count of derangements of 4 output: 9 3. [x] Compare the two There are 9 ways.

Now make it yours现在把它变成你的

Common errors常见错误

• AccessDeniedException on code interpreter Fix: Add that permission to the agent role, or relaunch.
• The checker never calls run_python Fix: Keep the "Write Python code to" sentence exactly in the system prompt.
• The sandbox prints nothing Fix: The code must print its result; keep that line in the tool text.

• AccessDeniedException on code interpreter 解决：给智能体角色加上这项权限，或重新启动。
• The checker never calls run_python 解决：把 “Write Python code to” 那句话原样保留在系统提示词里。
• The sandbox prints nothing 解决：代码必须打印结果；请保留工具说明里的那一行。

Takeaways要点回顾

• A managed code interpreter runs model-written code in a sealed sandbox, not on your machines.
• Keep the sandbox in the agent's region.
• Make the check a required to-do, not a suggestion.
• Turn on observability before the run, then read the trace.
• Delete the agent and its resources when you finish.

• 托管的代码解释器在封闭沙盒里运行模型写的代码，不在你的机器上。
• 沙盒和智能体放在同一个区域。
• 把验证写成必做的待办，而不是建议。
• 运行之前先打开可观测性，然后读轨迹。
• 做完之后，把智能体和它的资源删掉。
