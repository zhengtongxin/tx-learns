Safe cloud account安全的云账号

Open a cloud account the safe way, before you deploy anything · ~20 min · hands-on在部署任何东西之前，先用安全的方式开好云账号 · 约 20 分钟 · 动手实践

Step 1 · Lock root away, set alarms first第 1 步 · 锁起根用户，先设警报

Learn先学
  • Signing up gives you a root user that can do everything, even close the account. Protect it with MFA (password plus a one-time code from your phone), then stop using it.
  • A budget alert emails you when spend reaches a number you chose. Set it before creating anything: it cannot warn you about spending that already happened. It only sends email; it does not stop the spending.
  • Use several levels: a nudge, a warning, a shout.
  • 注册会给你一个什么都能做的根用户，连关闭账号都行。用 MFA（密码加手机上的一次性验证码）保护它，然后不要再用。
  • 预算警报会在花费达到你设定的数字时发邮件。要在创建任何东西之前设好：它没法提醒你已经发生的花费。它只发邮件，不会停止花费。
  • 多设几档：提醒、警告、大喊。
Budget name Amount (USD) Email when spend reaches nudge 1 50% of the amount warn 5 80% of the amount shout 10 100% of the amount (pick numbers you could not ignore)

Step 2 · A limited user in a group第 2 步 · 用户组里的受限用户

Learn先学
  • Give permissions to a user group, not to people. A new teammate is one name added to the group.
  • Do daily work as the limited user, never root.
  • 把权限给用户组，不要直接给人。新同事只需往组里加一个名字。
  • 日常工作用受限用户，不要用根用户。
Group: builders permissions: container registry (store images) serverless functions (run code) storage buckets (keep files) CDN (serve pages fast) API gateway (public front door) logs (read what happened) User: alex → member of builders

Step 3 · Pick a region, learn four words第 3 步 · 选区域，认四个词

Learn先学
  • A region is where your resources physically live. Pick one close to your users (for example Singapore) and keep it the same. Resources are invisible from other regions: if something vanished, check the region first.
  • Serverless compute runs your code when called. A container registry stores packaged apps (images). The identity service decides who can do what. The logging service keeps what your code prints. (AWS: Lambda, ECR, IAM, CloudWatch.)
  • 区域是你的资源实际所在的地理位置。选离用户近的（比如新加坡）并保持不变。其他区域看不到这里的资源：东西不见了，先查区域。
  • 无服务器计算在被调用时运行你的代码。容器镜像仓库存放打包好的应用（镜像）。身份服务决定谁能做什么。日志服务保存你的代码打印的内容。（AWS 里是 Lambda、ECR、IAM、CloudWatch。）

Now make it yours现在把它变成你的

Takeaways要点回顾

• MFA on root, then leave it alone.
• Budget alerts first, before any resource.
• Permissions go to a group; people join the group.
• Choose a region on purpose: resources are invisible across regions.

• 根用户开 MFA，然后别去动它。
• 先设预算警报，再建任何资源。
• 权限给用户组，人加入用户组。
• 有意识地选区域：资源跨区域是看不见的。
