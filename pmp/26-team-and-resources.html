Step 1 · Ground rules and a team charter第 1 步 · 基本规则与团队章程

Learn先学

A team charter is the team’s own agreement on how it works: values, meeting times, how decisions are made, how conflict is handled. Do not confuse it with the project charter, which authorises the project. The team writes it together, early, so a new member can read it and know what is expected.

团队章程是团队自己对工作方式的约定：价值观、开会时间、怎样做决定、怎样处理冲突。别把它和批准项目的项目章程混淆。团队要在早期一起写，让新成员读了就知道大家的期望。

Core hours: 10:00 to 16:00, all in the chat Decisions: try consensus, else the owner decides Blockers: raise in the daily stand-up, not later Conflict: talk to the person first, then the lead

Step 2 · Who does what: RACI第 2 步 · 谁做什么：RACI

Learn先学

A RACI chart lists tasks down one side and people across the top. R responsible does the work. A accountable owns the result and approves it; each task has exactly one. C consulted gives input both ways before a decision. I informed is told afterwards.

RACI 表一边列任务，一边列人。R 负责人做事。A 问责人对结果负责并批准，每项任务只有一位。C 被咨询者在决定前提供意见，双向沟通。I 被通知者事后得知。

Sort each description.

给每条描述分类。

Sort each one.

给每一项分类。

Step 3 · Fit work to the people you have第 3 步 · 让工作适配手上的人

Learn先学

A resource calendar shows when each person or machine is available. When one person is booked on two tasks at once, you have two tools. Resource levelling moves tasks so nobody is overbooked, and it can push the end date out. Resource smoothing adjusts work only inside the available float, so the end date does not move.

资源日历显示每个人或每台设备何时可用。当一个人同时被排到两项任务，你有两个工具。资源平衡通过挪动任务让没人超负荷，它可能让完工日期往后推。资源平滑只在可用的浮动时间内调整，所以完工日期不动。

Busy week: Ravi is booked on Task A (40 h) and Task B (40 h) A person has 40 h in a week. Levelling: start Task B the week after -> no overbooking, may end later Smoothing: use B's float to start it a week later if B has a week of float -> end date unchanged

Takeaways要点回顾

• A team charter is the team’s own agreement on how it works.
• RACI: one A per task; R does it, C advises, I is told after.
• A resource calendar shows availability.
• Levelling can move the end date; smoothing stays within float.

• 团队章程是团队自己对工作方式的约定。
• RACI：每项任务一个 A；R 做事，C 出主意，I 事后被告知。
• 资源日历显示可用时间。
• 平衡可能改变完工日期；平滑只在浮动时间内。
