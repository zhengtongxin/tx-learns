Starting and finishing开始与完成

Beat delay with a tiny first step, keep a visible list of what is done and finish things instead of leaving them nearly done · ~10 min · reading and practice用一个很小的第一步战胜拖延，保留看得见的完成清单，把事情做完而不是停在快做完 · 约 10 分钟 · 阅读加练习

Step 1 · Make the first step tiny第 1 步 · 让第一步很小

Learn先学

We delay when a task feels big, vague or unpleasant. The way in is a first step so small it is almost silly: open the document and write the title; put on your shoes; write the first sentence badly. Starting changes the feeling: a blank page feels heavy, but once the heading is written you are editing, not facing a mountain. The task is no longer an idea; it is something you are already in. Aim to begin; finishing comes in Step 3.

任务显得太大、太模糊或不愉快时，我们就会拖。入口是一个小到有点可笑的第一步：打开文档，写下标题；穿上鞋子；随便写出第一句。开始会改变感觉：空白页让人觉得沉重，可一旦写下标题，你就是在修改，而不是面对一座山。因为任务不再是个念头，而是你已经身处其中的事。目标是开始；怎么完成，第 3 步再说。

Step 2 · See your progress第 2 步 · 看见进度

Learn先学

Keep a done list next to the to-do list. Ticking items off, or moving the item to a Done section, gives a small reward and shows that you are moving. Break a big goal into steps you can finish in one sitting, so each tick is real. When motivation is low, a visible streak of small wins often does more than a new plan.

在待办清单旁边放一份“已完成”清单。划掉条目，或把条目移到“已完成”部分，会给你一点小奖励，也让你看到自己在前进。把大目标拆成一次就能做完的步骤，每个勾都是真的。动力不足时，一串看得见的小成就，往往比一个新计划更管用。

Sort each one.

给每一项分类。

Step 3 · Finish things第 3 步 · 把事情做完

Learn先学

Many things sit at ninety percent, taking up thought but producing nothing. Before starting something new, ask whether you can finish what is open. Define done up front, so you know when to stop polishing: for example, “done means the report is sent, with the three sections filled in”. Limit the number of tasks in progress to about three; a short list that moves beats a long list that stalls.

很多事停在百分之九十，占着心思却没有产出。开始新事之前，先问问能不能把手头的做完。事先定义“完成”，就知道什么时候该停止打磨，比如“完成就是报告发出去，三个部分都填好了”。把同时进行的任务限制在三件左右；短而在动的清单，胜过长而停滞的清单。

To do (max 3 in progress): - Report: write section 2 - Email: send the invoice Done today: - Booked the venue - Sent the agenda First step for the report: open the file, write the heading.

Takeaways要点回顾

• Start tiny.
• Keep a done list.

• 从很小的开始。
• 保留完成清单。
• 先完成再开新的。
