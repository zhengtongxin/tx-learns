Putting a model behind an API把模型放到 API 后面

You will learn to turn a model that needs a GPU into a function you can call from anywhere, paying only when it runs · ~20 min · concept你会学会把需要 GPU 的模型变成随处可调用的函数，只在运行时付费 · 约 20 分钟 · 概念课

The story故事

Wei Jie's tuned price model needs a GPU. His laptop at the repair counter has none, and renting a GPU all day for a few price guesses would burn money. He wants a function that wakes a GPU only when someone calls it, then goes back to sleep. Ah Boy just wants to type a description and get a price.

Wei Jie 的微调估价模型需要 GPU。他在维修柜台的笔记本没有，而为了偶尔几次估价整天租一块 GPU 太烧钱。他想要一个函数：有人调用时才唤醒 GPU，用完就让它睡。Ah Boy 只想输入一段描述，就得到价格。

Step 1 · Serverless: a GPU that sleeps第 1 步 · 无服务器：会睡觉的 GPU

Learn先学

Serverless means you do not keep a machine running. You describe what the code needs, and the platform starts a machine when a call arrives and stops it afterwards. You pay for the seconds it ran. It is like the aircon compressor that hums only when the room is hot, instead of running all night. For a GPU model that is called now and then, that is the right shape.

无服务器的意思是你不用让机器一直开着。你描述代码需要什么，平台在调用到来时启动机器，用完就停。你只为运行的那几秒付费。就像空调压缩机只在房间热时才嗡嗡响，而不是整夜开着。对偶尔才被调用的 GPU 模型来说，这就是合适的形状。

laptop (no GPU) --call--> platform --starts--> container with a GPU runs the model, returns a number platform --stops---> nothing running, nothing billed

Step 2 · Describe the machine in Python第 2 步 · 用 Python 描述机器

Learn先学

The platform here is Modal, which lets you define the machine in Python. After you sign up, make a token and install and authenticate its command-line tool. Then declare an app, an image (a base Linux with the Python packages your model needs), a secret that holds your hub token, and a GPU type. The secret lives in the platform's store, never in your code.

这里用的平台是 Modal，它让你用 Python 定义机器。注册后创建令牌，安装并登录它的命令行工具。然后声明一个 app、一个 image（一个装好模型所需 Python 包的基础 Linux）、一个保存 hub 令牌的 secret，以及 GPU 类型。secret 放在平台的保管库里，绝不写进代码。

import modal app = modal.App("price-guesser") image = modal.Image.debian_slim().pip_install("torch", "transformers", "peft", "bitsandbytes") secrets = [modal.Secret.from_name("hub-token")] # the name of a secret stored on the platform GPU = "T4"

Step 3 · Turn the model into a remote function第 3 步 · 把模型变成远程函数

Learn先学

Decorate a function so it runs on the platform instead of your laptop. Inside it, load the base model in 4 bits, attach the adapter, build the prompt, generate a few tokens and return the number. The decorator carries the image, the secrets, the GPU and a timeout, so a slow first load does not get cut off.

给函数加上装饰器，让它在平台上而不是你的笔记本上运行。函数里加载 4 位底座、挂上附加件、拼好提示、生成几个 token，然后返回数字。装饰器带上 image、secrets、GPU 和超时时间，这样第一次加载慢也不会被打断。

# app, image, secrets and GPU come from the last step @app.function(image=image, secrets=secrets, gpu=GPU, timeout=1800) def price(description: str) -> float: # load base in 4 bits, attach the adapter, then: prompt = f"{description}\nPrice is $" return guess_price(prompt) # the guessing function from the project; define it in this file too, so it runs in the container

Step 4 · Call it, and meet the cold start第 4 步 · 调用它，认识冷启动

Learn先学

From a notebook you call the function with .remote(). The first call has a cold start: the container boots and the weights load, which can take minutes. Later calls reuse a warm container for a while, so they take seconds. A cache volume for the model files avoids downloading them every time, and a scale-down time decides how long the machine waits before sleeping. Then deploy the app so it has a stable name that any other program can look up.

在笔记本里用 .remote() 调用这个函数。第一次调用有冷启动：容器启动、权重加载，可能要几分钟。之后的调用会在一段时间内复用温热的容器，只要几秒。给模型文件配一个缓存卷，就不用每次重新下载；缩容时间则决定机器睡觉前等多久。最后部署这个 app，让它有个稳定的名字，别的程序都能查到。

# in a notebook: a one-off run with app.run(): print(price.remote("Used phone, 128 GB, cracked corner")) # slow: cold start print(price.remote("Used phone, 128 GB, clean screen")) # fast: warm # from the terminal: modal deploy price_guesser.py # from another program: fn = modal.Function.from_name("price-guesser", "price") print(fn.remote("Used earbuds, boxed"))

Step 5 · Make the input look like the training data第 5 步 · 让输入长得像训练数据

Learn先学

A tuned model only does well on inputs that look like what it trained on. Real listings are messy: capital letters, emoji, half sentences. So add a small preprocessing step before the model. A cheap LLM rewrites the messy listing into the same tidy format used in training, then the tuned model guesses. Also keep a local and a remote version of the same function so you can test the logic without paying for a GPU.

微调模型只在像它训练数据的输入上表现好。真实的商品信息很乱：大小写、表情符号、半截句子。所以在模型前加一个小小的预处理步骤：由一个便宜的 LLM 把杂乱的信息改写成训练时用的整齐格式，再交给微调模型估价。同时保留同一个函数的本地和远程两个版本，这样不用花 GPU 的钱就能测试逻辑。

from openai import OpenAI client = OpenAI() def tidy(raw: str) -> str: reply = client.chat.completions.create(model="your-cheap-model", messages=[ {"role": "system", "content": "Rewrite this listing as one plain sentence about the item, its size and its condition. No emoji."}, {"role": "user", "content": raw}]) return reply.choices[0].message.content print(price.remote(tidy("SELLING!!! iphone 128gb crack corner but works LOL")))

What I got wrong我搞错的地方I pasted my hub token straight into the notebook. I moved it into a named secret and rotated the token. I also forgot that the secret's name and the environment variable keys inside it are separate things, so my code could not find the token until I matched them.我把 hub 令牌直接粘贴进了笔记本。后来我把它放进命名的 secret，并更换了令牌。我还忘了 secret 的名字和里面的环境变量名是两回事，所以在对上之前，代码一直找不到令牌。

Now make it yours现在把它变成你的

Back at the void deck回到组屋底层The lift at Block 12 does not run empty all night. It waits at the ground floor and moves when someone presses the button. A serverless GPU is the same lift: the first press means a short wait, and the next press while it is nearby is fast.12 座的电梯不会整夜空跑。它停在一楼，有人按按钮才动。无服务器 GPU 就是这部电梯：第一次按要稍等；它还在附近时再按，就很快。

Takeaways要点回顾

• Serverless GPU means you pay per use, not per day.
• You describe the machine in Python: app, image, secrets, GPU.
• Decorate a function so it runs remotely, with a generous timeout.
• The first call is a cold start; later calls are warm and fast.
• Secrets live in the platform's store, never in code.
• Set timeouts and a scale-down time to control cost.
• Tidy inputs so they look like the training data.

• 无服务器 GPU 意味着按用量付费，而不是按天。
• 用 Python 描述机器：app、image、secrets、GPU。
• 给函数加装饰器让它远程运行，并设置宽裕的超时。
• 第一次调用是冷启动；之后是温热的，很快。
• secret 放在平台的保管库里，绝不写进代码。
• 设置超时和缩容时间来控制成本。
• 把输入整理成像训练数据的样子。
