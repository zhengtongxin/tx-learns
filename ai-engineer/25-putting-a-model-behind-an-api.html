Step 1 · Serverless: describe a machine that sleeps第 1 步 · 无服务器：描述一台会睡觉的机器

Learn先学

Serverless means no machine runs all day. The platform starts one when a call arrives, stops it afterwards, and you pay for the seconds used. For a GPU model called now and then, that is the right shape (like an aircon compressor that hums only when the room is hot).

无服务器意味着没有机器整天开着。平台在调用到来时启动一台，用完就停，你只为用到的那几秒付费。对偶尔才被调用的 GPU 模型来说，这就是合适的形状（就像空调压缩机只在房间热时才嗡嗡响）。

Modal lets you define the machine in Python: an app, an image (Linux plus the packages your model needs), a secret holding your hub token, and a GPU type. The secret lives in the platform's store, never in your code.

Modal 让你用 Python 定义机器：一个 app、一个 image（Linux 加模型需要的包）、一个保存 hub 令牌的 secret，以及 GPU 类型。secret 放在平台的保管库里，绝不写进代码。

import modal app = modal.App("price-guesser") image = modal.Image.debian_slim().pip_install("torch", "transformers", "peft", "bitsandbytes") secrets = [modal.Secret.from_name("hub-token")] # the name of a secret stored on the platform GPU = "T4"

Step 2 · A remote function, and the cold start第 2 步 · 远程函数与冷启动

Learn先学

Decorate a function so it runs on the platform. Inside, load the base in 4 bits, attach the adapter, build the prompt and return the number; give it a long timeout. Call it with .remote(). The first call is a cold start (container boots, weights load: minutes); later calls reuse a warm container (seconds). Deploy the app to give it a stable name any program can look up.

给函数加装饰器，让它在平台上运行。函数里加载 4 位底座、挂上附加件、拼好提示并返回数字；设置较长的超时。用 .remote() 调用。第一次调用是冷启动（容器启动、权重加载：几分钟）；之后复用温热的容器（几秒）。部署 app 后它有个稳定的名字，别的程序都能查到。

Step 3 · Make the input look like the training data第 3 步 · 让输入长得像训练数据

Learn先学

A tuned model does well only on inputs that look like its training data. Real listings are messy (capitals, emoji, half sentences), so a cheap LLM first rewrites them into the tidy training format, then the tuned model guesses.

微调模型只在像训练数据的输入上表现好。真实的商品信息很乱（大小写、表情符号、半截句子），所以先由便宜的 LLM 把它们改写成训练时的整齐格式，再交给微调模型估价。

from openai import OpenAI client = OpenAI() def tidy(raw: str) -> str: reply = client.chat.completions.create(model="your-cheap-model", messages=[ {"role": "system", "content": "Rewrite this listing as one plain sentence about the item, its size and its condition. No emoji."}, {"role": "user", "content": raw}]) return reply.choices[0].message.content print(price.remote(tidy("SELLING!!! iphone 128gb crack corner but works LOL")))

Common errors常见报错modal.exception.AuthError: run modal setup once. A first call that takes minutes is the cold start. ModuleNotFoundError in the remote function: add the package to pip_install.modal.exception.AuthError：运行一次 modal setup。第一次调用要几分钟是冷启动。远程函数里报 ModuleNotFoundError：把包加进 pip_install。

Takeaways要点回顾

• Serverless GPU: pay per use, not per day.
• Describe the machine in Python (app, image, secrets, GPU); secrets never go in code.
• First call is a cold start; later calls are warm.
• Tidy inputs so they look like the training data.

• 无服务器 GPU：按用量付费，而不是按天。
• 用 Python 描述机器（app、image、secrets、GPU）；secret 绝不写进代码。
• 第一次调用是冷启动；之后是温热的。
• 把输入整理成像训练数据的样子。
