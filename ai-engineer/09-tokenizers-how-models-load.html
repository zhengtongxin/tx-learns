Tokenizers and model loading分词器与模型加载

You will load an open chat model yourself, step by step, and fit it on a small GPU · ~20 min · hands-on你会一步一步亲手加载一个开源聊天模型，并把它塞进小 GPU · 约 20 分钟 · 动手实践

Step 1 · A tokenizer turns text into numbers第 1 步 · 分词器把文字变成数字

Learn先学

A model reads only numbers. The tokenizer cuts text into pieces and gives each an id from its vocabulary. Every model family has its own tokenizer, so the same sentence gets different ids and counts in each. Like an EZ-Link gate, each system reads only its own card.

模型只读数字。分词器把文字切成小块，从词表里给每块一个 id。每个模型家族有自己的分词器，所以同一句话在不同家族里 id 和数量都不同。就像 EZ-Link 闸机，每个系统只认自己的卡。

from transformers import AutoTokenizer name = "some-org/some-chat-model" # pick an open chat model from the hub tok = AutoTokenizer.from_pretrained(name) ids = tok.encode("The lift on level 7 is under repair") print(len(ids), ids) print(tok.decode(ids))

Step 2 · The chat template第 2 步 · 对话模板

Learn先学

A chat model was trained on one exact layout, with special tokens marking who speaks, and families differ. Do not hand-write it: give the tokenizer the same role-and-content list you use with an API, and apply_chat_template builds it. API providers do this behind the scenes.

聊天模型训练时只见过一种确切的版式，用特殊 token 标明谁在说话，各家族不同。不要手写：把和 API 一样的角色加内容列表交给分词器，apply_chat_template 就会生成。API 服务商在背后替你做了这件事。

messages = [ {"role": "system", "content": "You read lift notices in a warm, clear voice."}, {"role": "user", "content": "Lift B is closed on Tuesday for servicing."}, ] text = tok.apply_chat_template(messages, tokenize=False, add_generation_prompt=True) print(text) # look at the special markers it added

Step 3 · Load the model and generate第 3 步 · 加载模型并生成

Learn先学

Pair the tokenizer with its model: same family and name, or you get nonsense. device_map="auto" puts the weights on the GPU. Encode the chat, call generate, decode only the new ids. Some models need a licence accepted and a hub access token first.

把分词器和它的模型配成一对：同一家族、同一名字，否则是乱码。device_map="auto" 把权重放到 GPU 上。编码对话，调用 generate，只解码新生成的 id。有些模型要先接受许可并使用 hub 访问令牌。

from transformers import AutoModelForCausalLM model = AutoModelForCausalLM.from_pretrained(name, device_map="auto") print(model.get_memory_footprint() / 1e9, "GB") inputs = tok.apply_chat_template(messages, add_generation_prompt=True, return_tensors="pt").to("cuda") out = model.generate(inputs, max_new_tokens=80) print(tok.decode(out[0][inputs.shape[1]:])) # only the new ids

Step 4 · Squeeze it with 4-bit quantisation第 4 步 · 用 4 位量化压缩

Learn先学

A multi-billion-parameter model in full precision can fill a free GPU. Quantisation stores each weight in 4 bits instead of 16: memory drops to about a quarter for a small quality loss. Memory, not speed, is the first wall. A text streamer shows words as they are made.

几十亿参数的全精度模型可能占满一块免费 GPU。量化把每个权重从 16 位改成 4 位存：内存降到约四分之一，质量只损失一点。第一堵墙是内存，不是速度。文本流式输出器让字边生成边显示。

import torch from transformers import BitsAndBytesConfig, TextStreamer small = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_compute_dtype=torch.bfloat16) model = AutoModelForCausalLM.from_pretrained(name, device_map="auto", quantization_config=small) print(model.get_memory_footprint() / 1e9, "GB") # roughly a quarter model.generate(inputs, streamer=TextStreamer(tok), max_new_tokens=80)

Common errors常见报错

• gated repo / 401 Unauthorized. Accept the licence on the model page, then huggingface-cli login.
• CUDA out of memory. Load in 4-bit or pick a smaller model.

• gated repo / 401 Unauthorized：到模型页面同意许可，再用 huggingface-cli login 登录。
• CUDA out of memory：改用 4 位加载或换更小的模型。

Takeaways要点回顾

• A tokenizer turns text into ids; each model family has its own.
• The chat template is the layout the model was trained on: never hand-write it.
• Tokenizer and model are a pair and must match.
• get_memory_footprint() shows what the model costs in GPU memory.
• 4-bit quantisation cuts memory to about a quarter for a small quality loss.

• 分词器把文字变成 id，每个模型家族都有自己的一套。
• 对话模板是模型训练时的版式：不要手写。
• 分词器和模型是一对，必须匹配。
• get_memory_footprint() 告诉你模型占多少 GPU 内存。
• 4 位量化把内存砍到约四分之一，质量只损失一点。
