The story故事

Ah Boy knows second-hand prices by heart, but he cannot sit at the counter all day. Wei Jie wants a program that reads a gadget's description and guesses its price. Ah Boy hands over a huge pile of online listings: title, description, features and price. Before any model, Wei Jie has to make that pile fit to learn from.

Ah Boy 把二手价格背得滚瓜烂熟，可他不能整天守在柜台。Wei Jie 想做个程序，读一件数码产品的描述就猜出价格。Ah Boy 给了他一大堆网上的商品列表：标题、描述、特点和价格。在碰任何模型之前，Wei Jie 得先把这堆东西整理到适合学习的程度。

Step 1 · Look before you touch第 1 步 · 先看，再动手

Learn先学

A model can only learn from what you feed it, so look at the data first. Load a published dataset from the Hugging Face hub with load_dataset. Print one record, the most expensive record, and how many records have a price at all. Think of a stock-take: you count what is on the shelf before you decide what to sell.

模型只能从你喂给它的东西里学，所以先看数据。用 load_dataset 从 Hugging Face hub 加载一个公开数据集。打印一条记录、最贵的一条记录，以及到底有多少条记录有价格。就像盘点货架：先数清货架上有什么，再决定卖什么。

from datasets import load_dataset listings = load_dataset("your-name/gadget-listings", split="train") # your own dataset id print(listings[0]) # one record priced = [r for r in listings if r["price"]] # many have no price print(len(priced), "of", len(listings), "have a price") print(max(priced, key=lambda r: float(r["price"]))) # the most extreme row

Step 2 · Keep only what is usable第 2 步 · 只留下能用的

Learn先学

Throw away rows with no price, rows with too little text, and prices that are tiny or absurd. Wei Jie kept prices between $1 and $1000, and descriptions with at least a minimum number of characters. A few huge outliers drag a model the wrong way, like one wrong price tag that makes a whole shelf look expensive.

丢掉没有价格的行、文字太少的行，以及太便宜或离谱的价格。Wei Jie 只保留 1 到 1000 美元之间的价格，以及描述至少达到最少字符数的行。几个特别大的离群值会把模型带偏，就像一张标错的价签，让整排货架都显得很贵。

MIN_CHARS = 300 def usable(row): if not row["price"]: return False price = float(row["price"]) text = row["description"] or "" return 1 <= price <= 1000 and len(text) >= MIN_CHARS kept = [r for r in listings if usable(r)] print("kept", len(kept), "of", len(listings))
kept 7120 of 9000

Step 3 · Clean the text into an Item第 3 步 · 把文字清洗成 Item

Learn先学

Put each survivor into a small Item class with one clean summary text and a price. Strip stray symbols and boilerplate lines such as "Manufacturer" or "Date first available". Drop any word with a long run of digits, like a part number: it adds noise, not meaning. Finally cut the text to a fixed length, so every example is about the same size.

把每个幸存的记录放进一个小小的 Item 类：一段干净的 summary 文字加一个 price。去掉乱码符号和“Manufacturer”“Date first available”这类套话。含一长串数字的词（比如零件编号）也删掉：它只带来噪音，没有意义。最后把文字截到固定长度，让每个例子大小差不多。

import re NOISE_LINES = ("Manufacturer", "ASIN", "Date first available") MAX_CHARS = 800 def clean(row): lines = [ln for ln in row["description"].splitlines() if not ln.startswith(NOISE_LINES)] words = [w for w in " ".join(lines).split() if len(re.findall(r"\d", w)) < 5] # drop part numbers return " ".join(words)[:MAX_CHARS] class Item: def __init__(self, row): self.summary = clean(row) self.price = float(row["price"]) items = [Item(r) for r in kept]

Step 4 · Plot, then balance第 4 步 · 画图，再均衡

Learn先学

Plot the text lengths and the prices. Prices are skewed: lots of cheap things and a long tail of expensive ones. If you train on that as it is, the model learns "the answer is about thirty dollars" and is rarely wrong by much, yet never useful. So sample on purpose: keep every expensive item and only part of the huge cheap crowd, so every price range and category is represented.

把文字长度和价格都画出来。价格是偏斜的：便宜的东西很多，昂贵的拖着一条长尾巴。如果原样训练，模型会学到“答案大概是三十块”，很少错得离谱，却毫无用处。所以要有意识地抽样：贵的全留，便宜的庞大人群只留一部分，让每个价格区间和类别都有代表。

import random random.seed(42) cheap = [i for i in items if i.price < 50] dear = [i for i in items if i.price >= 50] balanced = dear + random.sample(cheap, k=min(len(cheap), len(dear))) random.shuffle(balanced)

Step 5 · Split, then save第 5 步 · 切分，然后保存

Learn先学

Split into three sets: a big training set (hundreds of thousands), a validation set (a few thousand) and a test set (about 2,000). Think of Priya's tuition class: practice papers, a mock exam and the real exam. Never peek at the test set until the very end. Then push the finished dataset to the hub so a later notebook or cloud machine loads it in one line. Keep a small "lite" copy for quick runs.

切成三份：很大的训练集（几十万条）、验证集（几千条）和测试集（约 2000 条）。就像 Priya 的补习班：练习卷、模拟考和真正的考试。测试集在最后之前绝不能偷看。然后把整理好的数据集推送到 hub，以后的 notebook 或云端机器一行就能加载。再留一份小的“lite”版本，方便快速跑。

from datasets import Dataset, DatasetDict test = balanced[:2000] valid = balanced[2000:6000] train = balanced[6000:] def to_ds(rows): return Dataset.from_list([{"text": i.summary, "price": i.price} for i in rows]) data = DatasetDict({"train": to_ds(train), "validation": to_ds(valid), "test": to_ds(test)}) data.push_to_hub("your-name/gadget-prices") # needs a hub login lite = DatasetDict({k: v.select(range(min(500, len(v)))) for k, v in data.items()}) lite.push_to_hub("your-name/gadget-prices-lite")
What I got wrong我搞错的地方I spent time on models before I looked at the data. The first plot showed a few absurd prices that I would otherwise have trained on. Now the plot and the most extreme row come first, every time.我没看数据就先花时间去弄模型。第一张图一画，就看到几个离谱的价格，要是没看，我就拿它们去训练了。现在每次都先画图、先看最极端的那一行。

Common errors常见报错

• ValueError: could not convert string to float: ''. Some rows have an empty price. Filter them out before converting.
• DatasetNotFoundError or 401. The dataset id is wrong or private. Check the spelling and log in with huggingface-cli login.
• A model that always guesses cheap. The data is mostly cheap items. Balance the price bands before you split.

• ValueError: could not convert string to float: ''：有些行的价格是空的。转换之前先过滤掉。
• DatasetNotFoundError 或 401：数据集 id 写错或是私有的。检查拼写，并用 huggingface-cli login 登录。
• 模型总是猜低价：数据里大多是便宜的东西。切分之前先把各价格段配平。

Takeaways要点回顾

• Data work comes first and is most of the job.
• Look at one record and the most extreme record before anything else.
• Filter out missing, tiny and absurd prices.
• Clean the text: boilerplate, part numbers, fixed length.
• Plot the target: skewed prices need balancing.
• Split train, validation and test, and never peek at test.
• Push the finished dataset to the hub, with a small lite copy for fast tests.

• 数据工作排在最前，而且是工作的大头。
• 任何事之前，先看一条记录和最极端的那条。
• 过滤掉缺失、过小和离谱的价格。
• 清洗文字：套话、零件编号、固定长度。
• 把目标值画出来：偏斜的价格需要均衡。
• 切成训练、验证、测试，测试集绝不偷看。
• 把成品推送到 hub，再留一份小的 lite 版本做快速测试。

Recap小结

1. Look at the raw data first, then drop rows that are too short or have no price.
2. Clean the text, and balance cheap and expensive items so the model learns both.
3. Split into train, validation and test once, and never peek at the test set.

1. 先看原始数据，再去掉太短或没有价格的行。
2. 清理文字，并让便宜和贵的东西数量均衡，模型两边都学得到。
3. 训练、验证、测试只切一次，永远不要偷看测试集。
