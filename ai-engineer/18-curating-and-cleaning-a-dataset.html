Cleaning a dataset清洗数据集

You will turn a messy pile of listings into a clean, balanced dataset that later lessons can learn from · ~20 min · concept你会把一堆杂乱的商品列表整理成干净、均衡的数据集，供后面的课使用 · 约 20 分钟 · 概念课

Step 1 · Look, then keep only what is usable第 1 步 · 先看，再只留能用的

Learn先学

A model learns only from what you feed it, so look first. The code loads from the Hugging Face hub, a public site that hosts datasets, through its datasets library. The id is a placeholder: use any listings dataset with a title, a description and a price, or type twenty rows by hand as a list of dicts and skip the load line. Print one record, the most extreme record, and how many have a price. Then drop rows with no price, too little text, or a tiny or absurd price. A few outliers drag a model the wrong way.

模型只能从你喂给它的东西里学，所以先看。代码通过 datasets 库从 Hugging Face hub（一个托管数据集的公开网站）加载。那个 id 只是占位：用任何带标题、描述和价格的商品列表数据集都行，也可以手写二十行字典组成的列表，跳过加载那一行。打印一条记录、最极端的一条，以及有多少条有价格。然后丢掉没有价格、文字太少、价格太小或离谱的行。几个离群值会把模型带偏。

from datasets import load_dataset listings = load_dataset("your-name/gadget-listings", split="train") # placeholder: any listings dataset # or by hand: listings = [{"title": "Phone stand", "description": "...", "price": "12.90"}, ...] print(listings[0]) # one record priced = [r for r in listings if r["price"]] # many have no price print(max(priced, key=lambda r: float(r["price"]))) # the most extreme row MIN_CHARS = 300 def usable(row): if not row["price"]: return False price = float(row["price"]) text = row["description"] or "" return 1 <= price <= 1000 and len(text) >= MIN_CHARS kept = [r for r in listings if usable(r)] print("kept", len(kept), "of", len(listings))
{'title': 'Phone stand', 'description': '...', 'price': '12.90'} {'title': 'Pro camera kit', 'price': '1499.00'} kept 7120 of 9000

Step 2 · Clean the text into an Item第 2 步 · 把文字清洗成 Item

Learn先学

Put each survivor into an Item with one clean summary and a price: strip boilerplate lines, drop part-number words (noise, not meaning), and cut to a fixed length.

把每个幸存的记录放进一个 Item：一段干净的 summary 加一个 price。去掉套话行，删掉零件编号词（噪音，没有意义），并截到固定长度。

import re NOISE_LINES = ("Manufacturer", "ASIN", "Date first available") MAX_CHARS = 800 def clean(row): lines = [ln for ln in row["description"].splitlines() if not ln.startswith(NOISE_LINES)] words = [w for w in " ".join(lines).split() if len(re.findall(r"\d", w)) < 5] # drop part numbers return " ".join(words)[:MAX_CHARS] class Item: def __init__(self, row): self.summary = clean(row) self.price = float(row["price"]) items = [Item(r) for r in kept]

Step 3 · Balance the prices第 3 步 · 均衡价格

Learn先学

Prices are skewed: many cheap items, a long tail of dear ones. Train on that as is and the model learns "about thirty dollars", rarely far off and never useful. Sample on purpose: keep every expensive item and only part of the cheap crowd.

价格是偏斜的：便宜的很多，贵的拖着长尾。原样训练，模型会学到“大概三十块”，很少错得远，却毫无用处。有意抽样：贵的全留，便宜的只留一部分。

import random random.seed(42) # Simple version: balance everything. Stricter: split off the test set first and balance only the rest, # so the test set still looks like real listings. cheap = [i for i in items if i.price < 50] dear = [i for i in items if i.price >= 50] balanced = dear + random.sample(cheap, k=min(len(cheap), len(dear))) random.shuffle(balanced)

Step 4 · Split, then save第 4 步 · 切分，然后保存

Learn先学

Split into training (large), validation (a few thousand) and test (about 2,000), like practice papers, a mock exam and the real exam. Never peek at test until the end. Push the dataset to the hub so later notebooks load it in one line, plus a small "lite" copy for quick runs. Pushing needs a free Hugging Face account: create an access token with write permission on the site, then run huggingface-cli login once in a terminal and paste it.

切成训练集（很大）、验证集（几千条）和测试集（约 2000 条），就像练习卷、模拟考和真正的考试。测试集到最后之前绝不偷看。把数据集推送到 hub，以后一行就能加载，再留一份小的“lite”版本方便快速跑。推送需要一个免费的 Hugging Face 账号：在网站上创建一个有写权限的访问令牌，然后在终端运行一次 huggingface-cli login 并粘贴进去。

from datasets import Dataset, DatasetDict test = balanced[:2000] valid = balanced[2000:6000] train = balanced[6000:] def to_ds(rows): return Dataset.from_list([{"text": i.summary, "price": i.price} for i in rows]) data = DatasetDict({"train": to_ds(train), "validation": to_ds(valid), "test": to_ds(test)}) data.push_to_hub("your-name/gadget-prices") # needs a hub login lite = DatasetDict({k: v.select(range(min(500, len(v)))) for k, v in data.items()}) lite.push_to_hub("your-name/gadget-prices-lite")

Now make it yours现在把它变成你的

Takeaways要点回顾

• Data work comes first and is most of the job.
• Look at the most extreme row; filter missing, tiny and absurd prices.
• Clean the text: boilerplate, part numbers, fixed length.
• Balance skewed prices, then split train, validation and test, and never peek at test.

• 数据工作排在最前，而且是工作的大头。
• 看最极端的一行；过滤缺失、过小和离谱的价格。
• 清洗文字：套话、零件编号、固定长度。
• 均衡偏斜的价格，再切成训练、验证、测试，测试集绝不偷看。
