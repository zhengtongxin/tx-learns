Frontier vs local models云端与本地模型

You will ask several models the same question through one helper and see which dials really change the answer · ~15 min · hands-on你会用同一个辅助函数向多个模型问同一个问题，看看哪些旋钮真正会改变答案 · 约 15 分钟 · 动手实践

Step 1 · One helper, many providers第 1 步 · 一个函数，多家服务商

Learn先学

Most providers copy one chat format, and a local server such as Ollama offers it too. So keep one helper and swap three things: base URL, key and model name.

大多数服务商照搬同一种聊天格式，Ollama 这样的本地服务也提供它。所以只留一个辅助函数，只换三样：base URL、密钥和模型名。

import os from openai import OpenAI KEY_B = os.getenv("PROVIDER_B_API_KEY") # the second provider's key, kept in .env clients = { "cloud-a": OpenAI(), # reads OPENAI_API_KEY from the environment (your .env file) "cloud-b": OpenAI(base_url="https://<provider>/v1/", api_key=KEY_B), # optional second provider: put its address in place of <provider>, or delete this line "local": OpenAI(base_url="http://localhost:11434/v1", api_key="ollama"), } def ask(which, model, prompt, **extra): reply = clients[which].chat.completions.create( model=model, messages=[{"role": "user", "content": prompt}], **extra) return reply.choices[0].message.content

Step 2 · Easy prompts tell you nothing第 2 步 · 简单的题看不出差别

Learn先学

Two providers both tell a fine joke. A good test is a hard prompt with a trap: “Two coins are flipped. At least one is heads. What is the chance the other is tails?” The tempting answer is 1/2. Listing the pairs (HH, HT, TH; TT is ruled out) gives 2/3. (The local entry needs Ollama from Step 4; until then run only the cloud one.)

两家服务商都能讲个像样的笑话。好的测试是带陷阱的难题：“抛两枚硬币，至少有一枚是正面，另一枚是反面的概率是多少？”诱人的答案是 1/2；把组合列出来（正正、正反、反正；反反被排除）答案是 2/3。（local 一项需要第 4 步的 Ollama，在那之前只运行云端那一项。）

question = "Two coins are flipped. At least one is heads. What is the chance the other is tails? Explain briefly." for which, model in [("cloud-a", "gpt-5-mini"), ("local", "llama3.2")]: print(which, "->", ask(which, model, question)) # a small model can slip here

Which kind of prompt shows the difference between models?

哪种提示词能看出模型之间的差别？

Step 3 · Two dials: size and thinking第 3 步 · 两个旋钮：大小与思考

Learn先学

A small model with no thinking gets the puzzle wrong; a low reasoning effort often fixes it. So there are two dials: a bigger model (scale at training time) and more thinking before answering (scale at answer time). The second is cheap to try, but costs more tokens and time.

没有思考的小模型会答错；调到低档的推理力度往往就改对了。所以有两个旋钮：更大的模型（训练时的规模）和回答前多想一会儿（回答时的规模）。第二个试起来便宜，但要多花 token 和时间。

import time for effort in ["minimal", "low", "high"]: start = time.time() answer = ask("cloud-a", "gpt-5-mini", question, reasoning_effort=effort) print(effort, round(time.time() - start, 1), "s,", len(answer), "chars")

Step 4 · Going local, honestly第 4 步 · 诚实地看待本地模型

Learn先学

Run ollama pull llama3.2, then point the client at localhost (the local entry above). Local is free per call and private, because text never leaves your laptop, but usually weaker. Never pull a model bigger than your laptop's memory: B means billions of parameters, so use 1B to 3B on a small laptop.

运行 ollama pull llama3.2，再让客户端指向 localhost（上面的 local 那一项）。本地每次调用免费，而且私密（文字不离开电脑），但通常更弱。别拉取比笔记本内存还大的模型：B 是十亿参数，小笔记本用 1B 到 3B 的。

For each case, is a local model a good fit?

每种情况，本地模型合适吗？

Common errors常见报错

• APIConnectionError on the local client. Ollama is not running: start it with ollama serve.
• model 'llama3.2' not found. Run ollama pull llama3.2 once.

• 本地客户端报 APIConnectionError：Ollama 没运行，用 ollama serve 启动。
• model 'llama3.2' not found：运行一次 ollama pull llama3.2。

Now make it yours现在把它变成你的

Takeaways要点回顾

• One helper, many providers: swap only base URL, key and model name.
• Easy prompts hide differences; use a hard prompt with a trap.
• Two dials: a bigger model, or more thinking before the answer.
• Thinking costs tokens and time; cost and speed matter as much as the answer.
• Local is free per call and private, but usually weaker.

• 一个辅助函数，多家服务商：只换 base URL、密钥和模型名。
• 简单的题看不出差别，要用带陷阱的难题。
• 两个旋钮：更大的模型，或回答前更多的思考。
• 多想要花 token 和时间；成本和速度与答案同样重要。
• 本地模型每次调用免费又私密，但通常更弱。
