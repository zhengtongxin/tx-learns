Step 1 · Name the job, get a tool第 1 步 · 说出任务名，拿到工具

Learn先学

Hugging Face is the hub for open models (anyone can download and run them). Its transformers library has a high level, pipeline("task"): say the job, get a ready tool. Like ordering “chicken rice” at a hawker stall without explaining how to cook it. The low level (tokenizer plus model) comes next lesson.

Hugging Face 是开源模型的聚集地（任何人都能下载并运行）。它的 transformers 库有个高层接口 pipeline("任务名")：说出任务，拿到现成工具。就像在小贩摊点“鸡饭”，不用解释怎么煮。低层（分词器加模型）下一课再讲。

from transformers import pipeline feel = pipeline("sentiment-analysis") print(feel("The teacher explains slowly and my son finally gets fractions")) # [{'label': 'POSITIVE', 'score': 0.99...}]

Step 2 · One job per pipeline第 2 步 · 一个任务一条 pipeline

Learn先学

Each task name gives a different tool: summarising, translating, question answering, pulling out names, or sorting text into labels you invent. zero-shot-classification needs no training data: you make up the labels. The output shape changes with the task, so print it first.

每个任务名对应不同的工具：摘要、翻译、问答、抽取人名地名，或把文字分到你自己定的标签里。zero-shot-classification 不需要训练数据：标签自己编。输出形状随任务而变，所以先打印出来看。

from transformers import pipeline sorter = pipeline("zero-shot-classification") slip = "Please tell me when the next term payment is due." result = sorter(slip, candidate_labels=["praise", "complaint", "fees"]) print(result["labels"][0], result["scores"][0]) # fees 0.87

Step 3 · Where it runs, and why bother第 3 步 · 在哪里运行，以及为什么要自己跑

Learn先学

The first call downloads a default model (maybe gigabytes), then it is cached. A big model crawls on a CPU: switch the runtime to a GPU and pass device="cuda". Why not just use an API?
• No per-call bill, and the data stays with you.
• A small model for one narrow job is often cheaper and faster.
• The price: you own the GPU, downloads and library versions.

第一次调用会下载默认模型（可能好几个 GB），之后有缓存。CPU 跑大模型很慢：把运行环境切到 GPU，并传 device="cuda"。为什么不直接用 API？
• 没有按次计费，数据留在你手里。
• 专做一个窄任务的小模型，往往更便宜更快。
• 代价：GPU、下载和库版本都归你管。

from transformers import pipeline long_letter = open("parent_letter.txt").read() shorten = pipeline("summarization", device="cuda") # or pick the model yourself: # shorten = pipeline("summarization", model="some-org/some-summary-model", device="cuda") print(shorten(long_letter, max_length=60)[0]["summary_text"])

Common errors常见报错

• ValueError about cuda, or no GPU found. Remove device="cuda" to run on the CPU: slower but works.
• Token indices sequence length is longer than the specified maximum. Split the text and summarise each part.

• ValueError 提示 cuda，或没有显卡：去掉 device="cuda"，在 CPU 上运行，慢一点但能用。
• Token indices sequence length is longer than the specified maximum：把文本切成几段，各自总结。
