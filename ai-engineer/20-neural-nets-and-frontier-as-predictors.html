Step 2 · A vanilla neural network第 2 步 · 朴素的神经网络

Learn先学

First turn each description into a long vector of 5,000 hashed word counts: each word is hashed to a slot number, so there is no vocabulary list to store. A small PyTorch network is a few linear layers with activation functions between them. Training repeats four moves: forward, loss, backward, step. Print the parameter count once, and each epoch check the loss on items the network never trains on (the validation loss). It did about as well as the best classical model: neural nets are not magic on small features.

先把每段描述变成 5000 维的哈希词频向量：每个词被哈希到一个槽位，所以不用存词表。小小的 PyTorch 网络就是几层线性层，中间夹着激活函数。训练不断重复四步：前向、算损失、反向、更新。参数量打印一次就行，每个 epoch 再看一下网络没训练过的那些例子上的损失（验证集损失）。它的表现和最好的传统模型差不多：特征不多时，神经网络并不神奇。

import torch, torch.nn as nn from sklearn.feature_extraction.text import HashingVectorizer hasher = HashingVectorizer(n_features=5000) class PriceNet(nn.Module): def __init__(self): super().__init__() self.layers = nn.Sequential( nn.Linear(5000, 128), nn.ReLU(), nn.Linear(128, 32), nn.ReLU(), nn.Linear(32, 1)) def forward(self, x): return self.layers(x).squeeze(-1) net = PriceNet() print(sum(p.numel() for p in net.parameters()), "parameters") opt = torch.optim.Adam(net.parameters(), lr=1e-3) for x, y in batches: # x: word counts, y: true prices loss = nn.functional.l1_loss(net(x), y) opt.zero_grad() loss.backward() opt.step()

Step 3 · A frontier model, no training第 3 步 · 不训练的云端大模型

Learn先学

Now skip training entirely: ask a big model "Estimate the price of this product. Reply with the price only", plus the description. It is surprisingly strong, because it has seen the world's prices during its own training. The catch is a cost on every call, and a smaller model is usually weaker. Models add words anyway, so pull the number out with a regex. If no number is found this first version returns 0.0, which quietly hurts the score: the next lesson fixes it.

现在完全不训练：问大模型“估一下这件商品的价格，只回答价格”，再附上描述。它出奇地强，因为它自己的训练中见过世界各地的价格。代价是每次调用都要花钱，而小一点的模型通常更弱。模型总爱多说话，所以用正则把数字抠出来。如果找不到数字，第一版会返回 0.0，这会悄悄拉低分数：下一课会修好它。

import re from openai import OpenAI client = OpenAI() def frontier_pricer(item, model="your-big-model"): reply = client.chat.completions.create(model=model, messages=[ {"role": "user", "content": "Estimate the price of this product. Reply with the price only.\n\n" + item.summary}]) match = re.search(r"\d[\d,]*\.?\d*", reply.choices[0].message.content) return float(match.group().replace(",", "")) if match else 0.0

Step 4 · Get examples ready for fine-tuning第 4 步 · 为微调准备样例

Learn先学

Fine-tuning means training a model a little more on your own examples. For a hosted model it takes examples in JSON Lines: one chat per line, with a user message (the item) and an assistant message (the price, rounded to a whole number to save tokens, the small text pieces models read and bill by). Providers suggest starting with 50 to 100 examples. Wei Jie used 100 for one epoch (one pass over the examples), so the bill stayed tiny, plus a small validation file. Upload the files, start a job, wait, then plug the tuned model's name into the same predictor and the same evaluate.

微调就是用你自己的例子把模型再训练一点。托管模型的微调需要 JSON Lines 格式的样例：每行一段对话，包含 user 消息（商品）和 assistant 消息（价格，取整数以省 token，即模型读取和计费的文字小片段）。服务商建议从 50 到 100 条开始。Wei Jie 用了 100 条、跑一个 epoch（把样例过一遍），账单才会很小，另外再配一个小的验证文件。上传文件、开始任务、等待，然后把微调后的模型名字接进同一个预测函数和同一个 evaluate。

The real benefit shows with more data and a cheaper base model: lower cost and more consistent answers.我原以为微调后的模型会明显赢过直接用的大模型。底子强的模型只配 100 条样例，变化很小。真正的好处要在更多数据、更便宜的底座模型上才看得出：成本更低、答案更稳定。

Common errors常见报错

• KeyError: 'id' when reading your guesses. The CSV header differs from the code. Make the header exactly id,guess.
• The loss becomes nan. The learning rate is too high or the prices were not scaled. Lower the rate and scale the target.
• The frontier model replies with words, so float() fails. Ask for the number only and pull it out with a regular expression.

• 读自己的估价时报 KeyError: 'id'：CSV 的表头和代码不一致。把表头写成 id,guess。
• 损失变成 nan：学习率太高，或价格没做缩放。调低学习率并缩放目标值。
• 大模型回了一段话，float() 失败：要求只回数字，再用正则取出来。

Takeaways要点回顾

• Same harness, many predictors: human, classic ML, neural net, prompted model, fine-tuned model.
• A human is worse than a decent model but better than random.
• Hashed word counts give a vector with no vocabulary to store.
• A neural net trains by forward, loss, backward, step, and is no magic on small features.
• A frontier model can predict with no training, but costs money per call.
• Ask for the number only, then parse it with a regex.
• Fine-tuning data is JSON Lines with the price as the assistant reply; gains are small with few examples.

• 同一块计分板，很多预测器：人、传统机器学习、神经网络、提示词大模型、微调模型。
• 人比像样的模型差，但比随机猜好。
• 哈希词频得到的向量，不用存词表。
• 神经网络靠“前向、损失、反向、更新”训练，特征不多时并不神奇。
• 大模型不用训练就能预测，但每次调用都要花钱。
• 让它只回答数字，再用正则解析。
• 微调数据是 JSON Lines，价格放在 assistant 回复里；样例少时提升很小。

Recap小结

1. Your own guesses give a human score to compare with.
2. A small neural net learns from numbers; a big model uses what it already knows.
3. Fine-tuning data is just examples of the question and the right answer.

1. 你自己的估价能给出一个“人”的分数来做对照。
2. 小神经网络从数字里学；大模型用它本来就知道的。
3. 微调数据其实就是问题加正确答案的例子。
