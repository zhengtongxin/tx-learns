Predicting with data · Lesson 3用数据做预测 · 第 3 课

Neural nets as predictors神经网络预测器

You will plug a human, a small neural network and a big model into the same scoring harness and compare them fairly · ~25 min · concept你会把人、小神经网络和大模型接进同一块计分板，公平地比较 · 约 25 分钟 · 概念课

Step 1 · A human baseline第 1 步 · 人类基线

Learn先学

Everything here is scored by one harness: evaluate(pricer, items) calls your function on each item and prints the average error: how many dollars a guess is off, on average ($58 means guesses miss the real price by $58 either way). train and test are lists of items, each with a summary (the description) and a price; the test items are never used for training. Guess the first 100 test prices yourself, one per line in a text file, and score them. Score every other predictor on the same 100 items, so the comparison is fair. A human beats random but trails a decent model.

这里所有预测都用同一套评分工具打分：evaluate(pricer, items) 对每件商品调用你的函数，再打印平均误差：猜测平均差了多少美元（58 美元表示猜的价格平均比真实价格高或低 58 美元）。train 和 test 是商品列表，每件有 summary（描述）和 price（价格）；测试商品从不用于训练。把前 100 条测试商品的价格自己猜一遍，每行一个写进文本文件，再打分。其他预测方法也在这 100 条上打分，比较才公平。人比随机猜好，但不如像样的模型。

sample = test[:100] for n, item in enumerate(sample, 1): # read each one, write your guess on line n print(n, item.summary[:200]) guesses = [float(line) for line in open("my_guesses.txt")] # 100 lines, same order mine = {id(item): g for item, g in zip(sample, guesses)} def human_pricer(item): return mine[id(item)] evaluate(human_pricer, sample)
average error: $58.00 over 100 items

Step 2 · A vanilla neural network第 2 步 · 朴素的神经网络

Learn先学

Turn each description into 5,000 hashed word counts (each word hashed to a slot, so no vocabulary to store). PyTorch (torch) is the library; a tensor is its grid of numbers. A small network is a few linear layers (each multiplies its inputs by weights and adds them up) with an activation between them (ReLU turns negatives into zero, which lets the network learn more than straight lines). Training repeats four moves on each batch of 32 items: forward (net(x) guesses), loss (how far off, in dollars), backward (works out which way to nudge every weight) and step (the optimiser, here Adam, nudges them). On small features it does about as well as the best classical model: no magic.

把每段描述变成 5000 个哈希词频（每个词哈希到一个槽位，不用存词表）。PyTorch（torch）是所用的库；张量（tensor）是它的数字网格。小网络就是几层线性层（每层把输入乘上权重再相加），中间夹着激活函数（ReLU 把负数变成零，网络才学得了直线以外的东西）。训练对每批 32 件商品重复四步：前向（net(x) 给出猜测）、算损失（差了多少美元）、反向（算出每个权重该往哪边调）、更新（优化器，这里是 Adam，去调它们）。特征不多时，它和最好的传统模型差不多：并不神奇。

import torch, torch.nn as nn from sklearn.feature_extraction.text import HashingVectorizer hasher = HashingVectorizer(n_features=5000) class PriceNet(nn.Module): def __init__(self): super().__init__() self.layers = nn.Sequential( nn.Linear(5000, 128), nn.ReLU(), nn.Linear(128, 32), nn.ReLU(), nn.Linear(32, 1)) def forward(self, x): return self.layers(x).squeeze(-1) net = PriceNet() opt = torch.optim.Adam(net.parameters(), lr=1e-3) small = train[:5000] # enough to see it learn, and it fits in memory X = torch.tensor(hasher.transform([i.summary for i in small]).toarray(), dtype=torch.float32) Y = torch.tensor([i.price for i in small], dtype=torch.float32) batches = [(X[i:i+32], Y[i:i+32]) for i in range(0, len(X), 32)] for x, y in batches: # x: word counts, y: true prices loss = nn.functional.l1_loss(net(x), y) opt.zero_grad() loss.backward() opt.step() # lr=1e-3 above is the size of each nudge # zero_grad() clears the last batch's nudges before the new ones def net_pricer(item): # wrap the trained net like every other guesser x = torch.tensor(hasher.transform([item.summary]).toarray(), dtype=torch.float32) return float(net(x)[0]) evaluate(net_pricer, test[:100])

Step 3 · A frontier model, no training第 3 步 · 不训练的云端大模型

Learn先学

Skip training: ask a big model for the price, with the description. It is strong because it has seen the world's prices, but every call costs money. Models add words, so pull the number out with a regex, a search pattern for text: this one finds the first run of digits, with optional commas and a decimal point, and match.group() is the text it found.

不训练：把描述给大模型，让它估价。它很强，因为见过世界各地的价格，但每次调用都要花钱。模型总爱多说话，所以用正则表达式（一种文本搜索模式）把数字抠出来：这个模式找到第一串数字，可以带逗号和小数点，match.group() 就是它找到的那段文字。

import re from openai import OpenAI client = OpenAI() def frontier_pricer(item, model="your-big-model"): # replace with a current model name from your provider's model list reply = client.chat.completions.create(model=model, messages=[ {"role": "user", "content": "Estimate the price of this product. Reply with the price only.\n\n" + item.summary}]) match = re.search(r"\d[\d,]*\.?\d*", reply.choices[0].message.content) return float(match.group().replace(",", "")) if match else 0.0 # 0.0 quietly hurts the score

Step 4 · Examples for fine-tuning第 4 步 · 为微调准备样例

Learn先学

Fine-tuning trains a hosted model a little more on your examples: JSON Lines, one chat per line, a user message (the item) and an assistant message (the price, rounded to save tokens). Start with 50 to 100 examples. Then plug the tuned model into the same predictor and the same evaluate.

微调是用你的例子把托管模型再训练一点：JSON Lines 格式，每行一段对话，包含 user 消息（商品）和 assistant 消息（价格，取整以省 token）。从 50 到 100 条开始。然后把微调后的模型接进同一个预测函数和同一个 evaluate。

import json def to_line(item): return json.dumps({"messages": [ {"role": "user", "content": "Estimate the price: " + item.summary}, {"role": "assistant", "content": f"{round(item.price)}"}]}) with open("tune_train.jsonl", "w") as f: for item in train[:100]: # then upload this file on your provider's fine-tuning page and start a job; # when it finishes you get the tuned model's name: pass it as model= above f.write(to_line(item) + "\n")
What I got wrong我搞错的地方I expected a fine-tuned model to clearly beat a strong plain one. With 100 examples the change is small; the gain comes with more data and a cheaper base model.我原以为微调后的模型会明显赢过强的原模型。只有 100 条样例时变化很小；好处要在更多数据、更便宜的底座模型上才有。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Same harness, many predictors: human, neural net, prompted model, fine-tuned model.
• A neural net trains by forward, loss, backward, step, and is no magic on small features.
• A frontier model predicts with no training, but costs money per call; ask for the number only and parse it.
• Fine-tuning data is JSON Lines with the price as the assistant reply.

• 同一块计分板，很多预测器：人、神经网络、提示词大模型、微调模型。
• 神经网络靠“前向、损失、反向、更新”训练，特征不多时并不神奇。
• 大模型不用训练就能预测，但每次调用都要花钱；让它只回答数字再解析。
• 微调数据是 JSON Lines，价格放在 assistant 回复里。
