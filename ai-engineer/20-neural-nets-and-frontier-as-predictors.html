Step 2 · A vanilla neural network第 2 步 · 朴素的神经网络

Learn先学

Turn each description into 5,000 hashed word counts (each word hashed to a slot, so no vocabulary to store). A small PyTorch network is a few linear layers with activations between them. Training repeats four moves: forward, loss, backward, step. On small features it does about as well as the best classical model: no magic.

把每段描述变成 5000 个哈希词频（每个词哈希到一个槽位，不用存词表）。小小的 PyTorch 网络就是几层线性层，中间夹着激活函数。训练不断重复四步：前向、算损失、反向、更新。特征不多时，它和最好的传统模型差不多：并不神奇。

import torch, torch.nn as nn from sklearn.feature_extraction.text import HashingVectorizer hasher = HashingVectorizer(n_features=5000) class PriceNet(nn.Module): def __init__(self): super().__init__() self.layers = nn.Sequential( nn.Linear(5000, 128), nn.ReLU(), nn.Linear(128, 32), nn.ReLU(), nn.Linear(32, 1)) def forward(self, x): return self.layers(x).squeeze(-1) net = PriceNet() opt = torch.optim.Adam(net.parameters(), lr=1e-3) for x, y in batches: # x: word counts, y: true prices loss = nn.functional.l1_loss(net(x), y) opt.zero_grad() loss.backward() opt.step()

Step 3 · A frontier model, no training第 3 步 · 不训练的云端大模型

Learn先学

Skip training: ask a big model for the price, with the description. It is strong because it has seen the world's prices, but every call costs money. Models add words, so pull the number out with a regex.

不训练：把描述给大模型，让它估价。它很强，因为见过世界各地的价格，但每次调用都要花钱。模型总爱多说话，所以用正则把数字抠出来。

import re from openai import OpenAI client = OpenAI() def frontier_pricer(item, model="your-big-model"): reply = client.chat.completions.create(model=model, messages=[ {"role": "user", "content": "Estimate the price of this product. Reply with the price only.\n\n" + item.summary}]) match = re.search(r"\d[\d,]*\.?\d*", reply.choices[0].message.content) return float(match.group().replace(",", "")) if match else 0.0 # 0.0 quietly hurts the score

Step 4 · Examples for fine-tuning第 4 步 · 为微调准备样例

Learn先学

Fine-tuning trains a hosted model a little more on your examples: JSON Lines, one chat per line, a user message (the item) and an assistant message (the price, rounded to save tokens). Start with 50 to 100 examples. Then plug the tuned model into the same predictor and the same evaluate.

微调是用你的例子把托管模型再训练一点：JSON Lines 格式，每行一段对话，包含 user 消息（商品）和 assistant 消息（价格，取整以省 token）。从 50 到 100 条开始。然后把微调后的模型接进同一个预测函数和同一个 evaluate。

Takeaways要点回顾

• Same harness, many predictors: human, neural net, prompted model, fine-tuned model.
• A neural net trains by forward, loss, backward, step, and is no magic on small features.
• A frontier model predicts with no training, but costs money per call; ask for the number only and parse it.
• Fine-tuning data is JSON Lines with the price as the assistant reply.

• 同一块计分板，很多预测器：人、神经网络、提示词大模型、微调模型。
• 神经网络靠“前向、损失、反向、更新”训练，特征不多时并不神奇。
• 大模型不用训练就能预测，但每次调用都要花钱；让它只回答数字再解析。
• 微调数据是 JSON Lines，价格放在 assistant 回复里。
