End-to-end retrieval chain端到端检索链

You will connect the store to a model and get a chatbot that answers from your files in about ten lines · ~15 min · concept你会把向量库接到模型上，用大约十行代码得到一个照着你的文件回答的聊天机器人 · 约 15 分钟 · 概念课

Step 1 · Retriever and prompt第 1 步 · 检索器和提示词

Learn先学

A retriever wraps the store and returns the top few chunks for a question. The prompt then has two jobs:

检索器包在向量库外面，针对一个问题返回最靠前的几块。提示词有两个任务：

  • hold a slot for those chunks;
  • carry one rule: answer from the context, or say "I do not know". Without it, the model guesses.
  • 留一个位置放这些块；
  • 带上一条规则：照内容回答，没有就说“我不知道”。没有它，模型就会瞎猜。

Set temperature to 0 for facts: the model then always picks the most likely word.

回答事实时把 temperature 设成 0：模型每次都选最可能的词。

from langchain_chroma import Chroma from langchain_huggingface import HuggingFaceEmbeddings from langchain_openai import ChatOpenAI embedder = HuggingFaceEmbeddings(model_name="sentence-transformers/all-MiniLM-L6-v2") # same one as when building store = Chroma(persist_directory="council_db", embedding_function=embedder) retriever = store.as_retriever(search_kwargs={"k": 4}) # top 4 chunks TEMPLATE = """You help residents with questions about the town council. Answer using only the context below. If the answer is not in the context, say you do not know. Context: {context}""" llm = ChatOpenAI(model="gpt-4.1-mini", temperature=0)

Step 2 · The chain第 2 步 · 整条链

Learn先学

Search, paste, answer: retrieve for the question, paste the chunks into the template, add the history and the new question, call the model. Retrievers and models both use .invoke(), so they snap together.

搜索、粘贴、回答：针对问题检索，把块贴进模板，加上聊天记录和新问题，再调用模型。检索器和模型都用 .invoke()，所以很好拼接。

# pip install gradio: makes a chat page; open the link it prints import gradio as gr def answer(question, history): chunks = retriever.invoke(question) context = "\n\n".join(c.page_content for c in chunks) messages = [("system", TEMPLATE.format(context=context))] messages += [(m["role"], m["content"]) for m in history] messages.append(("user", question)) return llm.invoke(messages).content gr.ChatInterface(answer, type="messages").launch()

Which piece does each job in the chain?

链里每个零件各负责什么？

Step 3 · Where it breaks: follow-ups第 3 步 · 坏在哪：追问

Learn先学

Search sees only the latest question. "Who is the lift officer?" works. "And what about his manager?" does not: "his" means nothing to the store. History helps the model, not the search. The fix is rewriting the question before searching.

搜索只看最新的问题。“电梯负责人是谁？”没问题；“那他的上司呢？”就不行：“他”对向量库毫无意义。聊天记录能帮到模型，帮不到搜索。解法是搜索前先改写问题。

Common errors常见报错Embedding dimension 1536 does not match collection dimensionality 384: the store and the query used different embedders. Use one for both, or rebuild the store. "I do not know" for a question the files answer: print the chunks, then raise k or fix the chunking.Embedding dimension 1536 does not match collection dimensionality 384：建库和查询用了不同的嵌入模型。两边用同一个，或重建库。文件里有答案却说“不知道”：先打印片段，再调大 k 或改切块。

Now make it yours现在把它变成你的

Takeaways要点回顾

• A retrieval chain is a retriever, a prompt and a model: search, paste, answer.
• The prompt must say: answer from the context, otherwise say you do not know.
• Use temperature 0 for facts.
• Follow-ups are the weak spot, because search sees only the latest question.

• 检索链就是检索器、提示词和模型：搜索、粘贴、回答。
• 提示词必须写明：照内容回答，没有就说不知道。
• 回答事实时用 temperature 0。
• 追问是弱点，因为搜索只看最新的问题。
