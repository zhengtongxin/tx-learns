Price guesser价格估算器

You will build a screen that guesses a gadget's price and shows how good each guesser is, in accuracy, cost and speed · ~30 min · hands-on你会做出一个估价界面，并展示每个预测器在准确度、成本和速度上的表现 · 约 30 分钟 · 动手实践

Step 1 · One board with a hit rate第 1 步 · 带命中率的计分板

Learn先学

You need rows with a text and a price, split into train and test. A small set keeps each run to seconds. The box loads one from the Hugging Face hub; the project package below needs no account: python make_data.py writes invented listings to data/train.jsonl and data/test.jsonl, and its price_guesser.py holds all four boxes of this lesson in one file. evaluate is the scoring board: average error in dollars, plus the share of guesses within a tolerance ($40 or 20% of the real price). Every guesser is a function from text to a price.

你需要带 text 和 price 的数据行，分成训练集和测试集。数据小一点，每次运行只要几秒。代码框从 Hugging Face hub 加载一份；下面的项目包不需要账号：python make_data.py 会把虚构的商品写进 data/train.jsonl 和 data/test.jsonl，它的 price_guesser.py 把本课四个代码框合在一个文件里。evaluate 是计分板：平均误差（美元），加上落在容忍范围内（40 美元或真实价格的 20%）的猜测占比。每个预测器都是“文本进、价格出”的函数。

from datasets import load_dataset lite = load_dataset("your-name/gadget-prices-lite") # placeholder id: any set with text and price train, test = lite["train"], lite["test"] def evaluate(pricer_fn, rows, tol_dollars=40, tol_pct=0.2): errors, hits = [], 0 for row in rows: guess = pricer_fn(row["text"]) err = abs(guess - row["price"]) errors.append(err) if err <= tol_dollars or err <= tol_pct * row["price"]: hits += 1 return {"avg_error": sum(errors) / len(errors), "hit_rate": hits / len(errors)}

Step 2 · Classic and frontier guessers第 2 步 · 传统和大模型预测器

Learn先学

Build three classic guessers as plain-text functions: the training average (the bar to beat), word counts with linear regression, and word counts with a random forest (many small decision trees that vote). Then add the frontier model, a big hosted one. Models do not always obey "number only": you may get "About $120 maybe". Parse defensively: count failed parses and fall back to the average, instead of silently scoring zero.

把三个传统预测器写成纯文本函数：训练集平均价（要超过的底线）、词频加线性回归、词频加随机森林（许多小决策树一起投票）。再加上云端大模型。模型并不总听“只回答数字”：你可能收到“About $120 maybe”。要防御式解析：数一数解析失败的次数并用平均价兜底，而不是悄悄记成零。

Step 3 · One table, three numbers第 3 步 · 一张表，三个数字

Learn先学

Put every guesser in one table: average error, cost per 1,000 guesses, seconds per guess. If you later fine-tune a model of your own, it is one more row in the same table. The cheapest acceptable winner is often a classic model; the most accurate is often the frontier or tuned model. That trade-off is the lesson.

把所有预测器放进一张表：平均误差、每 1000 次猜测的成本、每次猜测的秒数。以后你要是微调了自己的模型，它也只是同一张表里多出的一行。最便宜的“够用”赢家通常是传统模型，最准的通常是大模型或微调模型。这种取舍就是这一课。

import time def row_for(name, fn, cost_per_1000): start = time.time() result = evaluate(fn, test) secs = (time.time() - start) / len(test) return {"name": name, **result, "cost_per_1000": cost_per_1000, "sec_per_guess": round(secs, 3)} table = [row_for("average", average_pricer, 0.0), row_for("linear", linear_pricer, 0.0), row_for("forest", forest_pricer, 0.0), row_for("frontier", frontier_pricer, 1.5)] # use your own price list print("unreadable replies:", unparsed)

Step 4 · A small screen where they disagree第 4 步 · 一个让它们“吵起来”的小界面

Learn先学

Wrap the guessers in a screen made with Gradio, a Python library that turns a function into a small web page: text in, estimate out, the others' answers beside it, and a warning when they spread far apart. Disagreement is a sign to check by hand.

用 Gradio 用 Gradio（一个把函数变成小网页的 Python 库）把预测器包成一个界面：输入文字，输出估价，旁边列出其他预测器的答案，分歧很大时给出警告。分歧大就是该人工看看的信号。

import gradio as gr GUESSERS = {"average": average_pricer, "linear": linear_pricer, "forest": forest_pricer, "frontier": frontier_pricer} def guess_all(text): answers = {name: round(fn(text)) for name, fn in GUESSERS.items()} spread = max(answers.values()) - min(answers.values()) warning = "They disagree: check by hand" if spread > 50 else "They roughly agree" return answers["frontier"], answers, warning # main answer, everyone's, then the flag gr.Interface(fn=guess_all, inputs=gr.Textbox(label="Describe the gadget"), outputs=[gr.Number(label="Estimated price"), gr.JSON(label="All guessers"), gr.Textbox(label="Trust")]).launch()

Common errors常见报错ValueError: could not convert string to float: ask for the number only, keep the regex, count misses. A great hit rate with a bad average error hides large misses: report both.ValueError: could not convert string to float：要求只回数字，保留正则，统计取不到的次数。命中率很好但平均误差很差，说明大的失误被掩盖了：两个数字都要报告。

Takeaways要点回顾

• Report accuracy, cost and speed together, on the same test set.
• Parse model replies defensively, with a fallback and a failure count.
• Classic models are often the cheapest acceptable winner; frontier and tuned models are often the most accurate, at a cost.
• Disagreement between guessers is a useful warning.

• 准确度、成本和速度要放在一起报告，并用同一个测试集。
• 防御式解析模型回复：有备用值，也数失败次数。
• 传统模型常常是最便宜的“够用”赢家；大模型和微调模型常常最准，但要花钱。
• 预测器之间的分歧是有用的警告。
