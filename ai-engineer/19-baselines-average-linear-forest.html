Predicting with data · Lesson 2用数据做预测 · 第 2 课

Baselines: average, linear, forest基线：平均值、线性、随机森林

You will learn to measure how bad a silly guesser is, so you can tell whether a clever one really helps · ~20 min · concept你会学会先量出“笨办法”有多差，才能判断聪明的办法是不是真的有用 · 约 20 分钟 · 概念课

The story故事

Wei Jie now has a clean set of gadget descriptions and prices from Ah Boy. He is itching to try a fancy model. Ah Boy stops him: "If a trick cannot beat saying the usual price every time, it is not helping." So Wei Jie builds a fair scoring board first, then climbs from the silliest guesser upwards.

Wei Jie 现在有了 Ah Boy 给的、干净的数码产品描述和价格。他迫不及待想试花哨的模型。Ah Boy 拦住他：“如果一个招数赢不过每次都报‘平常价’，那它根本没用。”于是 Wei Jie 先搭一块公平的计分板，再从最笨的猜法一路往上爬。

Step 1 · One scoring board for everyone第 1 步 · 人人共用一块计分板

Learn先学

Write one function, evaluate(pricer_fn, test_items). It runs every test item through a predictor, then works out the error in dollars for each and the average error. It can also draw a scatter plot of guess against truth, where the line y = x is a perfect score. Every predictor is just a function from an item to a number, so any of them plugs in. It is like Priya marking every student with the same answer sheet.

写一个函数 evaluate(pricer_fn, test_items)。它让每个测试项都过一遍预测器，算出每个的美元误差和平均误差，还可以画“猜测对真实”的散点图，y = x 那条线就是满分。每个预测器都只是“从一个 item 到一个数字”的函数，所以谁都能接上。就像 Priya 用同一份答案纸批改每个学生。

def evaluate(pricer_fn, test_items): errors = [] for item in test_items: guess = pricer_fn(item) errors.append(abs(guess - item.price)) avg = sum(errors) / len(errors) print(f"average error: ${avg:.2f} over {len(errors)} items") return avg

Step 2 · The floor and the bar第 2 步 · 底线与门槛

Learn先学

First guesser: a random price between 1 and 1000. It is terrible, and that is useful, because it is the floor. Second guesser: always say the average price of the training items. That is the bar. Anything fancier must beat "just say the average", or it is not worth running.

第一个猜法：在 1 到 1000 之间随便报个价。它糟透了，但这有用，因为它就是底线。第二个猜法：永远报训练集的平均价。这是门槛。任何更花哨的办法都得赢过“直接报平均价”，否则不值得跑。

import random def random_pricer(item): return random.randint(1, 1000) average = sum(i.price for i in train) / len(train) def constant_pricer(item): return average evaluate(random_pricer, test) evaluate(constant_pricer, test)

Step 3 · Numbers vs words第 3 步 · 数字对比文字

Learn先学

Linear regression draws the best straight-line rule from inputs to a price. Give it a few hand-made numbers (weight, a "weight unknown" flag, text length) and it barely improves, because the price information is not in those numbers. Give it word counts instead: count the 1,000 to 2,000 most frequent words, ignoring boring "stop words" like "the". Now "stainless" or "professional" carry signal, and the error drops a lot.

线性回归会画出从输入到价格的最佳直线规则。只给它几个手工做的数字（重量、“重量未知”标记、文字长度），几乎没有改进，因为价格的信息不在这些数字里。改成给它词频：统计最常见的 1000 到 2000 个词，忽略“the”这类无聊的停用词。这样“stainless”“professional”这类词就带上了信号，误差大幅下降。

from sklearn.feature_extraction.text import CountVectorizer from sklearn.linear_model import LinearRegression counter = CountVectorizer(max_features=1500, stop_words="english") X_train = counter.fit_transform([i.summary for i in train]) model = LinearRegression().fit(X_train, [i.price for i in train]) def words_linear_pricer(item): return float(model.predict(counter.transform([item.summary]))[0])

Step 4 · A forest of trees第 4 步 · 一片决策树森林

Learn先学

A random forest is many small decision trees, each asking a chain of yes/no questions, with the answers averaged like a vote. It catches patterns a straight line cannot, such as "expensive only when both words appear". The cost is time: it is slower to train. Gradient boosting (XGBoost style) is another strong traditional choice that works the same way in the harness.

随机森林是许多小决策树，每棵问一连串是非题，答案取平均，像投票。它能抓到直线抓不到的规律，比如“两个词同时出现才贵”。代价是时间：训练更慢。梯度提升（XGBoost 一类）是另一个强大的传统选择，在评分板里用法一样。

from sklearn.ensemble import RandomForestRegressor forest = RandomForestRegressor(n_estimators=100, n_jobs=-1, random_state=42) forest.fit(X_train, [i.price for i in train]) def forest_pricer(item): return float(forest.predict(counter.transform([item.summary]))[0]) evaluate(forest_pricer, test) # same test set as before

Put each baseline where it belongs on the ladder, from worst to best.

把每个基线放到阶梯上合适的位置，从最差到最好。

What I got wrong我搞错的地方I compared models on different slices of the data by accident, so the scores meant nothing. I fixed it with one shared test set that every predictor goes through the same evaluate. Also, a few big misses on expensive items dominate the average error, so I look at the scatter plot too.我不小心拿不同的数据切片去比较模型，分数毫无意义。后来改成所有预测器都用同一个测试集、同一个 evaluate。另外，贵东西上的几次大失误会拉高平均误差，所以我也会看散点图。

Now make it yours现在把它变成你的

Back at the void deck回到组屋底层Mdm Tan tells her helper: "If you cannot do better than saying the usual price, do not bother pricing each tin." The usual price is the baseline. Everything cleverer has to earn its place.Mdm Tan 对店员说：“如果你报得比‘平常价’还不准，就别费劲给每个罐头定价了。”平常价就是基线。其他更聪明的办法，都得靠成绩赢得位置。

Takeaways要点回顾

• Build the scoring harness first, then the baselines.
• A random guess is the floor; the training average is the bar.
• Hand-made numbers barely help when the signal is in the words.
• Word counts plus linear regression is a big, cheap jump.
• A random forest finds non-linear patterns but is slower.
• Judge every step with the same metric, on the same test set.
• Traditional ML on good features is a serious opponent for fancy models.

• 先搭评分板，再做基线。
• 随机猜是底线，训练集平均值是门槛。
• 信号藏在文字里时，手工数字帮助很小。
• 词频加线性回归，是便宜又显著的一大步。
• 随机森林能找到非线性规律，但更慢。
• 每一步都用同一个指标、同一个测试集来评判。
• 在好特征上的传统机器学习，是花哨模型的强劲对手。
