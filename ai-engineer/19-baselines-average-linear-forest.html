Baseline predictors基线预测器

You will learn to measure how bad a silly guesser is, so you can tell whether a clever one really helps · ~20 min · concept你会学会先量出“笨办法”有多差，才能判断聪明的办法是不是真的有用 · 约 20 分钟 · 概念课

Step 1 · One scoring board for everyone第 1 步 · 人人共用一块计分板

Learn先学

Before any clever model, write one evaluate(pricer_fn, test_items). It runs every test item through a predictor and reports the average error in dollars, plus a guess-vs-truth scatter plot (the line y = x is perfect). Every predictor is just a function from an item to a number, so any of them plugs in.

在用任何高明的模型之前，先写一个 evaluate(pricer_fn, test_items)。它让每个测试项都过一遍预测器，报告平均美元误差，再画一张“猜测对真实”的散点图（y = x 那条线是满分）。每个预测器都只是“从 item 到数字”的函数，所以谁都能接上。

import matplotlib.pyplot as plt def evaluate(pricer_fn, test_items): errors = [] for item in test_items: guess = pricer_fn(item) errors.append(abs(guess - item.price)) avg = sum(errors) / len(errors) print(f"average error: ${avg:.2f} over {len(errors)} items") plt.scatter([i.price for i in test_items], [pricer_fn(i) for i in test_items], s=8) plt.xlabel("true price"); plt.ylabel("guess"); plt.show() # the closer to y = x, the better return avg

Step 2 · The floor and the bar第 2 步 · 底线与门槛

Learn先学

Two simple guessers set the limits:

两个简单的猜法划出界限：

  • Floor: a random price from 1 to 1000. Terrible, and a useful reference.
  • Bar: always the training average. Anything fancier must beat it, or it is not worth running.
  • 底线：1 到 1000 之间随机报价。糟糕，但是有用的参照。
  • 门槛：永远报训练集平均价。更花哨的办法必须赢过它，否则不值得跑。

train and test are two lists of items from the cleaned dataset. Guessers learn from train; only test scores them.

train 和 test 是清洗好的数据集切出的两份商品清单。预测器从 train 学，只有 test 用来打分。

import random # train and test are the item lists you split in the last lesson; each item has .summary and .price def random_pricer(item): return random.randint(1, 1000) average = sum(i.price for i in train) / len(train) def constant_pricer(item): return average evaluate(random_pricer, test) evaluate(constant_pricer, test)
average error: $412.50 over 250 items average error: $162.40 over 250 items

Step 3 · Words, then a forest第 3 步 · 先用词，再用森林

Learn先学

The price signal lives in the words, not in hand-made numbers like text length. Count the 1,500 most frequent words (skip stop words like "the"), then fit:

价格信号在文字里，不在文字长度这类手工数字里。统计最常见的 1500 个词（跳过“the”这类停用词），然后拟合：

  • Linear regression: the best straight-line rule. A big, cheap jump over the average.
  • Random forest: many small decision trees, answers averaged. It catches patterns a line cannot, but trains slower.
  • 线性回归：最佳直线规则。比平均值进步很大，而且便宜。
  • 随机森林：许多小决策树，答案取平均。能抓到直线抓不到的规律，但训练更慢。
from sklearn.feature_extraction.text import CountVectorizer from sklearn.linear_model import LinearRegression from sklearn.ensemble import RandomForestRegressor counter = CountVectorizer(max_features=1500, stop_words="english") X_train = counter.fit_transform([i.summary for i in train]) y_train = [i.price for i in train] linear = LinearRegression().fit(X_train, y_train) forest = RandomForestRegressor(n_estimators=100, n_jobs=-1, random_state=42).fit(X_train, y_train) def linear_pricer(item): return float(linear.predict(counter.transform([item.summary]))[0]) def forest_pricer(item): return float(forest.predict(counter.transform([item.summary]))[0]) evaluate(linear_pricer, test) evaluate(forest_pricer, test) # same test set, same board

Put each baseline where it belongs on the ladder, from worst to best.

把每个基线放到阶梯上合适的位置，从最差到最好。

What I got wrong我搞错的地方I compared models on different slices of the data, so the scores meant nothing. One shared test set, one evaluate.我拿不同的数据切片去比较模型，分数毫无意义。要用同一个测试集、同一个 evaluate。
Common errors常见报错ValueError: X has 5000 features, but LinearRegression is expecting ...: you fitted on one vectoriser and predicted with another; reuse counter. A forest far better on training than on test memorised the rows; judge on the held-out test set.ValueError: X has 5000 features, but LinearRegression is expecting ...：拟合和预测用了不同的向量器；复用 counter。森林在训练集上远好于测试集，说明它背下了训练行；要用留出的测试集评判。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Build the scoring harness first, then the baselines.
• A random guess is the floor; the training average is the bar.
• Word counts plus linear regression is a big, cheap jump; a forest adds non-linear patterns but is slower.
• If a fancy model cannot beat the baseline, it is not worth the cost.

• 先搭评分板，再做基线。
• 随机猜是底线，训练集平均值是门槛。
• 词频加线性回归是便宜又显著的一大步；森林多了非线性规律，但更慢。
• 花哨的模型如果赢不了基线，就不值得那份成本。
