Chunks, embeddings and vector stores分块、向量与向量库

You will turn a folder of files into a searchable store where similar meaning sits close together · ~20 min · concept你会把一个文件夹变成可搜索的库，意思相近的内容会挨在一起 · 约 20 分钟 · 概念课

Step 1 · Measure, then cut into chunks第 1 步 · 先量一量，再切成块

Learn先学

Count what you have first (files, characters, tokens). If it all fits the context window, ask whether you need RAG at all. If not, cut each file into chunks of about 1000 characters with a 200-character overlap, so a sentence cut at an edge still appears whole in the neighbour. Each chunk keeps metadata, such as its source.

先数一数手上有什么（文件、字符、token）。如果全部放得进上下文窗口，先问问到底要不要 RAG。放不下，就把每个文件切成约 1000 字符的块，前后重叠 200 字符，这样在边缘被切断的句子，会在相邻的块里完整出现。每个块都保留元数据，比如来源。

# pip install langchain-core langchain-text-splitters langchain-openai langchain-chroma langchain-huggingface sentence-transformers tiktoken from pathlib import Path import tiktoken from langchain_core.documents import Document from langchain_text_splitters import RecursiveCharacterTextSplitter docs = [] for path in Path("council_files").glob("**/*.md"): docs.append(Document(page_content=path.read_text(encoding="utf-8"), metadata={"source": path.name, "kind": path.parent.name})) enc = tiktoken.get_encoding("cl100k_base") print(len(docs), "files,", sum(len(enc.encode(d.page_content)) for d in docs), "tokens") splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200) chunks = splitter.split_documents(docs) # metadata is copied to every chunk print(len(chunks), "chunks")

Step 2 · Embeddings: meaning as numbers第 2 步 · 向量：把意思变成数字

Learn先学

An embedding model turns text into a vector: a list of numbers (often 384 to 3072). Similar meaning lands nearby: “lift stuck” and “elevator broken” are neighbours with no shared word. A free local model works; a hosted one is usually better and costs a little.

向量模型（embedding model）把文字变成向量：一串数字（通常 384 到 3072 个）。意思相近的会落在附近：“电梯卡住了”和“电梯坏了”没有相同的词，却是邻居。免费的本地模型就行；托管的通常更好，花一点点钱。

# free and local, or paid and hosted: pick one from langchain_huggingface import HuggingFaceEmbeddings from langchain_openai import OpenAIEmbeddings embedder = HuggingFaceEmbeddings(model_name="sentence-transformers/all-MiniLM-L6-v2") # embedder = OpenAIEmbeddings(model="text-embedding-3-small") vector = embedder.embed_query("The lift is stuck") print(len(vector)) # 384 numbers for the small local model

Step 3 · The vector store第 3 步 · 向量库

Learn先学

A vector store answers “which stored vectors are closest to this one?”. Chroma saved to a folder means you do not re-embed on each start (delete the folder to rebuild). Use the same embedder for the chunks and every later question.

向量库回答“哪些存着的向量离这一个最近？”。把 Chroma 存到文件夹，每次启动就不用重新做向量（删掉文件夹即可重建）。块和之后的每个问题要用同一个向量模型。

import os from langchain_chroma import Chroma if os.path.exists("council_db"): # built last time: reuse it store = Chroma(persist_directory="council_db", embedding_function=embedder) else: store = Chroma.from_documents(documents=chunks, embedding=embedder, persist_directory="council_db") # embeds once, saved on disk for hit in store.similarity_search("Who fixes a stuck lift?", k=3): print(hit.metadata["source"])

Is each statement about chunks, embeddings or the store?

每句话说的是分块、向量，还是向量库？

Common errors常见报错

• Embedding dimension 1536 does not match collection dimensionality 384. A different embedder built the store. Use one for both, or delete the folder and rebuild.
• database is locked. Two programs use the same folder. Close one, or use a fresh folder.

• Embedding dimension 1536 does not match collection dimensionality 384：建库和查询用了不同的向量模型。两边用同一个，或删掉文件夹重建。
• database is locked：两个程序在用同一个文件夹。关掉一个，或换新文件夹。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Measure your files first; if they fit the context window, RAG may not be needed.
• Chunk about 1000 characters with 200 overlap, and keep metadata.
• An embedding turns text into a vector; similar meaning means nearby vectors.
• A vector store finds the closest vectors; save it to disk to avoid re-embedding.
• Use the same embedding model on both sides.

• 先量一量文件；放得进上下文窗口的话，也许不需要 RAG。
• 每块约 1000 字符、重叠 200，并保留元数据。
• 向量模型把文字变成向量；意思相近，向量就相近。
• 向量库找最近的向量；存到磁盘就不用重复做向量。
• 两边必须用同一个向量模型。
