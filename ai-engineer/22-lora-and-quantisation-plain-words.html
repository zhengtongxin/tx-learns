LoRA and quantisationLoRA 与量化

You will learn the two tricks that make fine-tuning fit on a small, cheap GPU, and tell them apart · ~20 min · concept你会学会让微调装得进小而便宜的 GPU 的两个技巧，并分清它们 · 约 20 分钟 · 概念课

Step 1 · LoRA: freeze the book, add sticky notes第 1 步 · LoRA：冻住课本，贴便利贴

Learn先学

A model is billions of weights, each stored in 16 bits (2 bytes): 3 billion weights is about 6 GB. Full fine-tuning updates every one and keeps extra copies for each, several times the model's size, far beyond a free GPU. So train less.

模型是几十亿个权重，每个用 16 位（2 字节）存：30 亿个权重约 6 GB。完整微调要更新每一个，还要为每个保存额外拷贝，是模型体积的好几倍，远超免费 GPU。所以要少训练。

LoRA (low-rank adaptation) freezes the original weights and trains only a small add-on: two thin matrices (grids of numbers; r, the rank, sets how thin) whose product is added to the original weights. Like sticky notes in a printed textbook, the base is never changed and the add-on is a small file you can share.

LoRA（低秩适配）冻住原来的权重，只训练一个小附加件：两个很“瘦”的矩阵（一格格数字；r 叫秩，决定有多“瘦”），它们的乘积被加到原权重上。就像课本页边的便利贴：底座从不被改动，附加件是一个可以分享的小文件。

one layer is 4096 x 4096 numbers ....... 16.8 million weights (frozen) LoRA with r = 8: two thin matrices 4096 x 8 + 8 x 4096 ................ 65,536 weights (trained) that is about 0.4 percent of the layer

Step 2 · Quantisation: pack the frozen part smaller第 2 步 · 量化：把冻住的部分压得更小

Learn先学

LoRA cuts what you train. Quantisation cuts the memory of the frozen part, storing each weight in 4 bits instead of 16, like vacuum-packing clothes: same clothes, a quarter of the space. A 3 to 8 billion weight model then fits a small GPU. LoRA on a 4-bit base is QLoRA.

LoRA 减少要训练的部分。量化减少冻住那部分的内存：每个权重用 4 位而不是 16 位存，就像把衣服抽真空：衣服不变，只占四分之一空间。这样 30 到 80 亿权重的模型就能放进小 GPU。在 4 位底座上做 LoRA 就是 QLoRA。

import torch from transformers import AutoModelForCausalLM, BitsAndBytesConfig pack = BitsAndBytesConfig( load_in_4bit=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype=torch.bfloat16, bnb_4bit_use_double_quant=True, # also compress the small scaling numbers ) model = AutoModelForCausalLM.from_pretrained( "your-small-open-model", quantization_config=pack, device_map="auto") print(model.get_memory_footprint() / 1e9, "GB")
2.3 GB

Step 3 · The LoRA settings and the data第 3 步 · LoRA 设置与数据

Learn先学
  • r: thickness, usually 8 to 32.
  • alpha: volume of the add-on; r or twice r.
  • target modules: which layers get an add-on; start with attention.
  • dropout: switches off a little of the add-on in training to avoid memorising.
  • r：厚度，通常 8 到 32。
  • alpha：附加件的音量；取 r 或 r 的两倍。
  • target modules：哪些层加附加件；从注意力层开始。
  • dropout：训练时关掉一小部分附加件，避免死记。

Shape each example as a prompt plus a short completion, and compute the loss on the answer only, so the model learns to produce the price, not repeat the description.

把每个例子整理成“提示 + 短回答”，只在答案部分算损失，这样模型学的是给出价格，而不是复述描述。

from peft import LoraConfig lora = LoraConfig( r=16, # thickness of the add-on lora_alpha=32, # volume knob, here twice r target_modules=["q_proj", "k_proj", "v_proj", "o_proj"], # attention layers lora_dropout=0.05, # switch off a little while training task_type="CAUSAL_LM", ) example = { "prompt": "Used phone, 128 GB, cracked corner, battery 82 percent. Price is $", "completion": "145", # train on this part only }

Takeaways要点回顾

• Full fine-tuning updates billions of weights: too much for a small GPU.
• LoRA freezes the base and trains two thin matrices; quantisation stores the frozen weights in 4 bits. The two are independent, so they combine (QLoRA).
• Four settings: r, alpha, target modules, dropout.
• Train on a prompt plus a short answer, with loss on the answer only.

• 完整微调要更新几十亿个权重：小 GPU 吃不消。
• LoRA 冻住底座、训练两个很瘦的矩阵；量化把冻住的权重存成 4 位。两者互相独立，所以能配合（QLoRA）。
• 四个设置：r、alpha、目标层、dropout。
• 用“提示 + 短答案”训练，只对答案算损失。
