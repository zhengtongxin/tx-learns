Stall brochure maker摊位宣传册生成器

You will chain two model calls so that a shop's website turns into a short brochure · ~25 min · hands-on你会把两次模型调用串起来，让一家店的网站变成一份简短的宣传册 · 约 25 分钟 · 动手实践

Step 1 · Summarise one page第 1 步 · 总结一个页面

Learn先学

One page in, one summary out. The system prompt sets task and tone; the user prompt carries the page text. A helper strips the page to plain text with BeautifulSoup (pip install beautifulsoup4; decompose() deletes a tag and what is inside it). Pages drawn by JavaScript come back nearly empty: a limit of this helper, not of the model.

一个页面进，一份摘要出。system 提示词定任务和语气，user 提示词装页面文字。辅助函数用 BeautifulSoup（pip install beautifulsoup4；decompose() 删掉标签及其内容）把页面剥成纯文字。靠 JavaScript 画出内容的页面抓回来几乎是空的：这是这个函数的局限，不是模型的问题。

import requests from bs4 import BeautifulSoup from openai import OpenAI client = OpenAI() def page_text(url): soup = BeautifulSoup(requests.get(url, timeout=10).text, "html.parser") for junk in soup(["script", "style", "img"]): junk.decompose() return soup.get_text(separator="\n", strip=True) def ask(system, user): reply = client.chat.completions.create(model="gpt-5-mini", messages=[ {"role": "system", "content": system}, {"role": "user", "content": user}]) return reply.choices[0].message.content print(ask("Summarise this shop page in three lines.", page_text("https://example.com")))

Step 2 · Let the model choose the links第 2 步 · 让模型挑出有用的链接

Learn先学

A brochure needs the About and Careers pages, not Privacy. That is hard as rules and easy for a model. Call 1 gets the landing-page links and returns JSON only. Show one example in the prompt (one-shot prompting) so the reply copies its shape, then json.loads it: it arrives as a string.

宣传册需要“关于我们”和“招聘”页，不需要“隐私”页。这很难写成规则，对模型却很简单。第 1 次调用拿到首页链接，只返回 JSON。在提示词里给一个例子（单样本提示），回复就会照着它的格式，再用 json.loads 解析：回来的是字符串。

import json from urllib.parse import urljoin def all_links(url): soup = BeautifulSoup(requests.get(url, timeout=10).text, "html.parser") return [urljoin(url, a["href"]) for a in soup.find_all("a", href=True)] link_system = """Pick the links a customer or job seeker would want. Skip terms, privacy and mailto. Reply as JSON like: {"links": [{"type": "about page", "url": "https://shop.example/about"}]}""" def pick_links(url, links): reply = client.chat.completions.create(model="gpt-5-mini", messages=[ {"role": "system", "content": link_system}, {"role": "user", "content": f"Site: {url}\nLinks:\n" + "\n".join(links)}], response_format={"type": "json_object"}) return json.loads(reply.choices[0].message.content)["links"]

Step 3 · Write the brochure第 3 步 · 写宣传册

Learn先学

Call 2 gets the landing page plus every picked page, joined under headings and cut to a fixed length so it stays cheap and inside the context window. Change one sentence of the prompt (“warm” to “funny”) and the tone changes: tone is just prompt.

第 2 次调用拿到首页和每个选中的页面，放在小标题下拼起来，并截到固定长度，既便宜又不超出上下文窗口。把提示词里的一个词从“温暖”改成“搞笑”，语气就变了：语气不过是提示词。

brochure_system = "Write a short brochure in markdown. Tone: warm and plain." def build_material(url): parts = ["Landing page:\n" + page_text(url)] for link in pick_links(url, all_links(url)): parts.append("Link: " + link["type"] + "\n" + page_text(link["url"])) return "\n\n".join(parts)[:5000] # quick cap; Lesson 2 counted tokens instead def brochure(url): return ask(brochure_system, build_material(url))

Which job belongs to the model, and which to plain code?

哪些活交给模型，哪些交给普通代码？

Step 4 · Stream the answer第 4 步 · 流式显示回答

Learn先学

A blank screen feels broken. With stream=True the reply arrives in small chunks you can show at once. The yield makes the function a generator: it hands back one piece at a time. It is not faster, it just stops the wait feeling empty.

空白的屏幕让人觉得坏了。传入 stream=True，回复就分小块到来，可以立刻显示。yield 让函数变成生成器：一次交出一小份。它不会更快，只是让等待不再像什么都没发生。

def brochure_stream(url): stream = client.chat.completions.create(model="gpt-5-mini", stream=True, messages=[ {"role": "system", "content": brochure_system}, {"role": "user", "content": build_material(url)}]) text = "" for chunk in stream: text += chunk.choices[0].delta.content or "" yield text for so_far in brochure_stream("https://example.com"): print(so_far[-40:])

Common errors常见报错

• json.decoder.JSONDecodeError. The model wrapped its JSON in words or code fences. Ask for JSON only, or strip fences first.
• MissingSchema: Invalid URL. A relative link has no https://. Join it with urljoin.

• json.decoder.JSONDecodeError：模型在 JSON 外面加了文字或代码围栏。要求只回 JSON，或先去掉围栏。
• MissingSchema: Invalid URL：相对链接没有 https://。用 urljoin 补完整。

Now make it yours现在把它变成你的

Takeaways要点回顾

• Two small calls beat one giant one: pick first, then write.
• Let the model make fuzzy choices; let code do the plumbing.
• JSON replies arrive as strings: json.loads them.
• Cut the input to keep the call cheap and inside the context window.
• Stream the output so the reader sees words straight away.

• 两次小调用胜过一次巨大的调用：先挑，再写。
• 模糊的判断交给模型，管道活交给代码。
• JSON 回复是字符串，要用 json.loads 解析。
• 截短输入，调用才便宜，也不超出上下文窗口。
• 流式输出，让读的人立刻看到字。
